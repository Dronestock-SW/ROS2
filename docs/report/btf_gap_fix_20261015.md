시계 변경은 수신 버퍼를 즉시 초기화한다.
계산 이력은 계산 실행기에서 다음 스냅샷 때 초기화한다.
발행 직전에 같은 시계인지 다시 검사한다.
늦은 응답을 정상 동기 응답으로 바꾸지는 않는다.

TDMA40 부분 프레임은 진단 span이 0일 수 있다.

거리 제곱 차이로 초기값을 구한다.
최대 8회의 보정으로 물리 거리 잔차를 최소화한다.
기존 잔차·연속성 기준을 통과해야 승인한다.
누락 앵커의 거리나 높이를 채우지 않는다.
부분 프레임을 기존 B4 이력에 섞지 않는다.
발행 시각은 마지막 실제 앵커 측정 시각이다.
이 경로는 C++ 계산기에 적용한다.
Python 비교 계산기는 기존 4앵커 경계를 유지한다.
