# 실물 B_TF 연결 결과 — 2026-10-05

실물 수신 연결의 구현·실행 결과다.
비행 전달 전에 완료 범위와 남은 검증을 확인한다.

## 현재 결론

실물 UWB·ToF·자세를 B_TF에 연결했다.
Jetson에서 60초 통합 실행 두 번을 마쳤다.
FC 위치 전달과 비행 검증은 미실시다.
관측 보류가 많아 비행용 입력으로 승인하지 않았다.

## 반영한 설치값

| 항목 | 값과 근거 |
|---|---|
| 앵커 XY 배치 | 6.3×4.6m, 사용자 확인 |
| 앵커 높이 | 네 앵커 모두 2.2m, 사용자 확인 |
| TFmini Plus | 하방·PX4 연결, 사용자 확인 |
| ToF 렌즈→UWB 안테나 | FLU [0,0,0.12]m, 사용자 확인 |
| 바닥 | 평평한 바닥·측정거리 확보, 사용자 확인 |
| 거리 편향 차감 | [0,0,0,0]m, 실물 교정 미완료 |

사용자 설치 확인과 독립 측량은 구분한다.
0m 편향 차감은 실제 편향이 없다는 뜻이 아니다.
태그 상태의 배치 이름은 구형 값이었다.
현재 계산은 태그 XY 대신 네 원시 거리를 사용한다.
따라서 companion의 확인된 앵커 좌표를 적용했다.

## 구현 범위

기존 수신기는 `/uwb/received`를 추가 발행한다.
원래 거리·앵커별 측정시각·호스트 수신시각을 보존한다.
기존 `/uwb_pose` 계산 경로도 보존했다.

새 `uwb_btf_node`가 해당 기록을 구독한다.
MAVROS의 실제 하방 거리·자세도 함께 구독한다.
현재 높이는 거리와 자세·장착 간격으로 계산한다.
FC의 추정 위치를 보정 입력으로 사용하지 않는다.
가상 정답이나 고정 높이로 누락을 채우지 않는다.

실물은 첫 앵커부터 마지막까지 보통 12ms가 걸린다.
새 연결부는 앵커별 실제 시각으로 회귀·잔차를 계산한다.
0.8초 창의 경계도 각 앵커 시각으로 검사한다.
동시 측정으로 바꾸어 기록하지 않는다.

핵심 B_TF 설정은 final108과 같다.
H80 창 0.8초, 잔차 한계 0.06m를 유지했다.
후보 구분 차이 0.015m, 직전 관측 만료 0.1초다.
실물 ToF 최대 나이는 0.1초다.
자세와 ToF의 허용 시각 차이는 0.02초다.
광축 수직 투영 0.8 이상을 지상 진단 조건으로 둔다.
이 조건은 실물 비행 승인 기준으로 확정한 값이 아니다.

ESP32 시계는 기존 호스트 대응 계산을 사용한다.
PX4 센서 시각은 MAVROS TIMESYNC로 받는다.
상수 통신 지연의 물리 교정은 미완료다.
출력에는 `timestamp_calibrated=false`를 유지한다.

출력은 `/uwb/btf_pose`의 안테나 기준 XY다.
높이·자세는 이 메시지의 관측 대상이 아니다.
새 launch는 FC 위치 브리지를 실행하지 않는다.
MAVROS의 위치 송신·목표·command 플러그인도 제외했다.
시동·모드·FC 파라미터를 변경하지 않았다.

두 구간 모두 원시 수신률은 약 43.96Hz다.
첫 구간 ToF 측정 범위는 0.43~1.28m였다.
두 번째 구간은 0.12~1.57m였다.
첫 실행의 앵커 제외 보정은 50건이다.
두 번째 실행에서는 4건이다.
이는 분기 실행 증거이며 정확도 검증이 아니다.

두 실행의 위치·이동·자세를 고정하지 않았다.
따라서 두 비율을 성능 향상·저하로 비교하지 않는다.
시작 시 상태 대기와 시계 준비도 전체 RAW에 포함했다.
구독 시작 전에 놓친 RAW도 분모에서 제거하지 않았다.
구간 평균이나 성공 좌표만으로 연속성을 판정하지 않는다.
두 번째 구간에서 발행 간 최대 공백은 약 17.27초였다.
직전 좌표를 새 값처럼 재발행하여 공백을 숨기지 않았다.

두 번째 실행의 주요 보류는 다음과 같다.

보류 원인을 센서 고장이나 NLOS로 단정하지 않는다.
앵커 순서·개별 거리 편향·측정 기준을 확인해야 한다.
마지막 실행에서 FC 상태 60개를 기록했다.
모두 시동 해제 상태였다. 모드는 ALTCTL이었다.
두 통합 실행은 60초 후 정상 종료했다.

## 남은 작업

1. 독립 기준점에서 태그의 실제 XYZ를 측정한다.
2. 그 지점의 각 앵커 예상 거리와 원시 거리를 비교한다.
3. 앵커 ID 순서·개별 편향·ToF 높이 기준을 확인한다.
4. 정지·직선 이동에서 보류와 발행 공백을 다시 측정한다.
5. 시간 지연·FC 기준점·좌표 정렬을 확인한다.
6. 그 다음 FC 지상 융합과 호버링을 별도로 검증한다.
