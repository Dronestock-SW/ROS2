# M04 H80 시간창 회귀

최근 거리 이력으로 위치를 구하는 모델 명세다. H80 참고 구현을 대조하거나 다른 위치 모델과 비교할 때 읽는다.

## 목적과 현재 상태

시간창의 네 앵커 관측을 함께 회귀한다.
ZIP의 C++과 기존 `h80.py`는 완전 동일하지 않다.
현재 파일 파이프라인은 두 풀이를 호출하지 않는다.
시험 variant를 구분한 뒤 수식과 출력을 비교한다.

2026-09-26에 기존 함수의 합성 샘플과 거리 로그 구조를 검사했다.
실측 정확도 검증과 구분해 [결과](../../report/uwb_h80_readiness_20260926.md)에 기록했다.

2026-09-27에는 실측 A 완료 후 B 준비 상태를 대조했다.
현재 1분 RAW·시각·배치·편향 후보로 파일 비교를 시작할 수 있다.
준비 검토 뒤 창 관리·네 앵커 조건·A/B 평가를 연결했다.
[B 준비표](stage_selection.md#2026-09-27-b-시작-준비)를 따른다.
후속 [B 완료 기록](../../report/uwb_h80_b_20260927.md)에 결과를 남겼다.
실측 정지 비교·합성 여섯 시나리오를 실행했다.
비행 연결은 미실시다.

## 입력 준비 판단

필요한 이력은 최근 거리와 시각이다.
이전 비행 경로·위치 추정 결과를 미리 확보할 필요는 없다.
지상 태그의 거리 기록으로도 함수와 창 처리를 시험할 수 있다.
네 앵커 각각 최소 3표본과 회귀행렬의 독립성이 필요하다.
0.8초는 최대 창 길이이며 최소 대기 시간과 같지 않다.
완성된 경로의 warmup·시각 매핑·교정은 별도 검증 대상이다.

## 처리 구조와 산식

```text
시각별 거리 창 → 설계행렬 → 열 스케일 조정
       → 가중 회귀·Huber 반복 → rank/잔차 검사 → 후보
```

`tau=(t_j-t_ref)`는 초 단위다.
설계 변수는 `[x0,y0,vx,vy,c0,c1,c2]`다.

```text
y_j = r_j^2 - ax_j^2 - ay_j^2
y_j ≈ -2*ax_j*(x0+vx*tau) -2*ay_j*(y0+vy*tau)
      +c0+c1*tau+c2*tau^2
e_j ≈ (y_fit_j-y_j)/(2*max(r_j, range_floor))
w_j = min(1, huber_delta/abs(e_j)) / variance_squared_range_j
```

`reference_slant`는 같은 높이의 앵커를 전제로 한다.
높이 차의 제곱 항은 공통 시간 다항식에 포함된다.
그 근사가 맞지 않는 움직임은 잔차·위치 오차로 평가한다.
`z_compensated`는 y_j에서 `(z_j-az_j)^2`도 뺀다.
이는 새 시험 variant이며 ZIP의 재현으로 표시하지 않는다.
Z를 뺀 목표값의 오차 전파도 별도로 계산한다.
정규화 시간 u를 쓰는 함수는 속도를 `x1/window_s`로 환산한다.
행렬의 역행렬을 직접 만들지 않고 QR/SVD로 푼다.

## 실패와 상태

앵커 하나라도 표본이 부족하면 네 앵커 모델은 차단한다.
서로 다른 시각이 부족해 행렬 rank가 낮아도 차단한다.
독립 함수의 기본 세 앵커 허용과 B 실행기를 구분한다.
B는 `required_anchor_count=4`로 호출한다.
Z 없이 reference_slant 수학 시험은 가능하다.
모든 모델의 공통 비교는 Z·기준 위치가 있는 자료로 수행한다.
단절과 boot에서는 이전 창을 재사용하지 않는다.

## 테스트와 평가

| 시험 | 확인할 결과 |
|---|---|
| 알려진 궤적·무잡음 거리 | 위치·속도·계수 단위 일치 |
| 같은 시각의 반복 표본 | 표본 수만으로 rank 통과하지 않음 |
| 단발 튐·지속 편향 | 강건성·잔차와 실제 오차 차이 |
| 이동·회전·정지·급변 | 평활 효과와 지연·최대 점프 |
| ZIP/Python/new variant | 동일 수식 구간과 의도적 차이 기록 |

출력률·표본수·공백·계산 시간도 함께 비교한다.
README의 과거 cm 오차를 이번 시험 결과로 사용하지 않는다.

## 2026-09-27 구현 연결

`processing/experiments/h80_b.py`가 파일 실행기다.
입력 해시·편향 잠금은 전용 JSON 설정으로 검사한다.
재부팅·시각 역행·150ms 초과 공백에서 창을 초기화한다.
추가 거리·위치 게이트와 Q_S10은 적용하지 않았다.
속도는 정규화 위치 계수를 0.8초로 나눈다.
최대 표본 나이 0.8초와 최신 표본 간격 0.04초를 구분한다.
현재 B의 모든 출력은 수신 주기 종료 시각을 가리킨다.
