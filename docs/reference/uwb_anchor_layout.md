# 현재 UWB 앵커 좌표

현재 실행에 쓰는 앵커 좌표 사전이다. 배치·설정 변경 전에 읽는다.

2026-10-15 사용자가 현재 배치를 다시 확인했다.
Tag B와 새 단일 태그 설계는 아래 좌표를 쓴다.
0.15m를 현재 기준으로 삼고 자동 복원을 가정하지 않는다.
[운영 조회](uwb_recovery_baseline_20261015.md)와 일치한다.

가로 x는 6.3m, 세로 y는 4.6m다.
A1을 원점으로 두고 A2 방향을 +x로 삼는다.
A3 방향은 +y다. 네 앵커 높이는 바닥 기준 0.15m다.
이 높이는 앵커 안테나 중심의 설치 높이다.
드론의 가상 고도 제거는 [고도 원칙](../altitude_policy.md)을 따른다.

| 앵커 | x (m) | y (m) | z (m) |
|---|---:|---:|---:|
| A1 | 0.0 | 0.0 | 0.15 |
| A2 | 6.3 | 0.0 | 0.15 |
| A3 | 0.0 | 4.6 | 0.15 |
| A4 | 6.3 | 4.6 | 0.15 |

```text
        +y
         ^
 A3 (0,4.6) -------- 6.3m -------- A4 (6.3,4.6)
         |                              |
       4.6m                           4.6m
         |                              |
 A1 (0,0) ---------- 6.3m -------- A2 (6.3,0) --> +x
```

A1-A2와 A3-A4는 x 방향 6.3m다.
A1-A3와 A2-A4는 y 방향 4.6m다.
두 대각선은 계산상 약 7.80064m다.
배열 순서는 `[A1,A2,A3,A4]`를 유지한다.

## 적용 위치

현재 Tag B의 명시적 설정과 일반 예제를 구분한다.

| 구분 | 경로·상태 |
|---|---|
| 현재 기준 파일 | [anchors_20261007_z015.json](../../src/drone_uwb/config/anchors/anchors_20261007_z015.json) |
| 배치 ID | `warehouse-rectangle-6p3x4p6-z0p15-20261007` 유지 |
| Tag B 수신 설정 | [uwb_tag_b.yaml](../../src/drone_uwb/config/runtime/uwb_tag_b.yaml)의 `anchor_file` |
| 운영 B_TF | 10/15 조회한 `field-btf-cpp.json`도 같은 네 좌표 |
| 일반 데모·Gazebo·Tag A·z2p2 예제 | 이 작업에서 변경하지 않음. 현재 Tag B 배치로 사용할 때 별도 선택 필요 |
| 이번 변경 | 현재 기준 문서·설정의 설명 갱신. 운영 좌표는 이미 일치하며 재배포하지 않음 |

XY 크기는 사용자가 정한 현재 고정값이다.
독립 측량 완료를 뜻하지 않으므로 검증 표시는 false다.
사용자 확인과 독립 측량 완료를 구분한다.
좌표 변경만으로 거리 bias를 재교정하지 않는다.
기존 교정값과 새 배치의 실측 검증은 별도다.

## 과거 자료와의 관계

9월 실측 재생에는 당시 좌표를 사용한다.

| 자료 | 사용할 배치 |
|---|---|
| 현재 Tag B·새 단일 태그 설계 | `anchors_20261007_z015.json` |
| 과거 높이 2.2m 시험 | 당시의 `anchors_20261004.json` |
| 2026-09-06 정지 기록의 A/B/C/D 재생 | `anchors_20260906.json`과 고정된 입력 해시 |
| 기존 `data/raw/`, `data/processed/` | 기록 당시의 좌표·설정·manifest |

과거 좌표 파일과 기록의 해시를 덮어쓰지 않는다.
당시 결과의 재현 근거를 유지하기 위해서다.
[9월 실측 이력](uwb_anchor_survey.md)은 이전 배치의 근거다.
[변경·검증 기록](../report/uwb_anchor_rectangle_20261004.md)을 함께 읽는다.
