# UWB 단계별 적용과 선택안

기능을 처리 순서와 선택 관계로 정리한 설계안이다. 개별 명세를 읽기 전에 전체 구조를 파악할 때 읽는다.

## 전체 구성

**공통 입력을 준비한 뒤 위치 계산 모델을 비교한다.**
게이트·필터는 각 모델에 추가할 수 있는 보조 기능이다.
이번 정리는 시험 순서 제안이며 모델 선정 결과가 아니다.

```text
UWB RAW                         ToF·자세 / 제공되는 Z
   |                                     |
① 원본·시각·단위 검사              원본·시각·기준점 검사
   |                                     |
② 거리 편향 차감                  안테나 기준 Z 준비
   + 선택적 거리 게이트                  |
   + 선택적 거리 신뢰도                   |
   +------------------+------------------+
                      |
③ 위치 계산 모델을 선택해 각각 실행
   A. 네 앵커 거리 풀이: 동일 가중 / 품질 가중
   B. H80: 거리 이력을 이용한 회귀
      └─ 단절 후 복구 시험에서만 Q_S10 추가 비교
   C. 세 앵커 네 묶음 → 후보 결합
   D. 묶음별 중간 교점 → 후보 결합
                      |
④ 결과 품질 확인 → 선택적 평활 → 최종 위치 게이트
   잔차 검출·제외 시험은 필요할 때 ③을 재실행
                      |
⑤ 좌표·기준점 변환 → 파일 기록 → 같은 기준으로 평가

추가 센서 시험은 필요한 자료를 확보한 뒤 별도 비교
```

그림의 네 분기는 같은 자료를 읽되 상태는 분리한다.
H80 창과 후보 결합 결과를 서로 입력으로 섞지 않는다.
그래야 각 위치 계산법의 효과를 구분할 수 있다.
직접 거리 UKF는 후속 비교에서 ③을 대체하는 별도 모델이다.

## 단계별 적용과 선택

공통 준비·모델 선택·추가 기능의 역할을 구분한다.

| 단계 | 공통으로 필요한 처리 | 비교하거나 추가할 기능 | 선택 방안 |
|---|---|---|---|
| ① 입력 준비 | RAW 보존, 시각·중복·단위 검사. ToF Z 연결 형식 | 시계 매핑·시간 정렬 방식 | 모든 모델의 공통 기반으로 준비 |
| ② 거리·높이 준비 | `RAW - 편향`, 위치 풀이에 필요한 Z 연결 | 거리 게이트, RF/CIR 기반 오차 모델 | 편향만 적용한 기준선과 하나씩 비교 |
| ③ 위치 계산 | 같은 앵커 지도·시간·기준점 사용 | A/B/C/D, 후속 직접 거리 UKF | 서로 대체하는 계산 모델로 비교 |
| ④ 결과 판정·평활 | 계산 성립 여부와 잔차를 기록 | 추가 배치 게이트, 이상 검출·제외, KF/UKF 평활, 위치 게이트 | 같은 모델에서 하나씩 켜고 꺼서 기여 확인 |
| ⑤ 변환·기록·평가 | 기준점·좌표 변환, 성공/실패·시각 기록 | 공통 지표로 모델·보조 기능 조합 비교 | 오차·새 관측 가용률·지연·복구를 함께 평가 |

행렬 rank 부족처럼 풀이 자체가 불가능한 조건은 항상 차단한다.
추가 품질 게이트의 임계값과 이 기본 조건은 구분한다.
Z 자료가 없는 동안 해당 계산 시험은 입력 대기로 둔다.
현재 단계 번호는 처리 순서이며 구현 완료 표시가 아니다.

## 위치 계산 모델의 선택 관계

사용자는 네 앵커의 동일 가중 거리 풀이 A를 기준선으로 정했다.
구성이 단순해 다른 기능의 추가 효과를 비교하기 쉽다.

| 선택지 | 적용하는 상황·목적 | 기대 효과 | 함께 평가할 한계 |
|---|---|---|---|
| A 동일 가중 | 최소 기능의 기준선 | 거리 보정·기하 계산의 기본 성능 파악 | 나쁜 거리도 같은 비중으로 반영 |
| A 품질 가중 | 앵커별 오차 분산을 알 때 | 불확실한 거리의 영향 조정 | 잘못된 신뢰도가 결과를 악화시킬 수 있음 |
| B H80 | 거리 이력을 사용할 때 | 창 안의 여러 관측과 강건 회귀 활용 | 시간창 준비·움직임 근사·추종 지연 |
| C 세 앵커 조합 | 네 묶음의 결과를 비교할 때 | 묶음별 불일치와 후보 결합 효과 확인 | 후보가 거리 측정을 공유함 |
| D 중간 교점 | 교점 기반 후보 생성법을 비교할 때 | 교점 선택·평균 방식의 효과 확인 | 교점 없음·복수 해·입력 오차 증폭 |
| 후속 직접 거리 UKF | 시간 상태와 거리 관측을 함께 시험할 때 | 운동 예측과 비선형 관측 갱신 비교 | 초기화·잡음 설정·공백 예측 검증 필요 |

C/D는 처음에 후보를 균등하게 결합한다.
그다음 같은 후보에 품질 가중·상하위 가중을 적용한다.
후보 생성과 가중치 변경의 효과를 따로 확인하기 위해서다.
12개 중간 교점 슬롯을 12개 독립 측정으로 취급하지 않는다.

## C와 D의 구체적인 구성

같은 네 거리를 쓰지만 묶음 안의 계산 방법이 다르다.

```text
네 앵커 A1, A2, A3, A4
  ├─ S1 = {A1,A2,A3}
  ├─ S2 = {A1,A2,A4}
  ├─ S3 = {A1,A3,A4}
  └─ S4 = {A2,A3,A4}

C: 각 S의 세 거리 잔차를 함께 최소화 → 위치 1개
   → 네 위치의 단순 평균 → 품질 가중의 추가 효과 비교

D: 각 S에서 두 앵커씩 원의 교점 계산
   S1의 예:
     (A1,A2) 교점 → A3 거리와 더 잘 맞는 교점 선택
     (A1,A3) 교점 → A2 거리와 더 잘 맞는 교점 선택
     (A2,A3) 교점 → A1 거리와 더 잘 맞는 교점 선택
   → 선택한 세 점의 평균 → 네 묶음 위치 결합
```

D의 원 중심은 각 앵커 XY다.
원의 반지름은 `sqrt(r_cal²-(z_ant-z_anchor)²)`다.
두 원은 보통 교점 두 개를 만들 수 있다.
세 번째 앵커의 거리 잔차가 작은 쪽을 고른다.
동률이나 교점 없음은 실패·모호 상태로 남긴다.
거리 확장으로 교점을 만드는 방식은 별도 시험안이다.

네 묶음에서 교점 세 개씩 고르면 슬롯은 최대 12개다.
고유 앵커 쌍은 여섯 개이며 묶음 사이에서 다시 사용된다.
따라서 C와 D 모두 후보 수만으로 정보량이 늘었다고 주장하지 않는다.
A1에 편향이 생기면 C의 S1·S2·S3가 함께 영향을 받는다.
후보의 다수결이나 평균만으로 이상 앵커가 해결되지는 않는다.

## 보조 기능을 붙이는 위치

추가 기능은 입력 조건과 해결할 문제가 있을 때 시험한다.

| 기능 | 연결 위치 | 적용·선택 조건 |
|---|---|---|
| 거리 게이트 | ② 거리 입력 뒤 | 단발 튐 억제와 정상 이동 거부를 함께 비교 |
| RF/CIR 신뢰도 | ② 오차 모델 → ③ 거리 가중치 | 실제 진단 필드와 교정 자료가 있을 때 |
| Q_S10 | ③ H80의 복구 분기 | 유효한 Z와 단절 후 복구 조건이 있을 때 |
| 배치 품질 게이트 | ③ 계산 중·④ 결과 확인 | 추가 거부가 실제 오차를 줄이는지 비교 |
| 잔차 이상 검출·제외 | ④ 검사 → ③ 조건부 재계산 | 검출 전용부터 확인하고 제외는 별도 시험 |
| 위치 KF/UKF | ④ 위치 계산 뒤 | 잡음 감소가 추종 지연 증가보다 유리한지 비교 |
| 위치 게이트 | ④ 최종 후보 | 튐 억제와 정상 이동·복구 지연을 함께 평가 |
| LiDAR 보조 | ② 거리 대조·교정 또는 ④ 위치 대조 | 앵커 대응이나 독립 위치·좌표 변환이 확보될 때 |
| GNSS·UWB 융합 | ③ 이후 위치 결합 분기 | 동시 GNSS 자료·좌표 변환·오차 정보가 있을 때 |

Q_S10은 현재 명세에서 H80 복구 보조로 설계했다.
모든 위치 계산법 뒤에 공통으로 붙는 필터는 아니다.
위치 UKF와 직접 거리 UKF도 적용 단계가 다르다.
후자는 같은 거리로 만든 위치를 다시 중복 갱신하지 않는다.

## 추가 기능의 효용과 시험 상황

아래 효용은 검증 전 예상이며 도입 우선순위의 제안이다.

| 기능 | 예상 효용 | 시도할 구체적인 상황 | 효과를 판단할 항목 |
|---|---|---|---|
| 거리 게이트 | 단발 튐 억제. 먼저 비교할 가치가 있음 | 정지·등속 입력의 한 앵커에 한두 번 큰 거리 오차 주입 | 최대 위치 오차 감소와 정상 이동의 거부율 |
| 배치 품질 | 불안정한 풀이를 식별하는 진단 | 중앙·가장자리·앵커 밖으로 이동. 좁은 앵커 배치도 합성 | 예측한 불량 구간과 실제 오차, 거부 후 가용률 |
| 위치 게이트 | 좌표 급변을 최종 단계에서 보류 | 한 번의 튐과 실제 급가속·방향 전환을 각각 입력 | 오수용 감소와 실제 움직임을 멈춰 보이는 현상 |
| 위치 KF/UKF | 작은 흔들림 감소 가능 | 정지→등속→급정지·반전, 짧은 공백 | 정지 산포·p95 오차·추종 지연·복귀 점프 |
| 직접 거리 UKF | 거리와 운동 예측을 한 계산에서 사용 | 같은 이동·가림 로그에서 A/H80/직접 UKF 비교 | 비선형 갱신의 이득과 잡음 설정 민감도 |
| Q_S10 | 단절 후 초기 위치 복구 보조 가능 | 150ms 이하/초과 공백, 복귀 시 양의 거리 편향, 이동 중 단절 | H80 단독 대비 복구 시간·오복구·잔여 편향 |
| 잔차 검출·제외 | 한 관측의 지속 이상 진단 가능 | 앵커 하나씩 편향 주입. 두 앵커 동시 편향도 대조 | 오검출·잘못된 제외·최대 오차. 검출 전용부터 시작 |
| RF/CIR | 차폐 때 나쁜 거리의 비중 조정 가능 | 직접 경로→사람/금속 차폐→복귀를 RF 진단과 동시 기록 | 품질 정보와 실제 거리 오차의 관계, 다른 세션 재현 |
| LiDAR 보조 | 독립 기준으로 거리 편향을 찾을 가능성 | 앵커 표적을 식별하거나 독립 지도 위치가 확보된 구간 | 거리 대조 오차, 잘못된 표적·지도 정렬 영향 |
| GNSS 융합 | 실내외 전환의 관측 연속성 | 실외→출입구→실내→실외의 동시 기록 | 단독 대비 공백·전환 점프·오차와 공분산 타당성 |

정지 잡음과 단발 튐은 비교적 작은 합성 시험부터 확인할 수 있다.
Q·RF/CIR·LiDAR·GNSS는 관련 입력이 확보됐을 때 시험한다.
H80 합성 예시에서 방향 반전은 A보다 RMSE가 증가했다.
따라서 평활이나 게이트의 효과를 정지 구간만으로 판단하지 않는다.
[실행한 예시와 한계](../../report/uwb_h80_readiness_20260926.md)를 함께 읽는다.

## 권장 시험 순서

선택은 한 번에 하나의 차이를 비교하며 진행한다.

1. 공통 입력·기록과 ToF Z 연결을 준비한다.
   자료가 없는 동안 인터페이스·누락·상태 전환을 먼저 시험한다.
2. 편향 차감과 A 동일 가중으로 최소 기준선을 만든다.
   2026-09-26 파일 실행기와 실측 정지 비교를 완료했다.
   [실측 A 기록](../../report/uwb_baseline_a_static_20260926.md)의 조건을 유지한다.
3. 같은 전처리 조건에서 A/B/C/D를 비교한다.
   가중치 비교는 필요한 오차 정보가 준비된 뒤 추가한다.
4. 후보 모델마다 게이트·평활을 하나씩 추가해 비교한다.
   H80에는 복구 구간에서 Q_S10의 추가 효과를 확인한다.
5. 개선된 모델·보조 기능 조합을 독립 평가 자료로 재확인한다.
   선택하지 않은 모델에도 유리한 조합이 있는지 좁혀서 비교한다.
6. RF/CIR·LiDAR·GNSS·직접 거리 UKF는 준비 조건에 따라 확장한다.
   센서 구성이 바뀐 결과는 별도 비교군으로 기록한다.

RF/CIR 자료가 먼저 준비되면 ③의 가중 풀이 시험에 사용해도 된다.
위 순서는 기능 준비 의존성을 고려한 제안이다.
처리 순서를 모든 기능의 일괄 실행 순서로 해석하지 않는다.

선정 기준은 [비교·선정 절차](90_evaluation.md)를 따른다.
오차가 줄었어도 출력이 자주 끊기거나 지연이 늘면 함께 평가한다.
현재 최종 모델·계수는 미선정이다.
A는 합성·실측 정지 기록 시험을 마쳤다.
B는 2026-09-27에 같은 실측 정지 입력으로 A와 비교했다.
C/D 첫 방식의 구현·정지·합성 비교도 완료했다.
C/D 후보의 품질 가중·반지름 확장·동적 실측은 남아 있다.
거리 가중 WLS는 별도 구현해 합성 입력으로 확인했다.
[Gazebo 준비 기록](../../report/uwb_gazebo_shadow_20260927.md)을 따른다.
기존 파이프라인의 계산·외부 전달 게이트도 닫혀 있다.

## 2026-09-27 B 시작 준비

B의 파일 비교는 현재 자료로 시작할 수 있다.
MAVROS·MAVLink는 이후 실시간 전달 경로다.
알고리즘의 파일 시험에 기체 통신을 연결할 필요는 없다.

| 앵커 좌표 | A가 사용한 배치 확보 | 같은 지도 사용 |

| H80 수식 | `preimu/h80.py` 있음 | 네 앵커 조건·수치 실패 검사 연결 |

첫 B는 기존 Python H80의 `reference_slant` 비교군으로 준비한다.
이 방식은 앵커의 높이가 같다는 지도 조건을 사용한다.
실시간 ToF 자료 없이 정지 기록의 수학 시험을 진행할 수 있다.
ZIP의 C++과 완전히 같은 구현이라고 표시하지 않는다.
ToF를 결합한 확장과 실비행 검증은 별도 단계다.

우선 H80만 A와 비교해 기여를 확인한다.
추가 게이트·Q_S10의 기여는 그 뒤 별도로 비교한다.
위 표는 착수 전 준비 검토 기록이다.
후속 요청으로 아래의 구현·비교를 완료했다.
