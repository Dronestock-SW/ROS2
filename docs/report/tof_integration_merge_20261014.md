## 충돌 해결

코드 충돌은 이미 빌드한 요청 처리 내용으로 해결했다.

| 파일·문서 | 해결 |
|---|---|
| manual_streams.py | r1 overlay의 바이트를 복원. 원격의50Hz도 포함 |
| glossary.md | 양쪽에서 추가한 용어 모두 보존 |
| ToF 후보 문서 | 기존 `-P`는 이전 후보. 확정본 `-T` 링크 추가 |
| PX4 패치 | 같은 드라이버에 두 후보를 중복 적용하지 않음 |
| Git 속성 | 확정 패치·명세의 바이트 보존. patch 문맥 공백 유지 |

다른 담당자의 native B_TF·mission·LiDAR 코드는 수정하지 않았다.
`-P` 후보의 소스도 삭제하지 않았다.
R3 후보와 R2+ToF r1은 서로 다른 펌웨어 구성이다.
