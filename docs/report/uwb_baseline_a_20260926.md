## 계산 구조와 산식

각 UWB 표본 시각 이전에 도착한 ToF·자세를 사용한다.
시각이 맞지 않거나 입력이 없으면 위치를 내지 않는다.

```text
원본 파일 보존
  -> 입력 형식·시간 확인
  -> 네 거리에서 각 편향 차감
  -> 각 거리 시각에 맞는 ToF·자세 선택
  -> 장착 기하로 안테나 Z 계산
  -> 네 거리 동일 가중 최소제곱 -> XY·잔차 파일
                                     |
별도 기준 XY ------------------------> 오차 평가
```

```text
r_i = raw_slant_i - bias_i

d_ToF = raw_ToF - bias_ToF
z_FC = z_ground - (R_WB * lever_ToF).z
                  - d_ToF * (R_WB * axis_ToF).z
z_ant_i = z_FC + (R_WB * lever_UWB).z

d_i(x,y) = sqrt((x-ax_i)^2 + (y-ay_i)^2 + (z_ant_i-az_i)^2)
(x_hat,y_hat) = argmin sum(i=1..4) (d_i(x,y)-r_i)^2

수평 오차 = sqrt((x_hat-x_ref)^2 + (y_hat-y_ref)^2)
거리 적합 RMS = sqrt(sum(i=1..4) (d_i-r_i)^2 / 4)
```

R_WB는 기체 벡터를 창고 좌표로 옮기는 회전이다.
lever는 FC에서 센서까지의 장착 벡터다.
자이로 RAW를 교정하는 계산은 포함하지 않는다.
거리 잔차와 실제 위치 오차는 다른 지표다.

ToF는 목표 시각 이전의 가장 최근 표본을 선택한다.
자세는 해당 ToF 시각 이전 표본을 선택한다.
미래 표본을 이용한 보간이나 Z 평활은 적용하지 않았다.
한 프레임 안에서는 XY가 같다고 근사한다.
네 거리의 측정 시각 간격은 이번 입력에서 12ms다.
수평 이동 시 이 근사의 영향을 별도로 시험해야 한다.
