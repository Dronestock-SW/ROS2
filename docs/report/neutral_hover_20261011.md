앵커 복원 전후 수동 비행의 관측 분석 결과다.

## 결론

**착륙을 제외한 38.5초 중립 호버를 확인했다.**
사용자의 표현은 조종 불능이 아닌 손을 뗀 구간이다.
RC 중립과 FC 고정 목표가 함께 확인된다.
UWB 공중 장기 공백은 이번 배치에서 재현되지 않았다.
UWB·LiDAR의 상대 변화와 FC 내부 추정은 차이가 난다.
독립 위치 기준이 없어 실제 XY 오차는 확정하지 않는다.

사용자는 실제 약간의 이동도 있었다고 설명했다.
착륙점도 이륙점과 다르다고 설명했다.
아래 구간은 이륙·스틱 조작·착륙을 제외했다.
따라서 착륙점 차이를 센서 오차로 계산하지 않았다.

## 실제 이동과 yaw의 대조

LiDAR도 약한 이동을 관측했다. 아직 기준 측위는 아니다.
같은 중립 구간의 첫·끝 스캔을 세 쌍으로 비교했다.

| 관측 | 상대 변화 |
|---|---|
| UWB 첫·끝 5초 중앙값 | XY 19.3cm |
| LiDAR 세 쌍의 이동량 | 16.1 / 18.2 / 18.3cm |
| LiDAR 네 방향 구역을 하나씩 제외 | 18.2–18.9cm |
| LiDAR yaw | 약 -2.84~-3.68° |
| FC 각속도·자세로 적분한 yaw | 전체 -3.62°, 첫·끝 5초 기준 -2.82° |
| FC heading 첫·끝 5초 중앙값 | 약 +0.07° |

스캔 잔차는 약 3.5–4.2cm다.
단순 2D 스캔매칭이며 장착 TF·deskew를 적용하지 않았다.
움직이는 사람을 분류해서 제거한 결과도 아니다.
각속도 적분도 바이어스가 누적되므로 정답이 아니다.
서로 다른 관측점과 좌표계의 벡터를 직접 빼지 않았다.
UWB 전체 변화가 가짜라는 결론은 근거가 부족하다.
실제 완만한 이동·회전과 FC 추정 차이를 우선 대조한다.

FC의 `heading_good_for_control=false`가 계속 기록됐다.
`cs_mag_hdg=true`, `cs_mag_aligned_in_flight=false`였다.
해당 펌웨어의 [EKF 구현](https://github.com/PX4/PX4-Autopilot/blob/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/modules/ekf2/EKF/ekf.h#L223)은
자력계 사용 시 공중 방위 정렬 완료를 요구한다.
[방위 정렬 조건](https://github.com/PX4/PX4-Autopilot/blob/d6f12ad1c4f70ad3230afd7d86e971421e02fef4/src/modules/ekf2/EKF/aid_sources/magnetometer/mag_control.cpp#L329)은
지면 기준 추정 높이 1.5m 초과를 사용한다.
이번 중립 구간의 `dist_bottom`은 1.159–1.209m다.
이 조합은 정렬 미완료와 부합한다.
그 자체로 이번 이동의 원인이나 조종 불능을 증명하지 않는다.
이를 해결하려고 이 문서가 더 높은 비행을 지시하지 않는다.
방위 기준 실측과 실내 시험 높이 정책을 함께 검토해야 한다.
