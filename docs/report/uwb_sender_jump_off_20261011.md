## 끄는 범위와 유지하는 검사

전달 단계의 변위 점프 거절만 선택적으로 우회한다.
PX4 자체 관측 검사까지 끄지 않는다.

```text
거리 원본 -> 기존 B_TF 계산·검사 -> 수평 좌표 변환
                                      |
                      전달기 점프 거절 OFF
                      원본 시각·중복·형식 검사는 ON
                                      |
                             PX4 ODOMETRY -> EKF
```

| 유지 항목 | 이번 처리 |
|---|---|
| B_TF·거리 입력의 기존 보호 | 유지. 원본과 선택 XY를 구분해서 기록 |
| 원본 stamp·150ms 신선도 | 유지 |
| 중복·역순·비정상 수치 | 거절 유지 |
| 공백 뒤 안정 수집 | 기존 획득·회복 시간 유지 |
| TIMESYNC·FC 파라미터·입력 독점 | 유지 |
| 새 시험 시작 | 최신 연결·DISARM·ON_GROUND가 있어야 전송 허용 |
| 정상 시동 뒤 | 위 지상 시작 승인 유지. 공중에서 자동으로 OFF하지 않음 |
| PX4 innovation 검사 | 유지 |
| 시계 초기화·다른 관측 세션 | 기존 보호 유지 |

설정은 시작할 때 읽는다. 공중에서 바꾸지 않는다.
이유: 전송 중단과 기준 변화가 생길 수 있다.
설정·재시작은 지상 DISARM에서만 수행한다.
구조화된 설정은 명시적인 boolean만 허용한다.
문자열 `"false"`나 숫자0은 거절한다.
