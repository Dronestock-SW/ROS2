# UWB 공백의 최소 추가 실측
정확한 위치와 시간 기준을 얻는 지상 절차다.
기존 공중 로그만으로 남은 원인을 못 나눌 때 읽는다.

## 먼저 할 일

다음 세 시험은 비행 없이 진행한다.
프로펠러를 제거하고 DISARM을 유지한다.
기체는 수평 받침대에 고정한다.
이유: 정해진 점과 높이를 반복해서 유지해야 한다.
FC·companion·태그의 관측 전원만 사용한다.
모터 명령이나 UWB→FC 융합은 이 시험에 필요 없다.

기존 앵커 좌표를 그대로 쓰려면 위치가 같아야 한다.
안테나 중심을 기준으로 A1–A4 XYZ를 대조한다.
본체 모서리나 바닥의 케이블 위치를 재지 않는다.
다른 높이의 앵커는 현재 H80 조건에 맞지 않는다.
Tag B=6, ROS_DOMAIN_ID=2를 사용한다.

## 1. 높이와 전달 주기: 한 점에서 90초

실제 높이 변화가 거리 불일치를 만드는지 확인한다.
아래 세 높이는 ToF 렌즈에서 평평한 바닥까지다.
ToF가 표시한 값을 기준 높이로 베끼지 않는다.
줄자나 레이저 거리계로 별도로 측정한다.
각 시험에서 태그 안테나 높이도 따로 기록한다.

| 시험 | 렌즈 높이 | 태그 수평 위치 | 기록 |
|---|---:|---|---|
| H1 | 약 0.30m | 같은 표시점 바로 위 | 정지 30초 |
| H2 | 약 0.80m | 같은 표시점 바로 위 | 정지 30초 |
| H3 | 약 1.30m | 같은 표시점 바로 위 | 정지 30초 |

실제로 맞춘 높이를 cm 단위로 적는다.
받침대는 ToF 시야나 UWB 안테나를 가리지 않는다.
안전한 고정이 안 되는 높이는 낮춰 기록한다.
이유: 흔들리는 받침대는 기준 측정이 아니다.

기록에서 다음 값을 비교한다.
- 실측 렌즈 높이와 ToF 오차.
- 앵커별 성공률·거리 편향·물리 거리 RMS.
- ToF 원본 시각·MAVLink 132·ROS 수신 간격.
- 높이 선택 성공 비율·B4/B3 선택·출력 공백.

40Hz 요청과 약 10Hz 실수신이 다르면 원인을 분리한다.
FC 센서 발행률과 MAVLink 발행률을 지상에서 대조한다.
기존 1Hz ULog만으로 센서 발행률을 확정하지 않는다.
100ms 만료 시간을 임의로 늘려 이 차이를 숨기지 않는다.
이유: 오래된 높이는 움직이는 기체의 높이와 다르다.

## 2. 실제 XY 오차: 세 점, 각 30초

태그 중심의 실제 XY를 알아야 거리 편향을 분리한다.
태그 중심에서 추를 내려 바닥 표시점에 맞춘다.
높이 H2를 유지한다. 기체 방향도 유지한다.
아래 위치는 6.3×4.6m 배치에서의 예시다.
측정 가능한 다른 세 점을 사용해도 된다.

| 점 | 예시 XY(m) | 용도 |
|---|---|---|
| P0 | (3.15, 2.30) | 기준·편향 후보 추정 |
| P1 | (4.15, 2.30) | 별도 X 방향 검증 |
| P2 | (3.15, 3.30) | 별도 Y 방향 검증 |

H2 기록을 P0로 사용하면 추가는 두 점뿐이다.
위치는 약속한 숫자 대신 실제 잰 값을 적는다.
줄자 해상도와 위치 오차 추정도 함께 적는다.
예: 각 좌표 ±1cm 또는 ±3cm.
P1/P2를 편향 맞추기에 함께 사용하지 않는다.
이유: 보정에 쓴 점으로 정확도를 주장할 수 없다.

정지점을 옮기면 [명시적 이력 초기화](btf_observation_session.md)를 쓴다.
설치 후 `observation_session` 번호와 응답을 남긴다.
이 단계는 독립된 정지 시험점이다.
이동 추적 시험 중에는 이력을 초기화하지 않는다.

출력은 다음처럼 분리해 계산한다.
- 기준점 대비 XY 오차: 평균 편향·RMS·P95·최대.
- 실측 XYZ에서 예상한 거리와 원시 거리의 차이.
- ToF 기반 거리 RMS와 H80 적합 RMS.
- 앵커 누락·후보 거부·출력 누락 시간.

같은 위치·높이에서도 A3/A4만 불안정하면 비교한다.
좌표는 고정하고 사람만 시야 밖으로 이동한다.
각 30초를 기록한다. 앵커를 옮기면 좌표도 다시 잰다.
이 비교는 최초 정지 시험에서 문제가 재현될 때만 한다.

## 3. 점프 보호와 시각: 지상 왕복 약 2분

거리 편향을 정리한 다음 실제 이동과 점프를 구분한다.
렌즈 높이 H2·기체 방향을 유지한다.
바닥에 0m·0.5m·1m 표시를 만든다.
받침대째 +X 1m 이동·정지·복귀를 두 번 한다.
이어서 +Y도 같은 왕복을 두 번 한다.
각 이동은 약 3초, 각 끝점 정지는 5초다.
이동 중 이력 초기화는 하지 않는다.

카메라를 바닥 표시와 태그 수직 기준이 보이게 고정한다.
동작 순서·실제 거리·움직인 시간을 기록한다.
이 기록은 축 방향·이동량·재획득 평가에 사용한다.
PX4 XY는 비교 대상으로 두며 정답으로 쓰지 않는다.

정확한 지연값 확정에는 공통 시각 사건이 필요하다.
영상에는 companion 화면의 단조 증가 시계를 함께 넣는다.
대신 하드웨어 트리거 LED와 원본 시각 기록을 써도 된다.
60fps라면 프레임 간격부터 약 16.7ms다.
화면 출력·촬영 지연을 포함한 불확실성을 기록한다.
수동 START 마커만으로 ms 단위 지연을 확정하지 않는다.
이유: 사람의 반응 시간이 센서 지연과 섞인다.
한 왕복으로 보정하고 다른 왕복으로 검증한다.
회전·원점·지연·잔차와 허용 불확실성을 함께 보고한다.
공통 시각 자료가 없으면 지연은 참고 추정으로 남긴다.

## 수집과 기록

기존 수집기를 유지하며 새 파일을 중복 생성하지 않는다.
시험 시작 전 `recording_active`와 토픽 증가를 확인한다.
service active만으로 기록 중이라고 판단하지 않는다.
저장공간 대기면 종료 로그를 PC 검증 백업 후 정리한다.
마커는 현재 수집 조각에 시작·종료를 각각 기록한다.

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=2 ROS_LOCALHOST_ONLY=1
systemctl --user status dronestock-manual-{observe,capture}.service
cat ~/.local/share/dronestock/manual-captures/status.json
ros2 run drone_uwb uwb_manual_capture status /absolute/path/to/capture-SESSION
ros2 run drone_uwb uwb_manual_capture mark /absolute/path/to/capture-SESSION \
  'P0_H2_BEGIN xy_measured lens_height_measured ref_sheet=trial01'
```

정확한 XYZ·높이·오차는 별도 측정표에 적는다.
예시 좌표나 높이를 실측 완료값으로 입력하지 않는다.
측정표·영상·원본·종료 manifest를 함께 보관한다.
원본은 Git에 올리지 않는다.

## 비행으로 남길 항목

위 시험을 통과한 뒤 비행 중 조건을 따로 확인한다.
진동·기울기·프로펠러·기체 차폐가 포함된다.
정지 호버와 가까운 X/Y 이동을 각각 기록한다.
이는 지상 기준점·시각 시험의 대체가 아니다.
UWB 관측 수정과 PX4 융합·자동비행 승인은 구분한다.
마지막 승인 위치 근처는 [연속 확인 후 복구](../architecture/btf_reacquisition.md)한다.
그 기준에서 멀어진 공백의 재획득은 실측 결과 뒤 결정한다.
