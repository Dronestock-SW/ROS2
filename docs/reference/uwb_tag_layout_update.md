# UWB 태그 앵커 좌표 갱신 — 이전 XY 펌웨어 이력
이 문서는 이전 태그 좌표 설정값 사전이다.
과거 XY 펌웨어와 당시 검산 절차를 대조할 때 읽는다.

현재 배치는 [6.3×4.6m 직사각형](uwb_anchor_layout.md)이다.
RAW 인계 태그는 좌표를 계산하지 않는다.
현재 좌표 설정은 companion에서 관리한다.
아래는 9월의 이전 XY 펌웨어에 대한 이력이다.

갱신 대상은 앵커 좌표다. 거리 교정값과 구분한다.
앞서 잰 앵커 사이 거리로 아래 좌표를 계산했다.
앵커의 실제 위치를 옮기는 작업은 아니다.

| 앵커 | x (m) | y (m) | z (m) |
|---|---:|---:|---:|
| A1 | 0.000 | 0.000 | 2.200 |
| A2 | 5.810 | -0.430 | 2.200 |
| A3 | 0.000 | 4.630 | 2.200 |
| A4 | 6.110 | 4.357 | 2.200 |

A1이 원점이다. +y는 A1에서 A3 방향이다.
+x는 그 방향을 볼 때 오른쪽이다.
불규칙 배치다. 직사각형 조건을 넣지 않는다.
이유: 실측한 여섯 거리가 기존 설정과 다르다.
계산 원본은 [앵커 실측값](uwb_anchor_survey.md)에 있다.

## 적용 경로 확인

현재 자료에는 USB 좌표 설정 명령이 없다.
명령이 없다고 단정한 것은 아니다.
지원 여부와 문법을 확인할 자료가 없는 상태다.

| 경로 | 필요한 것 | 현재 확인 |
|---|---|---|
| USB로 설정 갱신 | 펌웨어의 설정 명령·응답 규격 | 미확인 |
| 펌웨어 재빌드·업로드 | 소스, 보드 설정, 빌드 환경 | companion에서 소스 미발견 |
| companion에서 거리→x·y 계산 | 현재 RAW 거리, 실측 앵커 좌표 | 필요한 입력 확보 |

USB 케이블 연결만으로 임의의 설정을 쓸 수는 없다.
받는 펌웨어가 해당 명령을 해석해야 한다.
명령을 추측해서 전송하지 않는다.
이유: 적용 여부를 확인할 수 없기 때문이다.

## 태그에서 바꿀 항목

좌표 테이블을 갱신하고 배치 ID를 구분한다.

| 항목 | 요구 내용 |
|---|---|
| 앵커 순서 | A1, A2, A3, A4 유지 |
| 앵커 좌표 | 위 표의 x·y·z 반영 |
| 제안 배치 ID | `warehouse-irregular-z2p2-20260906` |
| 계산 방법 | 같은 높이의 거리 제곱 차로 x·y 계산 |
| RAW 거리 | 좌표 갱신 때문에 값을 바꾸지 않음 |
| 거리 교정값 | 이번 배치 갱신과 분리 |
| 검증 | RAW 거리로 재계산한 x·y와 태그 출력 비교 |

제안 배치 ID는 아직 태그에서 수신한 값이 아니다.
현재 수신 ID는 `warehouse-5x4p5-z2p2-v2`다.
태그 갱신 전에도 companion의 관측 계산은 가능하다.
비행용 센서 융합은 PX4 EKF2가 전담한다.
