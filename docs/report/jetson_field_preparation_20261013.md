# 13일 Jetson 현장 준비
실제 Jetson 빌드·입력·기록 검증 결과다.
오늘 저녁 웹 비행 시험을 준비할 때 읽는다.

## 현재 확인

Jetson SSH와 FC 읽기에 성공했다.
FC는 PX4 1.17.0, FMUv6C다.
현재 DISARM·AUTO.LOITER·지상 상태다.
조종기·앵커는 저녁에 켤 예정이라고 확인받았다.
RC는 0, UWB 거리 관측은 없다.
ToF는 0, 배터리 전압도 0이다.
FC 내부 EV 위치·광류 융합은 비활성이다.
이 상태를 비행 준비 완료로 처리하지 않는다.

| FC 읽은 값 | 현재 |
|---|---:|
| EKF2_EV_DELAY | 0ms |
| COM_OF_LOSS_T | 1초 |
| MIS_TAKEOFF_ALT | 1.7m |
| MPC_Z_VEL_MAX_UP | 0.5m/s |
| MPC_TKO_SPEED | 0.5m/s |
| MPC_Z_V_AUTO_UP | 0.5m/s |
| EKF2_EV_CTRL / OF_CTRL / RNG_CTRL | 1 / 1 / 1 |
| EKF2_EV_POS_X / Y / Z | -0.10 / 0 / -0.10m |

FC 파라미터는 쓰지 않았다.
비공개 템플릿은 실제 장착 기록의 -0.10m를 유지한다.
일반 예제의 -0.07m를 실제 기체에 복사하지 않는다.

## 추가 검증과 수정

Jetson ARM64 C++ 빌드와 ROS 4개 패키지가 성공했다.
웹·플랫폼 링크·C++·가상 FC에서 X, Y, XY 왕복이 END에 도달했다.
원래 출발점 복귀·착륙·DISARM도 모사 FC에서 확인했다.
이 결과는 실제 비행 성능을 증명하지 않는다.

후속 Python 정지 시험에서 LAND ACK가 누락됐다.
이전 기록만으로 fsync와 전달 문제를 확정하지 않는다.
초기 실패 기록을 별도 디렉터리에 보존했다.
추가 기록은 명령 준비·디스크 동기화·전달 시점을 구분한다.
LAND 전달이 디스크 동기화를 기다리지 않게 했다.
ARM·모드 진입은 기존처럼 기록을 먼저 확정한다.
FC가 AUTO.LAND로 바뀔 때까지 승인 목표 송신을 유지한다.
명령 전달의 중복 150ms 판단 만료 검사를 제거했다.
현재 FC·RC 권한과 ARM 전 새 관측 검사는 유지한다.

지상 웹 상태는 실제 FC 입력을 받았다.
출력 비활성·장비 미준비 상태가 정확히 차단됐다.
실행기 신원을 웹으로 전달하는 필드도 추가했다.
수정 후 재검증 결과는 아래에 이어 기록한다.

## EV_DELAY의 의미

현재 송신기는 B_TF 관측 header stamp를 쓴다.
이를 마이크로초로 바꿔 ODOMETRY.time_usec에 넣는다.
송신 순간의 현재 시각으로 덮어쓰지 않는다.
따라서 전체 통신 지연을 다시 EV_DELAY에 넣지 않는다.
실제 측정 시각과 stamp 사이의 잔여 오차를 구한다.
현재 B_TF는 timestamp_calibrated=false로 보고한다.
잔여 지연이 0이라고 실측한 상태도 아니다.

[PX4 설명](https://docs.px4.io/main/en/ros/external_position_estimation#tuning-ekf2-ev-delay)은
관측 stamp와 IMU 기준 실제 측정 시각의 차이를 설명한다.
단위는 ms이며 관측 만료 허용시간과 다르다.
저녁에 실제 UWB·FC ULog·연속 기록을 맞춘 뒤 정한다.
FC 값·관측 송신기·미션의 예상값을 함께 바꾼다.

## LiDAR SLAM 연결 경계

웹 미션 계약과 FC 명령 실행기를 분리한 구조를 유지한다.
추후 SLAM은 관측 어댑터에서 연결한다.
오늘의 입력 계약은 B_TF와 uwb_map이다.
SLAM을 지금 대체 센서로 승인한 상태는 아니다.

| 계층 | 후속 SLAM 통합 조건 |
|---|---|
| 관측 어댑터 | 원래 stamp, 좌표계, 공분산, 출처, reset 번호 |
| 좌표 정렬 | SLAM map과 앵커 좌표의 변환·부팅 신원 |
| FC 관측 송신 | 단일 송신기, 측정 시각 보존, EV 파라미터 일치 |
| 미션 판단 | FC 추정과 독립 관측을 구분, 공백 때 승인 목표 유지 |
| 웹·기록 | 출처와 상태를 전달, 관측 바뀜을 숨기지 않음 |

기존 FC 추정 위치를 독립 SLAM 관측으로 재사용하지 않는다.
LiDAR 연구 브랜치와 현재 센서 서비스의 변경 파일은 보존했다.
