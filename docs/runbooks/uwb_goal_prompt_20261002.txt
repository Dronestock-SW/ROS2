기존 동작과 이번 목표
- 기존 호버링은 “FC가 센서값을 받아 스스로 위치를 유지한 상태”로 설명해. 조종자가 Position 모드를 선택했고, 그 안의 위치 유지 계산과 제어는 FC가 수행했다.
- 기존 로그에서 확인한 광학흐름·하방 거리 융합과 Position 유지가 비교 기준이다. 해당 로그의 파일·시행·설정·센서 융합·비행 모드·위치 유지 구간을 확인해 재현 근거로 연결해.
- 호버링 제어는 기존 FC 기능을 이어서 사용해. 이번 목표는 UWB 현재 위치 공급과 목표 좌표 명령을 연결하고 그 결과의 이동·정지·복귀 정확도를 검증하는 것이다.

| 이미 되는 부분 | 이제 연결할 부분 |
|---|---|
| 센서값을 FC가 받아 위치 유지 | UWB 위치를 앵커 지도 좌표에 맞춰 FC에 제공 |
| 현재 위치에 머무르기 | 지정한 목표 좌표를 FC에 전달 |
| PX4의 기존 비행제어 | 이동·정지·복귀가 정확한지 검증 |

데이터와 제어 흐름
UWB + 필요한 보조기능 → 보정된 현재 위치 관측 → FC
지정한 목표 좌표 → 목표 명령 → FC
FC의 기존 위치제어 → 이동 → 감속 → 정지·유지 → 복귀

- LiDAR는 현재 위치를 더 잘 파악하도록 돕는 보조 후보다. 기존 하방 거리 센서의 사용 상태를 기록하고, LiDAR를 추가하거나 활용 범위를 바꿀 때는 필요성과 측위 개선 효과를 비교 평가해. LiDAR 채택 여부는 측위·가용률·지연과 FC 연결 검증 결과로 결정해.
- 기존 호버링 로그의 FC 동작과 새 SITL에서 UWB 관측·목표 명령을 연결한 결과를 구분해. 기존 Position 유지 근거만으로 새 UWB 융합·목표 이동을 완료 처리하지 마.

진행 순서
1. 현재 프로세스·버전·월드·모델·토픽·메모리·로그·UDP 수신기를 확인하고 같은 Python의 결합 import를 검사해. 기존 호버링 로그의 광학흐름·하방 거리 융합과 Position 유지 구간을 FC 동작의 비교 기준으로 정리해. 기존 로그와 현재 SITL의 센서·융합·모드 차이를 기록해.
2. 정상 가상 RAW·ToF·IMU·Gazebo 시계·정답과 PX4 상태·파라미터·시계 응답을 같은 세션에서 기록해. 입력 수·순서·신선도·실제 갱신률·높이 판정 사유와 누락을 읽어.
3. 장착 기준점, ToF 광축과 바닥면, 자세 기준축, 지도와 PX4 좌표 정렬, 공분산, 시각 대응과 reset 처리를 검증해. 검증하지 않은 값을 true로 바꿔 관측을 보내지 마.
4. 앵커 지도에 맞춘 현재 위치를 A 관측으로 FC에 실시간 제공하고 EKF2 융합을 먼저 확인해. 메시지 수신뿐 아니라 실제 사용·기각·innovation·reset과 vehicle_visual_odometry 측정시각을 ULog/uORB로 대조해. GNSS·광학흐름·하방 거리 등 기존 센서의 실제 사용 상태와 영향을 기록해.
5. A/B/C/D를 동일한 RAW·지도·교정·높이·평가 시각으로 비교해. 기존 B 0.8초 설정을 보존하고 B H80 0.4초는 동적 시험 후보로 평가해. 관찰한 실패 원인에 맞는 보조기능 또는 파라미터 하나씩 바꾸고 A·직전 채택 구성·새 구성을 비교해. LiDAR 보조 후보도 필요성이 확인되면 같은 방식으로 평가해. M03 등의 과거 기각을 근거 없이 되돌리지 마.
6. 교정·조정과 최종 평가의 위치·궤적·시드를 분리해. 독립 다점 정지, 축별 이동·정지·반전·단절·복구에서 측위 오차와 가용률·지연을 확인해. 평가 결과로 조정했다면 그 자료를 조정 자료로 바꾸고 새로운 독립 자료로 재평가해.
7. 관측 융합을 확인한 뒤 FC가 공중에서 위치를 유지하는 준비 상태를 확보해. 현재 실행기는 시동·이륙을 수행하지 않으므로 기존 PX4 시동·이륙 절차와 실제 준비 상태를 확인해. 그다음 지정한 목표 좌표를 FC에 전달하고 기존 FC 위치제어로 짧은 목표 이동·감속·정지·유지·순회·복귀·착륙과 이상 대응을 시험해. 목표 명령에 필요한 비행 모드와 전환 절차는 SITL에서 확인하고 기존 Position 호버링과 새 목표 명령 시험의 모드·관측 조건을 기록해. 도착 판단에는 PX4 위치·속도 유효성, 입력 신선도, 연속 유지시간을 모두 적용해.

완료 기준
A. 측위 완료: 잠근 구성의 독립 다점·동적 평가에서 유효한 새 UWB 관측의 최대 수평 오차가 0.07m 미만이어야 한다. 공통 표본 비교와 전체 평가 시각을 분모로 한 가용률, 지연, 최대 공백, 거부·누락·복구 시간을 함께 통과해야 한다. 가용률·지연 기준이 명세에 미정이면 평가 전에 SITL 시험 기준을 설정 파일과 manifest에 고정하고 최종 판정까지 완화하지 마.
B. 연결 완료: 보정된 UWB 현재 위치가 앵커 지도·FC 좌표·기준점·시각·불확실성 검증을 거쳐 실제 EKF2에 융합된 근거가 있어야 한다. 기존 광학흐름·하방 거리 융합의 Position 유지와 새 UWB 융합을 각각 기록해. 다른 위치원만으로 유지된 비행을 UWB 융합 검증으로 집계하지 마.

D. 독립 평가: 기존 호버링 로그를 FC 동작의 비교 기준으로 활용하고 새 UWB 연결·목표 명령의 결과를 별도 시행으로 평가해. UWB-정답 측위 오차, PX4-정답 추정 오차, PX4-목표 추종 오차, 정답-목표 실제 이동·도착 오차를 구분해. 정지·합성·파일 재생·모의 통신·실제 물리 비행의 근거 범위를 각각 표시해.
