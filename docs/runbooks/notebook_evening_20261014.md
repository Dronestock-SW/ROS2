실제 수직 이륙·좌표 안정화 성공은 아직 보장하지 않는다.

이 명령은 터널만 열며 서비스·비행을 시작하지 않는다.

```powershell
ssh -o ExitOnForwardFailure=yes -L 8001:127.0.0.1:8001 -L 8002:127.0.0.1:8002 arialhanho@100.110.163.94
```

웹 실행 준비 후 `http://127.0.0.1:8001`을 연다.
포트가 사용 중이면 기존 터널을 확인한다.
서로 다른 실행본을 중복 실행하지 않는다.
