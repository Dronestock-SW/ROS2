## 짧은 실물 시험과 해석

**RAW 통신은 확인했지만 위치 성능은 아직 검증하지 않았다.**
직접 UART 30초에 1,500 RAW를 수신했다.
모두 네 거리의 valid_mask가 15였다.
관측된 LoRa TX-done 누적값은 53이었다.
이는 실제 지상국 수신 확인이 아니다.

첫 시각 교환의 지연 상한은 8ms였다.
실제 왕복 지연 대부분은 약 8.7~9.8ms였다.
116개 응답 중 114개가 이 기준으로 거부됐다.
요청·응답 직렬화 시간을 포함한 실측값이다.
응답 수용 상한을 12ms로 바꿨다.
시각 불확실성 허용값은 5ms로 유지했다.
왕복별 offset 허용 구간의 교집합을 사용한다.
같은 기록에서 초기 3회 후 113회가 준비 상태였다.
추정 불확실성은 약 4.22~4.35ms였다.
이 값은 독립 기준시계로 검교정한 정확도가 아니다.

실제 수신 서비스의 12초 예비 기록도 확인했다.
RAW·변환된 RAW·B_TF 발행은 약 50Hz였다.
이 짧은 발행률은 위치 정확도 근거가 아니다.
실제 거리는 약 1.1~1.3m로 모여 있었다.
기존 6.3×4.6m 배치와의 일치는 확인되지 않았다.

schema 2 위치를 발행하지 않도록 차단했다.

## 수집 경로와 입력 부하 수정

**수집 손실과 태그의 송신 정체를 별개로 확인했다.**

수집기 손실·파일 오류를 별도로 기록한다.
직렬 폴링도 전용 스레드로 옮겼다.

## 앵커 중단·복구 경로

**CPU 중단 시험으로 SPI 오류 복구 누락을 발견했다.**
각 앵커 CPU를 J-Link로 8초씩 정지했다.
이 시험은 앵커 전원을 끄지 않는다.
A1·A3은 실행 재개 뒤에도 응답이 돌아오지 않았다.
A2·A4는 복구했고 LoRa 전송은 계속됐다.
따라서 첫 앵커 중단 시험은 실패다.

실물 RAM에서 SPI 오류 래치를 읽었다.
A1·A3은 `transfer_failed=1`이었다.
정상 응답 중인 A2는 0이었다.
기존 드라이버는 DMA 시간 초과를 잠근다.
응용 계층이 그 상태를 읽는 경로가 없었다.
레지스터 읽기 실패도 상위 코드에 전파되지 않았다.

앵커 R2는 SPI 오류를 직접 검사한다.
오류 때 SPI와 DW3000을 다시 초기화한다.
실패한 읽기 버퍼는 0으로 지운다.
과거 바이트를 새 RF 상태로 해석하지 않기 위해서다.
RF 세션·거래 순번 기록은 복구 중에도 보존한다.
네 역할 빌드와 전체 readback 검증이 통과했다.
