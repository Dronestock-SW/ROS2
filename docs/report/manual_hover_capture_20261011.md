## 후속: 45cm 변화의 계산과 관측 원인

계산은 재현됐다. 실제 XY 정확도는 미확정이다.
사용자는 실제로 45cm 이동하지 않았다고 보고했다.
외부 기준점의 연속 실측은 이 기록에 없다.

ROS monotonic 1630~1705초를 분석했다.
발행 좌표 2,961개 모두 `unchanged_B4`였다.
각 결정의 `obs_ids`로 원본 거리·시각을 복원했다.
누락 없이 동일 설정으로 H80을 다시 계산했다.
기록 대비 최대 차이는 7.24e-15m 미만이었다.
원시 XY 차분식도 3.62e-15m 미만으로 재현됐다.
이는 수치 재현성이다. 위치 정확도의 증거는 아니다.

처음과 마지막 5초의 중앙값을 비교했다.

높이를 반영하면 거리 입력 간 불일치가 드러났다.
높이 유효 발행 표본 2,770개를 따로 계산했다.
B4 XY와 각 앵커 측정 시각의 높이를 사용했다.
계산한 기하 거리에서 관측 거리를 뺐다.
4개 거리 RMS의 중앙값은 0.134m였다.
p95는 0.155m, 최대는 0.173m였다.
앵커별 잔차 중앙값은 모두 양수였다.

이를 독립 XY 오차나 확정 보정값으로 쓰면 안 된다.
입력 높이·배치·거리 중 무엇이 틀렸는지는 미확정이다.

B4는 높이 공통 항을 자유롭게 적합한다.
