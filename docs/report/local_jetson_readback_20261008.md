## FC 전체 설정과 어제 값의 대조

표준 파라미터 1,095개를 모두 수신했다.
인덱스 0~1,094의 누락·중복 없음을 확인했다.
별도 `_HASH_CHECK`까지 메시지 항목은 1,096개다.
두 수의 단위가 다르므로 구분한다.

MAVLink 원본 프레임도 보존했다.
1,096개 값의 형식·바이트 복호화를 다시 대조했다.
초기 수집기의 payload 오프셋 오류를 수정했다.
초기 결과는 제외하고 새 조회본을 사용했다.
완료 판정에서도 `_HASH_CHECK`를 별도로 세었다.
[파라미터 프로토콜](https://mavlink.io/en/services/parameter.html)을 따른다.

| 항목 | 어제 최종 직접 조회 | 오늘 직접 조회 | 웹 기본값과의 관계 |
|---|---:|---:|---|
| `MIS_TAKEOFF_ALT` | 약 1.3m | 1.2999999523m | 웹 기대값 0.6m와 다름 |
| `COM_RC_OVERRIDE` | 2 | 2 | 자동 모드 스틱 인계 미활성 |
| `EKF2_EV_CTRL` | 1 | 1 | 허용 설정만 같음. 실제 융합 미검증 |

추가 설정은 다음과 같다.
값의 의미는 PX4 1.17 공식 정의와 대조했다.
설정만으로 실제 상실 대응을 검증하지 않았다.

| 항목 | 현재 값 | 의미 |
|---|---:|---|
| `EKF2_EV_DELAY` | 0ms | 물리 지연 교정 완료를 뜻하지 않음 |
| `EKF2_EV_NOISE_MD` | 0 | 메시지 공분산 사용 설정 |
| `EKF2_EV_POS_X/Y/Z` | 모두 0 | 장착 실측값 확정 아님 |
| `EKF2_HGT_REF` / `EKF2_RNG_CTRL` | 0 / 1 | 현재 값 보존 |
| `EKF2_OF_CTRL` | 1 | 설정 확인. 실제 융합 검증 별도 |
| `COM_RC_IN_MODE` | 3 | 첫 유효 RC/MAVLink 입력 유지 |
| `COM_RC_STICK_OV` | 30% | 스틱 인계 기준 |
| `RC_MAP_FLTMODE/ARM_SW/KILL_SW` | 5 / 8 / 7 | 채널 동작은 전원 켠 뒤 확인 |
| `COM_RC_LOSS_T` / `NAV_RCL_ACT` | 0.5s / 3 | RC 상실 시 Land 설정 |
| `COM_DL_LOSS_T` / `NAV_DLL_ACT` | 10s / 0 | GCS 상실 대응 비활성 |
| `COM_LOW_BAT_ACT` | 0 | 배터리 경고 설정 |
| `COM_DISARM_LAND` | 2s | 착륙 후 자동 disarm 설정 |

근거: [PX4 1.17 파라미터 정의](https://docs.px4.io/v1.17/en/advanced_config/parameter_reference).
`COM_RC_OVERRIDE=2`는 Offboard 인계 비트만 켠다.
자동 이륙·착륙 중의 실제 RC 인계는 미검증이다.
`NAV_DLL_ACT=0`에서 통신 상실 자동 착륙을 가정하지 않는다.
이유: 해당 GCS 상실 대응 자체가 꺼져 있다.

어제 전체 파일은 세 값 변경 전 기록이다.
그 파일에는 표준값과 `_HASH_CHECK`가 함께 있다.
세 값의 재부팅 후 직접 조회는 별도로 존재한다.
이를 합친 비교 기준은 재구성 값임을 표시했다.
완전한 재부팅 후 전체 스냅샷으로 부르지 않는다.

| 비교 기준 | 현재와 다른 공통 파라미터 |
|---|---:|
| 어제 변경 전 전체 파일 | 14개 |
| 전체 파일 + 최종 직접 조회 3개 반영 | 11개 |

11개는 가속도계 보정값 6개·자력계 보정값 3개다.
나머지는 `COM_FLIGHT_UUID`와 `COM_FLTMODE4`다.
`COM_FLTMODE4`는 2(Position)에서 7(Offboard)로 다르다.
변경 주체·시각·이유는 이번 조회로 확정하지 못했다.
`COM_FLIGHT_UUID` 차이로 성공 비행 횟수를 추정하지 않는다.

## 통합 전에 보존할 계약

오늘 웹 코드를 현재 Jetson에 바로 적용하지 않았다.
다음 차이를 함께 처리해야 한다.

| 경계 | 어제 통합 | 오늘 웹 | 통합 조건 |

| 태그·배치 선택 | A/B, domain 1/2, 낮은 B 설정 | Tag A 기본 파일 고정 | 실제 태그·배치에 맞는 동일 선택 |
| 거리 시각 | TDMA·각 거리 원본 시각 | main 기반 경로 | TDMA·sideband·재시작 처리를 보존 |
| B_TF | 입력 시각·검사 강화 | 같은 시각 XYZ·높이 요구 | 두 변경을 함께 보존 |
| PX4 bridge | 배치·domain·TIMESYNC·발행자 검사 | 최신 관측 stamp·10Hz 상태 | 기존 보호 조건과 최신성 유지 |
| 장착값 | FRD 필드와 1mm 비교 | 별도 필드와 1cm 비교 | 측정 기준과 하나의 설정 계약 확정 |
| 웹 관측 | UWB/B_TF/PX4 입력 선택 | 미션 전달·단계 보고 | 출처·좌표·시각 구분 유지 |
| 명령 주체 | C++ BT + 미커밋 hover | Python 웹 FSM | 실제 PX4 writer 단일화 |

Tag B의 장착·바닥·배치 확인값은 false다.

이 값을 임의로 true로 바꾸지 않았다.
