## 4. WBS: 초기안 대비 재설계안

### 4.1 초기 WBS 문서의 소재 — 미확인

**저장소에 초기 8주 WBS 문서가 없다.** `git log --diff-filter=A` 전수 조회 결과, WBS 파일이
추가된 이력 자체가 없다.

확인 방법:

```bash
git log --all --pretty=format: --name-only --diff-filter=A | sort -u   # WBS 파일 없음
git log --all --pretty=format:'%s' | grep -oE 'W[0-9]+-[0-9]+' | sort -u
```

따라서 아래 4.2의 초기안은 **저장소에 남은 간접 근거로 역산한 것**이며, 원본 WBS의 완전한 태스크
목록이 아니다. 원본은 저장소 외부(문서 도구·메신저 등)에 있을 것으로 보이나 **미확인**이다.
