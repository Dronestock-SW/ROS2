# UWB 기능별 커밋 전 통합 확인

기능별 변경 범위와 남은 일을 이어받을 때 읽는다.

2kg은 가상 비교값이다. 실측 총질량은 미확정이다.

## 남은 작업

비행 적용과 최종 모델 선정은 완료 범위 밖이다.

| 항목 | 후속 확인 |
|---|---|
| 동적 실측 평가 | 동시 UWB·거리·자세와 독립 위치 기준 확보 |
| 센서 입력 연결 | 시계 대응·장착 높이·좌표 변환 확인 |
| C/D 확장 | 후보 품질 가중·반지름 확장 비교 |
| WLS 실측 적용 | 거리 오차 공분산 추정·공유 오차 처리 |
| Gazebo 실행 | GUI·센서별 수신·가상 RAW 발행 확인 |
| PX4 연결 | 관측 융합·UWB 기반 비행 별도 검증 |

기존 외부 전달 게이트는 닫힌 상태다.
