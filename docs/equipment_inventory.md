2026-09-20에는 TFmini Plus를 다른 드론에서 사용 중이었다.
2026-10-04 사용자는 ToF 실측 가능을 확인했다.
1호기 토픽·장착·PX4 융합 검증 완료를 뜻하지 않는다.
PMW3901의 마지막 확인 상태는 미입고다.
프레임은 기존 기록상 외주 진행 중이다.
현재 프레임 납기는 다시 확인해야 한다.

카메라는 반드시 CAM0에 꽂는다 (2026-08-12 확인).
이유: 현재 device tree 오버레이는 카메라 모듈을 module0 하나만 정의한다.
CAM1에 꽂으면 /dev/video0 이 안 뜰 수 있고, 2호기에 같은 코드를 배포해도 카메라만 동작하지 않는다.
확인값: `imx219 9-0010` (i2c 버스 9, 주소 0x10), badge `jakku_front_RBP194`, position `front`.
확인 명령: `ls /dev/video*` 와 `media-ctl -p | grep imx219`

## 운용 원칙 (군집 관련 확정사항)

- 드론 2대는 사전 구역 분할로 운용 (동적 할당 아님). 구역이 달라 드론 간 충돌 회피 불요
- 드론 간 통신 없음. 각 드론은 독립 시스템이며 지상국과만 LoRa로 통신
- 2호기 조립은 1호기가 Phase 3(마커 정렬)까지 검증된 후 착수

## 2026-09-06 실물 확인 갱신

TFmini Plus·PMW3901은 아직 없다.
사용자는 다음 주 입고 예정이라고 확인했다.
기존 BOM의 보유 표시는 이 확인으로 대체한다.
배선·포트 지정·드라이버 활성화는 입고 후 진행한다.
이유: 실제 연결 없이 수신 여부를 검증할 수 없다.

태그와 Pixhawk는 현재 따로 놓고 시험 중이다.
같은 기체에 고정할 예정이다.
예정 위치는 Pixhawk 위 약 30cm다.
앞으로는 약 5~7cm다. 좌우 차이는 미확인이다.
이 값은 장착 전 대략값이다.
고정 후 안테나 기준으로 다시 측정한다.
[작업 중단 기록](report/uwb_integration_20260906.md)을 따른다.

최종 구성은 Pixhawk와 같은 기체에 고정한다.
마지막 사용자 확인 때는 따로 놓고 시험 중이었다.

| 방향 | 사용자 근사값 |
|---|---:|
| Pixhawk보다 위 | 약 30cm |
| Pixhawk보다 앞 | 약 5~7cm |
| 좌우 | 미확인 |

고정 후 안테나 기준점으로 다시 측정한다.
이 값은 FC에 적용한 장착 위치 설정이 아니다.

## 2026-09-20 TFmini Plus 확보 갱신

TFmini Plus는 확보했고 다른 드론에서 사용 중이다.
사용자는 이후 1호기로 옮길 예정이라고 확인했다.
위 2026-09-06의 미입고 기록은 과거 상태다.
다른 드론의 배선·장착값을 1호기에 확정 적용하지 않는다.
이유: FC와 센서 사이의 위치·광축이 달라질 수 있다.
1호기에서 거리 수신과 측정시각을 확인한다.
새 장착값으로 UWB 선행 필터를 검증한다.

## 2026-09-27 사용자 장착 위치 확인

이번 회신의 수평 위치로 과거 예정치를 갱신한다.
기체 중심과 질량중심의 일치는 아직 미확인이다.

| 장비·항목 | 사용자 보고 |
|---|---|
| FC | 기체 중심에서 전방 14cm |
| UWB 안테나 | 기체 정중앙 |
| ToF | 기체 정중앙, 아래를 향함 |
| LiDAR | 기체 중심에서 전방 14cm |
| 질량 | 대략 2kg 이하 |
| 센서별 높이·카메라·광학흐름 위치 | 이번 회신에서 미확인 |

UWB는 FC보다 수평으로 14cm 뒤에 있다.
과거 앞 5~7cm 예정치를 재사용하지 않는다.
위·아래 장착 거리는 수평 위치와 구분한다.
모터 물리 추력은 이번 회신에 없다.
사용자가 지정한 27일 로그에는 정규화 추력 명령이 있다.
[가상 장비 구성·추력 검토](report/uwb_gazebo_equipment_20260927.md)를 따른다.
