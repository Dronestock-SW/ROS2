## 높이와 UWB 공백

중립 75초 구간의 중앙값은 1.04m였다.
이는 센서에서 바닥까지의 거리다.
FC 높이나 UWB 안테나 높이와 혼용하지 않는다.

모드 전환이나 수집 조각 사이의 공백은 제외했다.

## yaw와 센서 간 차이

중립 호버의 목표 yaw는 일정했다.

| 항목 | 값 |

| FC 추정 yaw | 약 80.776~83.054° |
| yaw 스틱 | 약 -0.002. 중립 오차 수준 |
| yaw 목표 이동률 | 사실상 0 |

| 선택 EKF의 mag fault·yaw reject | 0 |

명령이 계속 yaw 목표를 돌린 증거는 없다.
그렇다고 외부 기준의 실제 방위가 고정됐다고 단정하지 않는다.
위 상태 플래그는 후속 방위 검증 대상으로 남긴다.

ROS 중립 구간 75초의 XY 변동 폭은 다음과 같다.
PX4: X 0.086m / Y 0.088m.
UWB: X 0.179m / Y 0.454m.
두 좌표계의 축·원점은 아직 일치시킨 상태가 아니다.
각 좌표의 변동만 비교한 값이다.

같은 LiDAR 스캔을 강체 정합한 예비 결과도 보존했다.
첫 스캔 대비 약 0.30m·12.2° 차이가 나왔다.
잘린 잔차 RMS는 약 0.052m였다.
장착·deskew·공분산·3D 자세 보상을 검증하지 않았다.
따라서 실제 이동량이나 yaw 정답으로 사용하지 않는다.
FC와 LiDAR가 다르게 보인다는 후속 조사 근거다.

공중 LiDAR 기록에는 광선 시각이 있었다.

time_increment는 약 0.000250초였다.
해당 표본에서 두 시각 필드가 0인 경우는 없었다.
초기 지상 시작 표본의 0값과 구분한다.
시각의 의미·축 방향 실측은 여전히 남는다.
