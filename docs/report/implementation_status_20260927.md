# 구현 현황과 Position 호버링 보고 — 2026-09-27

비행·UWB·임무 구현의 현재 범위를 정리한 기록이다. 다음 통합 작업과 검증 항목을 정할 때 읽는다.

## 현재 도달한 단계

**수동 Position 호버링 성공과 UWB 오프라인 보정 시험까지 진행했다.**
호버링 성공은 이번 사용자 보고를 반영했다.
UWB 수신과 A 계산은 저장소 코드·시험 기록으로 확인했다.
이번 호버링에 UWB가 쓰였는지는 아직 확인하지 못했다.
후속 API 조사에서 9월 26일 파일의 모드·융합 설정을 읽었다.
그 파일은 `ALTCTL`, 외부 위치 융합 꺼짐 상태였다.
보고된 Position 성공 시험과 같은 로그로 취급하지 않는다.
[파라미터 API와 추출 근거](../uwb_mavros_parameter_api.md)를 참고한다.

```text
비행 기반
  수동 Position 호버링 성공 [사용자 보고]
                          |
                 사용한 위치 입력 확인 필요

UWB 개발
  RAW 수신·기록 [완료]
       -> 편향 차감·A 파일 계산 [시험 완료]
       -> ToF·자세 동시 실측 연결 [남음]
       -> 보정 결과의 실시간 출력 연결 [남음]
       -> PX4 융합·비행 성능 확인 [이번 보고와 연결 미확인]

자동 임무
  도착·공백·복구 상태 판단 데모 [구현]
       -> 실제 이동·정지·임무 비행 연결 [남음]
```

## 항목별 구현과 검증

코드가 있는 것과 비행에서 검증한 것을 구분한다.

| 항목 | 구현·확인한 범위 | 남은 범위 |
|---|---|---|
| 수동 Position 호버링 | 사용자 성공 보고 | 위치 입력·시험 조건·로그 연결 확인 |
| UWB 수신 노드 | RAW 거리 수신, 입력 검사, `/uwb_pose` 발행. 지상 수신 기록 있음 | 새 보정 결과를 실시간 경로에 연결 |
| 파일 파이프라인 | 입력·시각·편향·거리 게이트·이력·센서 버퍼·진단 기록 | 통합 좌표 계산·외부 전달 게이트는 닫힘 |
| A 위치 계산 | 별도 파일 실행기. 합성·실측 정지 로그 계산 완료 | 동적 실측·여러 위치·실시간 연동 검증 |
| ToF·자세 기반 Z | 기하 함수·입력 선택·합성 시험. ULog 거리·자세 추출 | 동시 UWB와 시간·장착·좌표 연결 |
| H80·Q_S10 | 독립 수식 함수 존재. H80 제한 합성 샘플 확인 | 이번 실측 A와 비교·모델 선정·운용 연결 |
| 앵커 조합·중간 교점·추가 가중치 | 기능별 입출력·설계 명세 작성 | 모델 구현과 비교 시험 |
| UWB→PX4 브리지 | 좌표 변환·검사·전달 코드 존재 | 실제 기체의 사용 여부·융합 성능 확인 |
| 자동 임무 | 도착·입력 공백·복구 상태 판단 데모 | 실제 비행 명령과 자동 임무 검증 |

기존 수신 노드와 새 파일 계산기는 다른 실행 경로다.
파일 계산기의 성공이 수신 노드에 자동 반영되지는 않는다.
비행 추정·자세 제어는 PX4 EKF2·PX4의 역할로 유지한다.

## Position 호버링 보고의 근거

사용자가 성공했다고 알려준 항목을 완료 이력에 추가했다.

| 항목 | 기록 |
|---|---|
| 보고일 | 2026-09-27 |
| 사용자 보고 | “수동 비행 검증에서 position 모드를 통한 호버링 구현을 성공한상태.” |
| 완료 반영 | 수동 Position 모드 호버링 |
| 실제 시험일·장소·기체 | 이번 메시지에 미기재 |
| 호버링 시간·위치 편차 | 수치 미제공 |
| 사용 위치 입력 | 아직 확인하지 못함 |
| 이번 성공과 연결된 비행 로그 | 이번 확인에서 대조하지 않음 |
| 9월 26일 ULog와의 관계 | 동일 시험이라고 확인하지 않음 |

이 보고만으로 특정 센서의 융합을 완료 처리하지 않는다.
어떤 위치 입력으로 호버링했는지에 따라 검증 범위가 달라진다.
Phase 1의 자동 이동·정지·임무 완료 판정도 별도로 유지한다.

## A 시험에서 확보한 기준

실측 정지 기록으로 편향 후보의 효과를 확인했다.

| 시험 | 결과·한계 |
|---|---|
| 합성 10초 | 400회 중 371개 위치. 처음 29회 시간축 준비 |
| 실측 정지 평가 | 2,540회 모두 계산. 별도 1차 로그에서 편향 후보 산출 |
| 전체 수평 차이 RMSE | 24.91cm → 10.70cm |
| 가림 보고 구간 RMSE | 50.70cm → 42.26cm |
| 기준점 | 당시 수기 기록. 독립 검증되지 않은 한 지점 |
| 최근 UWB 검증 | 9월 26일 pytest 66개·빌드·재생 통과 |

[A 합성 기록](uwb_baseline_a_20260926.md)과
[실측 정지 A 기록](uwb_baseline_a_static_20260926.md)에 근거를 보존했다.
위 수평 차이는 비행 중 위치 유지 오차가 아니다.
이번 수동 호버링의 성능 수치로 사용하지 않는다.

## 다음 통합 작업의 순서

이번 호버링의 위치 입력을 확인한 뒤 연결 범위를 정한다.

| 순서 | 작업 | 완료 판단 |
|---|---|---|
| 1 | 성공한 호버링의 센서·설정·로그 연결 | 사용한 위치 입력을 구분할 수 있음 |
