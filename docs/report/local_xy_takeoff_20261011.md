# 앵커 로컬 이륙 중 밀림 분석
2026-10-11 실행 4의 실제 FC ULog 분석이다.
다음 이륙 전에 센서 동작과 미확인 원인을 볼 때 읽는다.

## 확인 결과

사용자는 +X·-Y 방향 밀림과 RC 개입을 보고했다.
광류를 비활성화한 이륙은 아니었다.
사용 중 EKF 인스턴스 1의 실제 광류 융합을 확인했다.

중단 후에도 광류 융합은 유지됐다.
RC 인계 이후 실행기는 위치 명령을 중단했다.
이 비행은 XY 경유지 이동 단계에 진입하지 않았다.

이륙 중 XY 목표 변화폭은 두 축 모두 0m였다.
명령 좌표가 옆으로 이동한 증거는 없다.

같은 시점 EV 위치 innovation은 N +0.030m, E -0.157m였다.
이는 관측과 EKF 예측의 차이며 실측 이동 정답이 아니다.
사용자가 본 밀림 전체 거리를 이 값으로 단정하지 않는다.
