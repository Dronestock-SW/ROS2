# 고도(z) 처리 원칙

고도의 측정·제어 책임을 정하는 기준이다.
고도 입력이나 데모 값을 연결할 때 읽는다.

## 현재 기준

2026-10-14 수신 분리 패치에서도 ToF 100ms를 유지한다.
IMU 시간차 20ms·장착·평면 바닥 조건도 유지한다.
120·150ms는 [파일 재생 비교](report/btf_sensor_timing_20261014.md)에만 적용했다.
[100/50/50Hz 기준](architecture/tof_100_50_50.md)의 코드 수정을 승인받았다.
실물 주기·지연은 미검증이다. 재생·배포는 보류한다.

드론 고도에는 실측 센서를 사용한다.
2026-10-04 사용자가 ToF 실측 가능을 확인했다.
공용 데모의 사인파 고도는 제거했다.
측정이 없으면 가상값이나 고정 높이로 대체하지 않는다.
이유: 생성한 값은 드론의 현재 높이를 나타내지 않는다.

1. UWB는 x·y 수평 위치를 제공한다.
   `/uwb_pose.z=0`은 메시지의 미관측 자리값이다.
2. 고도는 TFmini Plus와 Pixhawk IMU/EKF가 담당한다.
   PX4의 고도 융합·제어 책임을 유지한다.
3. companion은 z를 직접 제어하지 않는다.
4. 비행용 z 유효성 검사는 추가하지 않는다.
   `virtual_wall_node`의 기존 TODO를 유지한다.

## 측정값과 좌표의 구분

2026-10-12 사용자 지시로 다음 원칙을 고정한다.
측정하지 않은 수직 속도를 0으로 채워 전달하지 않는다.
큰 분산도 미관측을 뜻하는 대체 수단으로 쓰지 않는다.
이유: PX4가 이를 수직 관측·리셋 값으로 쓸 수 있다.
수평 LiDAR는 실제 관측한 두 성분만 전달한다.
수직 미관측을 표현하지 못하는 3축 경로는 채택하지 않는다.
NaN의 허용 여부도 수신 경로의 계약으로 확인한다.
과거 `vz=0` 실험은 실패 재현 기록으로만 보존한다.
[2D 비교 결과](report/lidar2d_height_outage_20261012.md)를 따른다.
아래 XY 위치 메시지의 z 자리값 예외와 구분한다.

2026-10-09 사용자는 지상 참조 표시를 요청했다.
명시한 `ground_antenna_height_m=0.15`를 사용한다.
최신 FC 연결·ON_GROUND일 때만 적용한다.
ARM 상태여도 지상 판정이면 표시할 수 있다.
실측 ToF가 없을 때의 안테나 설치 높이 추정이다.
`current_z_trusted=false`, `xyz_valid=false`를 유지한다.
공중·이륙·착륙·상태 만료에서는 고정값을 쓰지 않는다.
실측이 돌아오면 바로 실측값으로 바꾼다.
PX4 고도·목표·ToF 입력에는 이 값을 넣지 않는다.
이유: 지상 설치 높이는 현재 비행 고도의 측정값이 아니다.

2026-10-11에는 B4 XY와 높이 발행을 분리했다.
같은 높이의 네 앵커는 공통 높이 항을 제거한다.
따라서 유효한 B4 XY에는 ToF가 필수가 아니다.
`allow_b4_xy_without_tof`의 기본값은 true다.
원본 시각·네 관측의 신선도·점프 검사를 유지한다.
`unchanged_B4`만 이 예외에 해당한다.
높이가 없으면 XYZ는 발행하지 않는다.
B3 선택에는 기존 높이·연속성 조건을 유지한다.
후속 B4 검사는 유효 실측 높이와 거리를 대조한다.
각 앵커 시각의 높이·적합 XY를 사용한다.
불일치가 확인되면 ToF 누락으로 이를 지우지 않는다.
높이 미관측과 불일치를 별도 상태로 기록한다.
이 검사는 XY 관측의 기하 검사다. z 제어가 아니다.
[구현·재생 결과](report/b4_height_integrity_20261011.md)를 따른다.
2026-10-12에는 이 미배포 연구 검사를 분리했다.
`enforce_b4_height_integrity=true`로 명시해야 적용한다.
기본 false는 기존 현장 B_TF 경로를 유지한다.
검사 한계값과 true의 차단·복구 조건은 그대로다.
이유: 거리·배치 보정 전 적용을 보류한 실험이다.
[FINAL 대조 기록](report/final_cleanup_20261012.md)을 따른다.
추적 만료 시 [근거리 재획득](architecture/btf_reacquisition.md)을 쓴다.
실측 높이가 있는 유일 후보만 연속 확인한다.
ToF의 100ms 만료·장착·바닥 확인 기준은 그대로다.
자세한 근거는 [공백 수정](report/uwb_gap_followup_20261011.md)을 따른다.

이전의 지상 전용 예외도 호환성을 위해 남긴다.
`allow_ground_xy_without_tof=true`가 필요하다.
새 B4 예외를 false로 설정하면 이전 동작을 재현한다.
지상 모델과 실제 높이를 혼동하지 않는다.
이유: 지상 참조는 비행 중 높이의 근거가 아니다.

별도 지상 높이 모델도 명시적으로 선택할 수 있다.
B_TF 설정의 `ground_antenna_height_m`가 필요하다.
최신 ON_GROUND·연결·정지 속도를 함께 요구한다.
수평 자세·장착·평면 바닥 확인도 요구한다.
ARM 여부만으로는 이 모델을 끄거나 켜지 않는다.
실측 높이가 없을 때만 거리 기하에 사용한다.
`ground_reference_B3`로 측정 경로와 구분한다.
기존 거리 잔차·후보 유일성·연속성 검사는 유지한다.
기본 설정은 초기 연속성 근거가 없으면 XY도 거부한다.
`ground_subset_initialization=true`인 현장 지상 설정은
같은 유일 후보가2초·30표본 이상 유지돼야 초기화한다.
표본 공백은0.1초 이하, 위치 반경은0.05m 이하다.
추적 재획득은 기존 XY의0.1m 안에서만 허용한다.
이 문장의 근거리 경로와 별도로 이동 복구를 추가했다.
이동 복구는 실측 높이·승인 UWB 속도만 사용한다.
지상 높이 추정이나 수직 이륙으로 XY 범위를 넓히지 않는다.
[이동 복구와 freeze](architecture/btf_reacquisition.md)를 따른다.
지상·정지·수평 조건이 사라지면 이 초기화도 중단한다.
`/uwb/btf_xyz`에 추정 높이를 발행하지 않는다.
ToF 센서 메시지와 PX4 z에도 넣지 않는다.

| 값 | 의미 | 사용 경계 |
|---|---|---|
| ToF 실측 거리 | 센서 광축을 따른 하방거리 | 원본 거리·시각·센서 기준점 보존 |
| 거리 후보정용 Z | 자세·바닥·레버암을 반영한 높이 | FC 또는 UWB 안테나 기준을 명시 |
| PX4 고도 | PX4 EKF가 추정한 위치 | 비행 상태·고도 제어에 사용 |
| 앵커 z=2.2m | 앵커 설치 높이의 기존 설정 | 드론 가상 고도와 별개 |
| Tag B 앵커 z=0.15m | 2026-10-07 임시 안테나 시험 설정 | 추후 2.2m 복원, 실측 완료 아님 |
| MIS_TAKEOFF_ALT=1.3m | 사용자 요청으로 FC에 저장한 기본 이륙 높이 | 앵커 높이·관측 z와 별개 |
| 메시지 자리값 z=0 | XY 전용 메시지의 필수 필드 | 실측 높이나 목표 고도로 해석하지 않음 |

ToF 거리만으로 지도상의 z를 채우지 않는다.
이유: 기울기·장착 오프셋·바닥 기준을 반영해야 한다.
변환식과 연결 조건은 [M02 명세](specs/uwb/02_tof_z_adapter.md)를 따른다.

2026-10-08 실물 경로는 `/uwb/btf_xyz`를 표시한다.
XY와 같은 시각의 바닥 기준 태그 높이를 담는다.
FC에 전달하는 `/uwb/btf_pose`는 XY 전용이다.
10월 8일 구현은 높이 누락 때 XY도 중지했다.
10월 11일 구현은 유효한 B4 XY를 유지한다.
이는 XY 관측 경계다. 목표 z·고도 제어는 바뀌지 않는다.
웹 이륙은 PX4 `MIS_TAKEOFF_ALT`를 사용한다.
명령의 altitude는 NaN이다. 웹 경유지 z는 사용하지 않는다.
[비행 시험 구조](architecture/web_test_flight.md)를 따른다.

2026-10-11 사용자 요청의 앵커 로컬 XY 시험은 별도 계약이다.
`anchor_trial`의 `command_frame=local_xy`에서만 적용한다.
PX4 Offboard 위치 명령에는 유효한 로컬 XYZ가 필요하다.
START 때 받은 PX4 높이 + FC `MIS_TAKEOFF_ALT=1.7m`를
고정 높이 목표로 전달한다. 측정값을 생성하거나 덮어쓰지 않는다.
UWB는 XY만 제공하며 ToF·EKF와 PX4 고도 제어를 유지한다.
companion에 고도 PID·추력·자세 제어는 추가하지 않는다.
지리 기준점이나 위도·경도 변환은 사용하지 않는다.

## 공용 데모와 실측 입력

`drone_demo`는 XY 경로·목표·공백 시험만 제공한다.
가상 고도에 의존하던 사선거리 RAW 생성도 제거했다.
ROS Pose의 z는 0 자리값이며 상태의 `z_m`은 null이다.

`/tof/range`의 `sensor_msgs/Range`를 구독한다.
토픽은 `real_tof_topic`으로 지정한다.
측정은 `/demo_status.tof`에 하방거리로 표시한다.
누락·오류·노후 입력은 `range_m=null`이다.
`tof_timeout_s=0.2`는 데모 표시의 기본 만료 시간이다.
비행용 z 판정 임계값이 아니다.
ToF 수신 후에도 XY 데모는 계속 실행된다.

DOMAIN_ID 99·localhost 제한을 유지한다.
실측 토픽 연결·단위·시각·장착 확인은 장치에서 수행한다.
이번 수정은 그 연결이 완료됐다는 뜻이 아니다.
[공용 데모 기준](architecture/demo_design.md)을 따른다.

## UWB 파일 계산 경로

2026-09-21에는 실측 부족으로 합성 자료를 만들었다.
그 자료와 Gazebo 시험은 재현용으로 보존한다.
새 실측에는 `source=measured`와 원래 시각을 기록한다.
공용 파일 파이프라인의 계산·출력 게이트는 닫혀 있다.
실측 가능 여부만으로 정렬·장착 검증을 완료 처리하지 않는다.
이유: 동시 UWB·자세와의 시각 대응도 필요하다.
[파이프라인 기준](architecture/uwb_pipeline_design.md)을 따른다.

T-mini Pro는 전방 스캔 센서다.
하방 ToF 대신 고도 입력으로 사용하지 않는다.
