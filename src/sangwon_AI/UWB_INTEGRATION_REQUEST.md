# UWB 전체 사양 요청서
이 문서는 UWB 담당자에게 받을 자료와 수령 후 검토 절차다.
장비 사양을 전달받고 Jetson 연동 범위를 정할 때 읽는다.

상태: 사양 수령 대기 / 2026-10-02.
사용자 결정: **UWB 전체 사양을 받은 뒤 Jetson 어댑터를 설계한다.**
현재 제품의 통신 방식·출력 형식·성능은 확정하지 않는다.
기존 저장소의 DWM3000EVB·시리얼 JSON 기록은 과거 참고 자료다.
새 제작품에 그대로 적용한다고 가정하지 않는다.
구현 담당과 PX4 전달 담당도 사양 검토 뒤 확정한다.

## 1. 담당자에게 요청할 자료

아래 자료를 한 개의 사양 개정으로 묶어 전달받는다.
지원하지 않는 항목은 ‘미지원’, 아직 모르는 항목은 ‘미확정’으로 표시한다.
전체 사양 수령은 모든 기능을 지원한다는 뜻이 아니다.
지원 범위와 한계까지 설명된 자료가 필요하다.

| ID | 요청 자료 | 포함할 내용 |
|---|---|---|
| U01 | 장비 구성 | 태그·앵커 모델, 수량, 펌웨어 버전, 구성도, 담당자 |
| U02 | 연결·전원 | USB/UART/네트워크 등 실제 방식, 커넥터·핀·전압·전원 조건, 통신 설정 |
| U03 | 전체 프로토콜 | 필드·타입·단위·범위, 메시지 종류, 프레임 경계·길이·체크섬, 오류 처리 |
| U04 | 출력의 의미 | 위치인지 앵커별 거리인지, 실측·필터·예측·직전 값 유지의 구분 |
| U05 | 좌표 기준 | XY/XYZ 지원, 원점·축·부호·단위, 앵커 배치와 측량 기준, 태그 측정점 |
| U06 | 시간·신규 관측 | 측정 시각과 송신 시각의 의미·단위·시계, 순번·중복·재부팅·순환 처리 |
| U07 | 품질·실패 상태 | 유효/무효 판정, 오래된 값 표시, 앵커 부족·차폐·통신 단절 상태 |
| U08 | 오차·불확실성 | 정확도 시험 원본, 기준 좌표, 편향·분산, 공분산 제공 여부와 산출 의미 |
| U09 | 갱신·지연 | 측정 주기, 송신 주기, 지연·공백·변동 실측, 정지/이동/차폐 조건 |
| U10 | 시작·복구 | 전원 인가 순서, 초기화 시간, 설정 보존, 재연결·장치 재부팅·교정 절차 |
| U11 | 재현 자료 | 정상·정지·이동·유효하지 않음·유지값·재부팅 원시 로그와 해설 |
| U12 | 인수·변경 관리 | 전체 사양 개정, 알려진 제한, 설정 내보내기, 변경 통보 방식, 제공 일정 |

샘플은 한 줄 예시와 연속 원시 기록을 함께 받는다.
원시 기록에는 사용한 펌웨어·설정·시험 조건을 연결한다.
장착 위치와 기체 중심까지의 거리도 확인한다.
앵커는 운용 중 이동하지 않는 기존 결정을 유지한다.
재설치 등 구성 변경이 생기면 기존 검증본의 적용 여부를 다시 검토한다.

## 2. 전달용 요청 문안

> 실내 드론의 Jetson 연동을 위해 UWB 전체 사양 패키지를 요청합니다.
> U01~U12의 연결·프로토콜·좌표·시간·품질·실패 동작과 원시 로그를 포함해 주세요.
> 미지원·미확정 항목도 명시해 주세요.
> 사양을 받은 뒤 Jetson 측 어댑터와 PX4 연동 방법을 설계하겠습니다.
> 지금 단계에서는 특정 JSON 키나 ROS 메시지로의 출력 변경을 요청하지 않습니다.

이 문서는 요청 초안이며 실제 외부 전달은 별도다.

| 회신 항목 | 기입란 |
|---|---|
| 담당자·연락 경로 | 회신 대기 |
| 사양 개정·장비/펌웨어 버전 | 회신 대기 |
| U01~U12 자료 위치 | 항목별 파일·절 번호로 회신 |
| 미지원·미확정 항목과 영향 | 회신 대기 |
| 샘플 장비·전체 사양 제공 가능일 | 회신 대기 |

## 3. 전체 사양 수령 후의 연동 순서

```text
전체 사양 + 원시 로그
         |
  의미·누락·성능 검토
         |
  연결/파서 어댑터 설계
         |
  관측값 + 품질 + 시간 분리
         |
  승인된 지도/기체 좌표 변환
         |
  PX4 전달 경로 선정·융합 검증
         |
  행동 트리가 PX4 융합 상태로 판단
```

| 단계 | 결정할 내용 | 완료 증거 |
|---|---|---|
| 사양 인수 | 필드 의미·장비 한계·누락 확인 | U01~U12 검토표, 미해결 목록 |
| 어댑터 설계 | 실제 통신·파싱·오류·재접속 처리 | 실제 샘플에 대응하는 변환표 |
| 내부 인터페이스 | 관측·품질 메시지, 시간 기준·QoS·소유자 | 웹/BT/PX4와 책임 경계 합의 |
| 지상 재생 | 정상·이상 로그를 같은 판정으로 재현 | 관측 수·거부 사유·시각 추적 |
| 실장 측정 | 장착 오프셋·좌표 변환·지연·오차 측정 | 기준점과 비교한 원시 데이터 |
| PX4 융합 | 지원 축·시간·불확실성 전달과 EKF 수용 | PX4 로그·기준 위치 대조 |

구문과 전송 방식의 차이는 어댑터로 수용할 수 있다.
없는 측정 시각·유효성·좌표 의미를 어댑터가 만들어낼 수는 없다.
정보가 부족하면 추가 회신 또는 별도 측정 방법이 필요하다.
그 조건이 해결되기 전 해당 입력을 자율비행용으로 승인하지 않는다.

위치가 아니라 앵커별 거리만 제공된다면 위치 계산 모듈이 추가로 필요하다.
이는 파서 변경으로 끝나지 않는다.
해당 계산의 담당·오차 모델·검증 범위를 별도로 정한다.

## 4. 사양이 달라도 유지할 판정 원칙

아래는 내부 요구사항이며 UWB가 그대로 내보낼 필드명이 아니다.

| 상황 | 내부 처리 원칙 |
|---|---|
| 새 유효 관측 | 검증된 시간·좌표·품질 조건을 통과하면 융합 후보 |
| 직전 값 유지·중복 재전송 | 신규 위치 측정으로 다시 융합하지 않고 품질 기록 |
| 좌표 숫자만 동일 | 정지 중 새 관측일 수 있음. 값의 동일성만으로 중복 판정 금지 |
| 예측 위치 | 측정과 구분. 독립된 새 UWB 측정처럼 재주입하지 않음 |
| 무효·잘린 프레임·알 수 없는 개정 | 거부 사유 기록, 정상 관측으로 승격하지 않음 |
| 시간 역행·재부팅 | 시간 연결을 재검증, 이전 시각과 무조건 이어 붙이지 않음 |
| XYZ/yaw 일부 미지원 | 미지원 축을 0 값의 유효 관측으로 채우지 않음 |
| 공분산 미제공 | 0으로 완전 정확성을 주장하지 않음. 실측 기반 모델 필요 |

신규 관측 상실 시간은 마지막 유효 신규 관측을 기준으로 계산한다.
수신 시각으로 측정 시각을 대신할 수 있는지는 지연 측정 뒤 결정한다.
기존 로그의 `fix`·`xy_control_fresh`·`xy_control_held`는 과거 매핑 예시다.
향후 장비의 필수 키로 지정하지 않는다.

UWB 사양 확정 전에는 이 문서의 요청 목록과 검토 절차까지만 유지한다.
정확한 ROS 메시지·PX4 전달 API·수치 임계값은 미정이다.
검증 계획은 [VALIDATION_PLAN.md](VALIDATION_PLAN.md)의 UWB 항목을 따른다.
