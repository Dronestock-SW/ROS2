# B_TF 이력 격리와 오차 판정 검사

이력 격리 원인과 거리 잔차 검사 결과다.
관측 개선과 다음 실측을 준비할 때 읽는다.

목적은 자율주행에 쓸 관측의 신뢰성을 평가하는 것이다.
이전 위치 이력만으로 지속 격리를 재현했다.
자율주행 적용은 보류한다.

| 같은 실측 입력의 재생 조건 | B4 승인 | 점프 격리 |
|---|---:|---:|
| 새 이력 | 1856 | 0 |
| 이전 +X 평균 위치를 기준으로 지정 | 0 | 1872 |
| 이전 위치 유지·모델만 초기화 | 0 | 1872 |

실행 중 프로세스의 실제 이전 좌표는 회수하지 않았다.
재생에는 통제 목적으로 이전 시험 평균을 넣었다.
기록 순서는 실제 콜백 순서의 대용이다.
따라서 실기의 완전 복제라고 주장하지 않는다.

B4의 6cm 기준은 내부 거리 RMS다.
독립 기준점 대비 XY 오차가 아니다.
6cm 미만이면 B4를 유지한다.
6cm 이상이면 ToF B3 후보를 검사한다.

새 이력의 B4 내부 RMS 평균은 1.84cm였다.
실측 높이를 쓴 물리 거리 RMS 평균은 8.36cm였다.
이 값은 독립 XY 오차가 아니다.
두 잔차의 집계 방식도 같지 않다.
승인 116개에는 지상 참조 높이가 사용됐다.
실측 높이 표본과 분리해야 한다.

기존 회귀 검사 120개가 통과했다.
운영 코드·FC 설정·보정값은 바꾸지 않았다.
이번 게시 과정에서 회귀 검사를 재실행하지 않았다.

다음 순서는 시험 세션 초기화 검증이다.
그 뒤 높인 기준점의 독립 XY를 측정한다.
센서 누락·높이 출처·거리 일관성을 함께 평가한다.
이후 동적 좌표·시각 정렬과 PX4 융합을 확인한다.
초기화 절차와 B4 물리 잔차 차단은 미구현이다.
실물 비행 검증도 남아 있다.

후속 작업에서 [지상 초기화](../runbooks/btf_observation_session.md)를 구현했다.
단위·ROS callback 시험을 통과했다. 현장 적용은 남아 있다.
B4 물리 잔차 차단과 공중 재획득은 여전히 미완료다.
[비행 기록 비교](hover_gap_analysis_20261010.md)를 함께 확인한다.
