# 현재 UWB 앵커 좌표

현재 실행에 쓰는 앵커 좌표 사전이다. 배치·설정 변경 전에 읽는다.

2026-10-04 사용자 지시로 직사각형을 고정했다.
가로 x는 6.3m, 세로 y는 4.6m다.
A1을 원점으로 두고 A2 방향을 +x로 삼는다.
A3 방향은 +y다. 높이는 기존 2.2m를 유지한다.
2.2m는 앵커 설치 높이다.
드론의 가상 고도 제거는 [고도 원칙](../altitude_policy.md)을 따른다.

| 앵커 | x (m) | y (m) | z (m) |
|---|---:|---:|---:|
| A1 | 0.0 | 0.0 | 2.2 |
| A2 | 6.3 | 0.0 | 2.2 |
| A3 | 0.0 | 4.6 | 2.2 |
| A4 | 6.3 | 4.6 | 2.2 |

```text
        +y
         ^
 A3 (0,4.6) -------- 6.3m -------- A4 (6.3,4.6)
         |                              |
       4.6m                           4.6m
         |                              |
 A1 (0,0) ---------- 6.3m -------- A2 (6.3,0) --> +x
```

A1-A2와 A3-A4는 x 방향 6.3m다.
A1-A3와 A2-A4는 y 방향 4.6m다.
두 대각선은 계산상 약 7.80064m다.
배열 순서는 `[A1,A2,A3,A4]`를 유지한다.

## 적용 위치

실행 기본값은 새 좌표 파일을 읽는다.

| 구분 | 경로·상태 |
|---|---|
| 기준 파일 | [anchors_20261004.json](../../src/drone_uwb/config/anchors/anchors_20261004.json) |
| 배치 ID | `warehouse-rectangle-6p3x4p6-z2p2-20261004` |
| ROS 수신 | `integration/ros/node.py`의 기본 `anchor_file` |
| 공용 데모 | `drone_demo/core.py`의 설치 설정 로더 |
| Gazebo 생성 | `integration/gazebo/gazebo_rig.py`의 기본 `--anchors` |
| Gazebo 비교 기본값 | `config/gazebo/gazebo_shadow.json`의 같은 좌표 |
| 실제 장치·기존 생성 월드 반영 | 미실시. 기존 실행 중인 프로세스·생성 파일은 자동 변경하지 않음 |

XY 크기는 사용자가 정한 현재 고정값이다.
독립 측량 완료를 뜻하지 않으므로 검증 표시는 false다.
Z=2.2m는 이번에 새로 측정한 값이 아니다.
좌표 변경만으로 거리 bias를 재교정하지 않는다.
기존 교정값과 새 배치의 실측 검증은 별도다.

## 과거 자료와의 관계

9월 실측 재생에는 당시 좌표를 사용한다.

| 자료 | 사용할 배치 |
|---|---|
| 현재 ROS·데모·새 Gazebo 생성 | `anchors_20261004.json` |
| 2026-09-06 정지 기록의 A/B/C/D 재생 | `anchors_20260906.json`과 고정된 입력 해시 |

과거 좌표 파일과 기록의 해시를 덮어쓰지 않는다.
당시 결과의 재현 근거를 유지하기 위해서다.
[9월 실측 이력](uwb_anchor_survey.md)은 이전 배치의 근거다.
[변경·검증 기록](../report/uwb_anchor_rectangle_20261004.md)을 함께 읽는다.
