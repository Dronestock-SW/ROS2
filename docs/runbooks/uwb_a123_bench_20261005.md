# A4 결측 시 A1·A2·A3 지상 시험

A4가 동작하지 않을 때 쓰는 관측 시험 절차다.
좌표 기준점을 표시하고 기록을 시작할 때 읽는다.

## 실행 조건

세 앵커의 동일 높이 조건으로 XY를 계산한다.
B_TF의 네 앵커 결함 검출 시험과 구분한다.
FC 위치 전달과 모터 시동을 수행하지 않는다.
이유: 세 앵커 관측의 정확도를 먼저 확인해야 한다.

사용자가 새 장소의 치수를 확인했다.
A1=(0,0,2.2), A2=(6.3,0,2.2), A3=(0,4.6,2.2)m다.
UWB 태그는 ToF 렌즈보다 위로 0.12m다.
프로펠러를 분리하고 평평한 바닥을 사용한다.

## 전용 설정

`src/drone_uwb/config/runtime/uwb_a123_bench.yaml`을 사용한다.
`min_anchors=3`, `active_anchor_mask=7`이다.
7은 A1·A2·A3만 선택하는 비트 마스크다.
기존 기본값은 네 앵커·마스크 15로 유지한다.
원시 거리·마스크·실패 사유를 수정하지 않는다.
A4가 복구되어도 선택에 넣지 않는다.
A1·A2·A3 중 하나라도 없으면 좌표를 보류한다.

세 앵커 차분 계산의 잔차는 정확도 증거가 아니다.
줄자로 확인한 독립 위치와 대조해야 한다.
ToF·자세·배터리·FC 상태는 별도로 기록한다.
현재 세 앵커 XY에 ToF 보정이나 H80을 적용하지 않는다.
출력은 `/uwb/a123_pose`이며 FC 브리지는 실행하지 않는다.

## 기록 시작

Jetson Bash에서 실행한다.
다른 프로그램이 장치를 사용하면 실행기가 중단된다.
기존 기록을 임의로 종료하지 않는다.

```bash
cd /home/pgyxn/github/ROS2
source /opt/ros/humble/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=1 ROS_LOCALHOST_ONLY=1 PYTHONIOENCODING=utf-8
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python3 src/drone_uwb/tools/capture_a123_bench.py \
  --output data/raw/a123_sensorcheck_$(date +%Y%m%d_%H%M%S) \
  --stage sensor_check --seconds 60
```

원시 UWB는 `uwb/raw`에 기록한다.
계산 판정은 `uwb/processed`에 기록한다.
FC 센서는 `telemetry.jsonl`에 기록한다.
`manifest.json`의 기준점이 null이면 위치 오차를 산출하지 않는다.
`--reference-xy 1 1`은 XY만 확인된 P1 기록에 사용한다.
이 경우 기준은 `[1,1,null]`이며 높이를 추정해 채우지 않는다.
`--reference-xyz`와 `--reference-xy`는 동시에 사용할 수 없다.
준비 중 재시작을 요청한 기록은 원형을 보존한다.
별도 `evaluation_status.json`에 제외 이유와 대체 기록을 남긴다.
큰 기준점 차이가 발견되면 실제 기준점과 앵커 대응을 먼저 확인한다.

## 안내 순서

| 단계 | 동작 | 기록 |
|---|---|---|
| 1 | 현재 위치에서 60초 정지 | 세 앵커 수신·A4 결측·FC 센서 |
| 2 | P1=(1,1), P2=(3,1), P3=(1,2.5), P4=(2,1.5), P5=(3,2)m | 각 60초, 3회 반복 |
| 3 | P1↔P2 직선 이동 | 3회 왕복, 끝점만 5초 유지 |
| 4 | P1↔P3 직선 이동 | 3회 왕복, 끝점만 5초 유지 |
| 5 | P1→P2→P4→P1 이동 | 방향 전환·복귀 3회 |
| 6 | 지상에서 A3 전원 10초 중단 후 복구 | 두 앵커일 때 차단·복구 후 30초 |

각 기준점은 안테나의 바닥 수직 투영 위치다.
태그 안테나 중심의 바닥 기준 높이도 측정한다.
준비 완료를 확인한 뒤 해당 기준점 기록을 시작한다.
이동이나 단절을 수행했다고 임의로 기록하지 않는다.
