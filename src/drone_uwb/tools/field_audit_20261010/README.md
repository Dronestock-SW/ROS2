# 2026-10-10 파일 분석 도구 보존본
당시 사용한 분석 스크립트 원본이다.
같은 기록을 재검토할 때 읽는다.

운영 노드나 설치용 도구가 아니다.
Linux·ROS2 Humble의 Python 의존성이 필요하다.
원본 센서 자료는 이 디렉터리에 포함하지 않는다.
스크립트의 고정 경로와 시각은 당시 시험을 가리킨다.
임시 원본이 정리됐다면 별도 보관본이 필요하다.

analyze_stationary.py는 시작 ROS ns와 기준 x y를 받는다.
기준 미확인 구간은 x y 대신 unknown을 받는다.
replay_btf_audit.py는 파일만 읽고 발행을 메모리로 대체한다.
ROS를 초기화하거나 FC 명령을 보내지 않는다.
재생 코드 경로는 감사 당시 HEAD와 맞춰야 한다.
실행 결과로 임시 스냅샷 폴더에 분석 파일을 쓴다.
이 보존본은 범용화·배포 검증한 CLI가 아니다.
