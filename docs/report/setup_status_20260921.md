## 설치와 계정 설정

ROS2 설치는 확인했다. 계정의 실행 준비는 남아 있다.

| 항목 | 확인 결과 |
|---|---|
| ROS2 Humble | `/opt/ros/humble`에 설치됨 |
| colcon | `/usr/bin/colcon` 존재 |
| MAVROS·MAVROS Extras | 2.14.0 설치됨 |
| gscam | 2.0.2 설치됨 |
| 영상 관련 ROS 패키지 | `cv_bridge`, `camera_calibration` 조회됨 |
| 지오이드 자료 | `egm96-5.pgm` 존재·읽기 가능 |
| Tailscale 서비스 | `active` |
| 계정 시작 파일 | ROS 소싱·`ROS_DOMAIN_ID` 설정 줄 없음 |
| 확인 셸의 `ROS_DOMAIN_ID` | 미설정 |
| 개인 저장소 빌드 산출물 | `build/`, `install/`, `log/` 없음 |
| 사용자 rosdep 캐시 | `~/.ros/rosdep/sources.cache` 없음 |
| LiDAR 서브모듈 | `4ef70d3` 체크아웃 확인 |

`source /opt/ros/humble/setup.bash` 후 조회했다.
위 공용 ROS 패키지는 정상 조회됐다.
현재 소싱 범위에서 자체 패키지 3종은 조회되지 않았다.
대상은 `drone_uwb`, `drone_demo`, `drone_platform_link`다.
소스는 저장소에 있지만 이 계정의 빌드는 미확인이다.

패키지 목록 확인 중 기존 XML 오류도 발견했다.
`src/drone_bringup/package.xml`의 20행이다.
XML 주석 안의 `--`로 파싱이 실패했다.
전체 빌드 전에 해결해야 할 기존 항목으로 기록한다.
이번 문서 작업에서 코드를 수정하지 않았다.

## 장치 경로와 접근 상태

장치 경로의 존재만 확인했다. 데이터를 수신하지 않았다.

| 경로 | 존재 | `pgyxn`의 읽기·쓰기 접근 |
|---|---|---|
| `/dev/lidar` | `ttyUSB0` 링크 | 둘 다 불가 |
| `/dev/uwb` | `ttyUSB1` 링크 | 둘 다 불가 |
| `/dev/pixhawk` | 없음 | 해당 없음 |
| `/dev/video0` | 있음 | 둘 다 가능 |

현재 프로세스의 그룹에 `dialout`이 없다.
접근 결과는 `os.access`로 확인했다.
포트를 열거나 센서 노드를 실행하지 않았다.
과거 `user` 계정의 시험과 이번 계정을 구분한다.
