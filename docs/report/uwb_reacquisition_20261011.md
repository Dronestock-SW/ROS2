# UWB 근거리 재획득 검증
정상 B3가 돌아와도 추적 만료로 막히던 경로를 수정했다.
수정 범위와 기존 로그 재생 결과를 확인할 때 읽는다.

## 결과

기존 세 기록에서 현재 관측 152개를 추가 발행했다.
기존 출력의 삭제·좌표 변경은 0개다.
C3 최대 공백은 10.751초에서 8.701초로 줄었다.
남은 큰 점프 구간은 계속 거부한다.
실물 위치 정확도·PX4 융합·비행 검증은 아니다.

## 변경 경계

100ms를 늘리지 않고 별도 확인 단계를 추가했다.
자세한 조건은 [근거리 재획득 설계](../architecture/btf_reacquisition.md)를 따른다.

| 항목 | 처리 |
|---|---|
| 근거 | 마지막 승인 B4/B3 XY를 별도로 보존 |
| 복구 후보 | 실제 ToF/IMU 높이와 기존 유일성 검사를 통과한 B3 |
| 고정 반경 | 마지막 승인 XY부터 0.10m 이내 |
| 확인 기간 | 동일 제외 앵커로 0.15초·4표본 이상 |
| 표본 간격·이동 | 100ms 이하, 기존 속도·거리 여유 한도 유지 |
| 실패 처리 | 후보 교대·높이 누락·큰 이동·시각 중복이면 확인 재시작 |
| 발행 | 확인된 현재 관측만 원래 시각으로 발행 |

확인 중 거부된 후보는 기준 XY를 갱신하지 않는다.
긴 공백으로 H80를 비워도 마지막 승인 XY는 남긴다.
이 기준은 근거리 확인용이며 좌표 출력에 복사하지 않는다.
실제 모델 초기화·시각 역행은 그 기준도 비운다.
이전 승인 좌표가 없는 공중 B3 초기화는 계속 거부한다.
지상 초기화·raw 점프 검사·원본 시계 검사는 바꾸지 않았다.
Z 생성·보간·PX4 XY 피드백도 추가하지 않았다.
FC 파라미터를 바꾸지 않았다.

## 동일 로그 비교

비교 기준은 `18d980a`의 B4 XY 분리 코드다.
양쪽 모두 같은 원본·현장 config·수신 순서를 사용했다.
수신 순서는 원래 콜백 순서의 근사라는 한계가 있다.

| 기록 | 변경 전 XY | 변경 후 XY | 재획득 횟수 | 최대 공백 전 → 후 |
|---|---:|---:|---:|---|
| C1 | 816 | 880 | 1 | 12.350 → 12.350초, 기록 끝에서 잘림 |
| C2 | 372 | 372 | 0 | 16.450 → 16.450초, 기록 끝에서 잘림 |
| C3 | 1,579 | 1,667 | 5 | 10.751 → 8.701초 |

재획득 6회 뒤 추적이 이어져 152개가 추가됐다.
6회의 확인 시간은 0.150–0.175초다.
승인 기준과의 거리는 0.022–0.087m였다.
이는 실제 위치 오차가 아니라 복구 반경 검사값이다.
추가 좌표의 정확도는 독립 실측이 필요하다.

| 보존 검사 | 결과 |
|---|---|
| 기존 발행의 삭제 | 세 기록 모두 0개 |
| 양쪽 발행의 XY 차이 | 최대 0m |
| raw 입력·점프 검사·raw 기준·H80 결과 | 모든 결정에서 동일 |
| raw 점프 거부 | C1 121 / C2 87 / C3 283개, 전후 동일 |
| 재획득 전 원본 시각·표본 대응 | 모든 결정 정렬 일치 |

### C3의 10.7초 구간

초기 추적 만료를 복구했다. 후반의 큰 차이는 보류했다.
seq 113496에서 신선도 100.042ms가 되어 추적이 만료됐다.
새 코드는 그 후보를 즉시 승인하지 않는다.
seq 113502까지 6표본·150.029ms를 확인했다.
이때 이전 승인 위치와 차이는 약 2.2cm였다.
현재 관측으로 복귀한 뒤 기존 B3 추적을 이어갔다.

seq 113575부터 후보 유일성이 나빠졌다.
그 다음에는 연속성 한도 밖의 후보가 나왔다.
seq 113594 이후 raw 점프 거부도 그대로다.
따라서 146.831–155.532초의 8.701초 공백은 남는다.
시각은 C3 수집 시작 기준이다.
이를 관측 정상화가 확인된 구간으로 단정하지 않는다.

시간만 기다리면 큰 점프가 승인되는 방식은 쓰지 않았다.
실제 이동과 거리 편향을 나눌 독립 XY가 없기 때문이다.
추가 실측은 [기존 절차](../runbooks/uwb_gap_measurements.md)에 남겼다.

첫 FC readback은 응답이 없어 중단했다.
같은 읽기 전용 조회를 재시도해 15개 조회를 완료했다.
그중 파라미터 12개를 전후 대조했다.
전체 FC 파라미터를 다시 썼거나 대조했다는 뜻은 아니다.

적용 뒤 저장공간 하한으로 수집이 대기한 것도 발견했다.
이 상태와 관측 노드의 정상 실행을 구분한다.
종료·쓰기 완료·연속 지상/DISARM 기록 8개를 골랐다.

원격 원본의 해시·열린 파일 없음도 다시 확인했다.
그 588,466,891바이트만 원격에서 정리했다.
비행·미완료·상태 불명 기록은 정리하지 않았다.
PC의 검증된 압축본과 검증표는 Git 밖에 보존했다.
여유 공간은 1,920,286,720바이트로 회복했다.
수집기가 `collecting`으로 복귀했다.
새 manifest의 source revision은 `1155967`이다.
설정 파일과 수집기의 저장공간 하한은 바꾸지 않았다.

## 재현

원본과 재생 파일은 Git 밖에 보관한다.
기존 원본 해시는 [호버·공백 보고서](hover_gap_analysis_20261010.md)를 따른다.
새 비교 결과에는 전후 재생 SHA256도 포함된다.

```bash
PYTHONPATH=src/drone_uwb OPENBLAS_NUM_THREADS=1 \
  python3 src/drone_uwb/tools/replay_manual_btf.py /private/C3 \
  --output /private/near-prior-c3.jsonl
python3 src/drone_uwb/tools/analyze_btf_gaps.py /private/C3 \
  --replay /private/near-prior-c3.jsonl \
  --baseline-replay /private/btf-xy-separated-c3.jsonl \
  --output /private/reacquisition-comparison.json
```

`paired_algorithms`는 알고리즘 변경 전후를 비교한다.
기존 높이 발행 조건 비교와 구분한다.
추가·삭제·공통 XY 차이·상위 검사 변경을 함께 보고한다.
수신 시각이나 표본 순서가 다르면 비교를 거부한다.
