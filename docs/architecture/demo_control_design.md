# 수평 제어 데모 기준
이 문서는 수평 제어 데모의 입력·출력 기준이다.
명령으로 움직이는 모형을 시험할 때 읽는다.

## 범위

기존 1.2m 높이를 재사용해 수평 제어를 시험한다.
현재 위치·목표·UWB 공백 형식도 재사용한다.
실행은 DOMAIN_ID 99와 localhost로 제한한다.
이유: 가상 목표와 실기 입력이 섞이지 않게 한다.

```text
이동 모형 -> /demo_pose -----------+
    |                            |
가상 UWB -> /uwb_pose -> 임무 판단·수평 P 제어
                                 |
/target_pose --------------------+
                                 |
                      /demo_velocity_command
                                 |
                        유효기간 검사 -> 이동 모형
```

기존 시간 기반 데모는 그대로 제공한다.
제어 데모는 별도 launch로 선택한다.
명령이 없으면 모형의 목표 속도는 0이다.
목표점은 모형을 직접 움직이지 않는다.

이 모형은 속도 응답과 가속도 제한만 표현한다.
현재 위치는 모형의 정답을 사용한다.
UWB는 새 관측 수신 여부를 확인하는 역할이다.
EKF2·IMU·비행 물리 성능 시험은 아니다.
MAVROS와 실제 PX4를 연결하지 않는다.
이유: 이번 범위는 수평 제어의 기능 검증이다.

## 설정

기존 `demo.json`과 새 `control.json`을 함께 쓴다.

| 설정 | 기본값 | 의미 |
|---|---:|---|
| 가상 z | 0.2~2.2m, 8초 주기 | 기존 데모 높이 |
| `speed_m_s` | 0.25m/s | 합성 수평 속력 상한 |
| `start_hold_s` | 2초 | 모형의 초기 정지 구간 |
| `kp_xy_s_inv` | 0.5/s | 위치 오차를 속도로 변환 |
| `max_accel_m_s2` | 0.5m/s² | 명령 속도의 변화 제한 |
| `plant_accel_m_s2` | 0.5m/s² | 모형의 가속도 제한 |
| `plant_response_s` | 0.15초 | 모형의 속도 응답 시간 |
| `control_rate_hz` | 20Hz | 제어 판단·명령 발행 주기 |
| `command_timeout_s` | 0.20초 | 모형이 명령을 쓸 최대 나이 |

모든 수치는 데모 초기값이다.
실기의 허용 속도와 정지 성능을 뜻하지 않는다.
z 방향의 속도나 추력은 계산하지 않는다.
이유: 수평 기능만 시험하고 고도 책임을 유지한다.

## 제어 동작

위치 P 제어에 합성 속력과 변화량 제한을 적용한다.

| 임무 상태 | 수평 명령 |
|---|---|
| 이동·접근·정착·도착 | 목표 오차 × Kp, 제한 적용 |
| 목표 대기·입력 대기 | 속도 0으로 감속 |
| 공백·복구 확인 | 속도 0으로 감속 |

도착 후에도 같은 목표를 유지한다.
UWB 복구는 기존 연속 수신 조건을 사용한다.
명령 생성 간격이 유효기간을 넘으면 감속부터 재개한다.
도착 여부는 거리·속력·지속 시간으로 평가한다.

## ROS2 계약

좌표계는 `uwb_map`으로 통일한다.
PX4의 ENU와 정합했다는 뜻은 아니다.

| Topic | 형식 | 역할 |
|---|---|---|
| `/demo_pose` | `PoseStamped` | 모형의 현재 위치. z=1.2m |
| `/target_pose` | `PoseStamped` | 기존 데모 목표 |
| `/uwb/raw`, `/uwb_pose` | 기존 형식 | 가상 거리와 전처리 관측 |
| `/demo_mission_state` | `String` JSON | 기존 임무 상태 판단 |
| `/demo_velocity_command` | `String` JSON | 모형 전용 수평 속도 명령 |
| `/demo_status` | `String` JSON | 모형 속도·명령 수신 상태 |

명령에는 생성 시각·순서·유효기간을 넣는다.
`demo=true`, `flight_output=false`를 명시한다.
수신부는 좌표계·숫자·속력·시각을 검사한다.
중복·과거 명령은 유효기간을 갱신하지 않는다.
잘못된 명령은 현재 명령을 해제한다.
유효기간이 끝나면 모형은 속도 0을 목표로 감속한다.
즉시 위치나 실제 속도를 0으로 바꾸지는 않는다.

ROS 시각은 메시지 나이를 계산하는 데 쓴다.
수신 후 만료는 단조 시계로 계산한다.
현재 노드는 벽시계 기준이다.
SITL 시계 연결은 다음 단계에서 별도로 구현한다.

## 검증 범위

명령이 이동 결과를 바꾸는지 확인한다.

| 시험 | 확인 내용 |
|---|---|
| 정지·이동 | 목표 정착과 속력·변화량 제한 |
| UWB 1초 공백 | 감속·정지 후 복구 |
| 명령 1초 단절 | 모형이 명령 만료를 감지하고 감속 |
| 목표 변경 | 새 목표 방향과 연속 속도 변화 |
| 중복·과거·오류 입력 | 오래된 명령과 도착 판정 차단 |
| ROS2 연결 | 발행 명령을 모형이 수신해 이동 |

실행은 [공용 데모 절차](../runbooks/demo_procedure.md)를 따른다.
설계 근거는 [제어 조사](../report/next_horizontal_control_research_20260913.md)에 있다.
