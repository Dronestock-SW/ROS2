# 웹 명령 연결 — 2026-10-11

현재 UWB 송신기와 웹 명령을 연결한 기록이다.
START·ARM 요청과 실제 기체 실행을 구분할 때 읽는다.

## 적용 설계

사용자는 웹 START·ARM 요청 연결을 승인했다.
이륙 높이는 추가로 1.7m를 지정했다.
기존 미션 START의 준비 검사는 유지한다.
별도 ARM은 수동 모드에서 시동만 요청한다.
PX4의 정상 ARM 검사를 사용한다.
강제 ARM·모드 전환·자동 이륙을 묶지 않는다.

웹 → 같은 단일 실행기 → MAVROS CommandBool → PX4

ARM은 현재 실행기 세션과 3초 요청 시각을 검사한다.
최신 DISARM·지상·RC·잔량·수동 모드가 필요하다.
요청 번호를 기록한 뒤 한 번만 전송한다.
응답 재조회와 웹 재시작은 ARM을 재전송하지 않는다.
ACK와 실제 ARM 상태는 따로 표시한다.
미션 START는 DISARM 상태에서 사용한다.

새 송신기는 `/uwb/local_odometry_status`를 사용한다.
기존 브리지와 다른 횟수·시각 필드를 변환한다.
현재 호스트 부팅 ID와 최신 발행을 대조한다.
좌표 회전·장착값은 송신기와 일치시킨다.
동적 정렬·비행 검증을 완료로 바꾸지 않는다.

## 확인

FC `MIS_TAKEOFF_ALT`를 2.5m에서 1.7m로 변경했다.
강제 파라미터 조회로 1.70000005m를 확인했다.
MAG_TYPE·FLOW_ROT·THR_HOVER·EV_CTRL은 유지됐다.
RC_IN_MODE=3·RC_OVERRIDE=1도 유지됐다.
이 단계에서 시동·이륙 명령은 보내지 않았다.

로컬 관련 시험 100개가 통과했다.
Jetson 격리 검사 61개도 통과했다.
ARM 어댑터는 가짜 서비스로 정상 요청 한 건을 확인했다.
실제 ROS 제어 서비스에 시험 ARM을 보내지 않았다.

웹·실행기·전달기만 별도 배포본으로 교체했다.
센서·기존 UWB 융합 프로세스는 유지했다.
FC 텔레메트리 주기도 변경하지 않았다.
실행기는 사용자 클릭 뒤 명령을 받는다.
조회 시 `can_arm=true`·DISARM·POSCTL이었다.
브리지 발행·변환 일치·현장 XY·1.7m 검사가 통과했다.
조회 시 `can_start=false`였다.
전역 원점·실측 지도·높이 관측이 아직 없다.
동적 정렬·시각·방위·ULog 확인값도 미완료다.
기존 RC 전용 정책은 RC_IN_MODE=3에서 미통과다.
이 항목들을 임의로 통과 처리하지 않았다.
실제 ARM·자동 비행 시험은 아직 수행하지 않았다.
