# B_TF 관측 재획득
공백 뒤 정지·이동 관측을 복구하는 설계다.
관측 복구와 비행 중 점프 보호를 수정할 때 읽는다.

## 결정

정지 근처 복구와 이동 중 복구를 구분한다.
신선도 제한 100ms를 늘리는 방식은 쓰지 않는다.
기존 점프 검사를 유지한다. 이동 복구만 별도 심사한다.

```text
새 RAW -> 기존 TDMA/시각/raw 점프 검사
  -> 큰 이동: 공백 전 속도와 일치하는가?
       -> 연속 확인 통과 -> 현재 RAW로 H80 재개
       -> 실패 -> 신뢰 기준 freeze, 발행 없음
  -> H80/ToF
  -> 신선한 B3 직전 위치 있음 -> 기존 연속성 검사
  -> 직전 위치 만료 -> 마지막 승인 위치 근처인가?
       -> 같은 유일 B3 후보 연속 확인 -> 현재 관측 발행
       -> 멀면: 공백 전 속도와 일치하는가?
            -> 유일 후보 연속 확인 -> 현재 관측 발행
            -> 불일치 -> 거부 유지
```

## 복구 조건

| 조건 | 기준 |
|---|---|
| 이전 근거 | 실제 승인한 B4/B3 위치가 존재 |
| 현재 입력 | 원래 시각의 신선한 4거리·ToF/IMU 높이 |
| 후보 | 기존 거리 RMS·유일성 검사 통과 B3 |
| 원점 거리 | 마지막 승인 XY부터 0.10m 이내 |
| 연속 확인 | 같은 제외 앵커, 0.15초 이상·4표본 이상 |
| 표본 사이 공백 | 기존 B3 신선도 한도 0.10초 이하 |
| 표본 사이 이동 | 기존 0.10m + 1m/s × 표본 간격 이하 |
| 확인 중 실패 | 후보 불일치·높이 만료·큰 이동 시 확인 재시작 |

0.10m는 기존 `continuity_margin_m`를 사용한다.
확인 중에는 마지막 승인 위치를 이동시키지 않는다.
이 근거리 복구 반경은 시간이 흘러도 키우지 않는다.
이유: 고정된 잘못된 위치가 시간만으로 승인될 수 있다.
첫 XY가 없는 공중 B3 초기화는 허용하지 않는다.
지상 초기화는 기존 별도 절차를 유지한다.

H80 표본 이력과 복구 기준의 수명을 구분한다.
일반 표본 공백은 H80·활성 추적 이력을 비운다.
마지막 승인 위치는 복구 반경 판단에만 보존한다.
원본 시각 역행·실제 세션 초기화는 그 기준도 비운다.
일부 앵커 누락 시 fitting 이력만 비운다.
마지막 승인 위치·속도 근거는 제한 시간 동안 보존한다.
큐 만료·시계 재동기화는 속도 근거도 비운다.

## 이동 중 재획득

과거 승인 UWB만으로 확인용 이동 경로를 만든다.
PX4 위치·속도·명령·IMU 적분을 입력하지 않는다.
확인용 경로를 관측이나 제어 상태로 발행하지 않는다.

| 조건 | 초기 구현값 |
|---|---|
| 승인 이력 | 최근 0.5초, 8표본 이상, 길이 0.3초 이상 |
| 이력의 최대 표본 간격 | 0.1초 |
| 측정 속도 범위 | 0.15~2m/s |
| 직선 fitting 최대 오차 | 0.04m |
| 이력 전반·후반 속도 차이 | 0.25m/s 이하 |
| 확인 경로 | 마지막 승인 XY + 승인 이력 속도 × 실제 시각 차이 |
| 승인 이력 이후 최대 시간 | 1.5초, 확인 시간 포함 |
| 경로 오차 한도 | min(0.20m, 0.10m + 0.10m/s × 시각 차이) |
| 복귀 관측 확인 | 같은 후보, 0.15초·4표본 이상 |
| 복귀 표본 간격 | 0.1초 이하 |
| 복귀 속도 차이 | 0.25m/s 이하 |
| 기존 방향으로 진행한 속도 비율 | 0.5~1.5 |

이 값들은 비행 속도 제한이나 실측 보정값이 아니다.
관측 재획득 모델의 초기 보수적 한도다.
급가속·급회전·1.5초 초과 공백은 자동 복구하지 못한다.

raw 복구에는 실측 ToF·IMU 높이를 요구한다.
차분 잔차와 실제 거리 RMS 모두 0.06m 미만이어야 한다.
B3는 기존 높이·거리 RMS·후보 유일성 검사를 유지한다.
일반 B4 XY 발행은 여전히 높이와 독립적이다.
PX4 브리지의 기본 `ObservationGuard()`는 변경하지 않았다.
이동 복구는 `MeasuredBtf`의 raw 검사에서 명시적으로 켠다.
따라서 이번 관측 복구만으로 FC 융합 복구를 보장하지 않는다.

## 이륙 시 freeze

freeze는 신뢰 기준을 고정하는 동작이다.
이전 XY를 새 측정 시각으로 반복 발행하는 기능이 아니다.

- 이륙 전 정지 이력은 이동 속도 근거로 인정하지 않는다.
- 지상 높이 추정값으로 이동 복구 속도를 학습하지 않는다.
- 연속 수신 중 큰 점프는 이동 복구를 잠근다.
- 복귀 후보가 예상 경로와 모순돼도 잠근다.
- 거부된 점으로 기준 위치·속도를 갱신하지 않는다.
- 기다려서 예측 경로가 잘못된 점에 도달해도 풀지 않는다.
- 원래 기준의 기존 검사 통과나 명시적 지상 초기화가 필요하다.

수직 상승만으로 수평 이동 범위를 넓히지 않는다.
ToF·IMU가 복귀해도 XY 이동 근거를 별도로 확인한다.
현재 구조는 일정한 수평 속도 복구만 다룬다.
점진적인 공통 거리 편향은 독립 측정 없이는 구분하지 못한다.

## 범위와 한계

복구 시 현재 관측의 원래 시각·좌표를 발행한다.
이전 XY 복사·예측 관측 발행·PX4 위치 입력은 금지한다.
FC 파라미터·명령·Z 제어를 바꾸지 않는다.
복구 완료는 실물 위치 정확도나 비행 승인이 아니다.
큰 이동도 과거 속도와 복귀 관측이 맞으면 재획득한다.
근거가 부족한 큰 이동은 계속 거부한다.
실제 정확도 판단에는 독립 위치 근거가 필요하다.

## 검증 계획

1. 정지·근거리 이동 중 단발 누락 뒤 복구를 확인한다.
2. 지속하는 큰 점프·후보 교대·높이 누락을 거부한다.
3. 중복 시각·초기 근거 없음·긴 공백을 구분한다.
4. C1/C2/C3를 원본 순서로 재생해 기존 기준과 비교한다.
5. 추가 출력 수·최대 공백·점프 거부를 함께 보고한다.
6. 새 출력의 정확도를 독립 기준 없이 확정하지 않는다.
7. 일정 속도·여러 방향·입력/높이 누락 복구를 시험한다.
8. 이륙 정지 기준의 큰 튐·지속 편향을 거부한다.
9. 기록 좌표를 바꾸지 않고 인위적 공백을 시험한다.
