# A-cache 전환 비용 구분
Python 고정 기하 재사용 후보의 비용 기록이다.
실측 효과와 운영 전환 작업을 비교할 때 읽는다.

후속 제품 통합에서 기동·status audit와 영구 회귀 검사를 추가했다.
이 문서의 보류·남은 작업은 A/B 시험 종료 당시 상태다.
현재 계약과 완료 범위는 [제품 계약](../architecture/btf_acache.md)을 따른다.

## 실제 변경 범위
설정 변경 후 재시작 조건과 국소 개선을 확인했다.
시험 후보를 유지하고 운영 적용은 보류한다.
순간 XY 중앙값은 약 0.44~0.46ms 줄었다.
전처리 중앙값은 약 27~31% 줄었다.
전체 큰 지연·출력 공백은 개선과 악화가 섞였다.
[실측 보고서](btf_acache_ab_20261015.md)를 기준으로 판단한다.

제품 후보는 2파일, 추가 55줄·삭제 1줄이다.
공통 시간 계측과 시험 하네스는 이 수에서 제외한다.
새 C++ 라이브러리나 ctypes 호출은 추가하지 않는다.
기존 NumPy와 기존 B_TF C++ 핵심을 사용한다.

## 비교의 의미
이전 C++ 후보는 4파일 +164/-3줄이었다.
이번 후보는 높이 투영을 바꾸지 않는다.
범위가 달라 줄 수나 효과를 그대로 맞비교하지 않는다.
별도 라이브러리·ABI 관리가 없다는 차이는 분명하다.
실행 중 좌표 갱신 기능은 구현하지 않는다.
지원하려면 캐시와 기존 C++ 핵심·이력을 함께 갱신해야 한다.
그 작업은 이번 비용에 포함하지 않는다.

## 판단 기준
인건비 단가나 작업 시간을 추정해 금액을 만들지 않는다.
국소 절감과 전체 지연 개선을 구분한다.
설정 변경 후 재시작이 새 배치를 반영하는지 확인한다.
Claude 44차 사전 검토와 45~46차 결과 검토·정정을 반영했다.
낮은 추가 관리 비용에 비해 국소 효과가 있다는 의견이었다.
큰 지연과 인과적으로 무관하거나 회귀가 없다고 단정하지 않는다.
운영본 변경·실기 배포는 보류한다.
