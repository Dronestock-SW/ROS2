# LiDAR 보정의 속도별 비교 절차

UWB·LiDAR 보정 강도를 비교하는 시험 절차다.
예측·관측 보정의 후보값을 정할 때 읽는다.

## 진행 순서

**시간 정렬 후 고정 설정과 속도별 설정을 비교한다.**
2026-09-28 사용자는 예측·관측 보정 우선안에 동의했다.
속도마다 적절한 값을 시험하자는 의견도 제시했다.
아래 수치는 시뮬레이션 탐색 제안이다.
실측 최적값이나 비행 적용값은 아직 없다.

```text
동시 센서 기록 → 좌표·장착·시간 정렬
 → 고정 설정 → 속도별 설정 → 품질까지 반영한 설정
 → 같은 기준값으로 평가 → 별도 세션에서 재확인
```

비행용 상태추정기는 PX4 EKF2로 유지한다.
companion은 관측과 불확실성을 제공한다.
스무딩은 필터링 결과를 본 뒤 추가 비교한다.
지연된 관측의 시각 정렬은 첫 시험부터 수행한다.

## 1. 비교 입력 준비

같은 세션의 관측과 독립 기준값을 확보한다.

| 입력 | 기록할 내용 |
|---|---|
| UWB | RAW·보정 위치·측정 시각·수신 시각 |
| LiDAR | 스캔·스캔매칭 결과·시각·정합 품질 |
| IMU·PX4 | 자세·위치·속도·융합 상태·위치 reset |
| 목표 | 좌표·명령 시각·속도·가속도 제한 |
| 기준값 | Gazebo 정답 또는 독립 실측 위치 |
| 실행 조건 | 지도·장착값·설정·코드 버전 |

좌표계와 기체 기준점을 먼저 맞춘다.
측정 시각과 도착 시각을 구분한다.
LiDAR 입력은 상대이동인지 지도 위치인지 명시한다.
상대이동만으로 초기 절대 위치 편향을 교정하지 않는다.
이유: 같은 이동량에도 서로 다른 출발점이 가능하다.

UWB를 이미 쓴 LiDAR 위치의 계보도 기록한다.
같은 관측을 독립 정보로 두 번 융합하지 않는다.
평가용 정답은 시험 중 추정기에 전달하지 않는다.
정답으로 잡음 통계를 맞추는 일은 조정 자료에서만 한다.

## 2. 지연과 센서 오차 분리

속도별 보정 강도 전에 시간 지연을 확인한다.
등속 이동에서 미보정 지연의 위치 차이는 약 v×지연이다.

| 속도 | 미보정 지연 0.1초의 위치 차이 |
|---|---:|
| 0.2m/s | 2cm |
| 0.5m/s | 5cm |
| 1.0m/s | 10cm |

위 표는 산술 예시다. 센서 실측 결과가 아니다.
가속·회전 구간은 이 등속 근사와 구분한다.
지연을 맞춘 뒤 남은 오차로 설정을 비교한다.

## 3. 속도와 움직임별 기록

정지부터 시작해 같은 경로를 여러 속도로 반복한다.

| 조건 | 첫 시뮬레이션 제안 | 확인 항목 |
|---|---|---|
| 정지 | 0m/s | 편향·흔들림 |
| 저속 직선 | 0.2m/s | 이동량·지연 |
| 중속 직선 | 0.5m/s | 이동량·지연 |
| 빠른 직선 | 0.8m/s | 관측 품질·추종 오차 |
| 각 속도에서 정지·반전 | 같은 가속도 제한 | 최대 오차·정착시간 |
| 회전·가림·단절 | 같은 경로의 별도 구간 | 정합 실패·복구 |

속도값은 운용 제한이나 실기 허용값이 아니다.
목표 속도와 실제 추정 속도를 함께 기록한다.
가속도·회전율·관측 주기도 기록한다.
정지 판정 속도와 유지시간은 평가 전에 고정한다.
현재 합격 임계값은 미정이다.

## 4. 비교 후보 고정

센서 입력을 같게 두고 보정 정책만 바꾼다.

| 후보 | 바꾸는 항목 | 비교 목적 |
|---|---|---|
| 기준선 | LiDAR 보조 없음 | LiDAR 추가 효과 |
| A | 고정 관측 잡음 설정 | 기본 예측·관측 보정 |
| B | 속도에 따른 관측 잡음 설정 | 속도별 조정의 추가 효과 |
| C | 속도·정합 품질에 따른 설정 | 품질 반영의 추가 효과 |

모든 후보에 같은 시간 정렬을 적용한다.
A/B/C의 필수 유효성·단절 판정은 같게 둔다.
C는 유효 관측의 품질에 따라 불확실성을 조절한다.
속도가 높을수록 더 강하게 보정한다고 미리 정하지 않는다.
이유: 예측 오차와 LiDAR 오차가 함께 커질 수 있다.
관측 잡음은 축별 오차와 편향을 대조해 정한다.
불확실성을 키우는 것만으로 편향 교정을 대체하지 않는다.

EKF의 보정 이득 K는 공분산으로 계산된다.
속도별 고정 K 표를 PX4에 직접 적용하지 않는다.
관측 잡음 설정과 실제 이득은 구분해 기록한다.
UWB·LiDAR의 PX4 입력 경로는 구현 전에 확정한다.
두 노드가 같은 외부 위치 입력에 번갈아 발행하지 않는다.
이유: 관측의 출처와 좌표 기준이 뒤섞일 수 있다.

단순 보정식은 파일 비교 후보로만 둘 수 있다.
이 경우 alpha는 보정 차이를 반영하는 비율이다.
alpha=0.02를 매 관측에 쓰면 주기에 따라 반응이 달라진다.
주기 영향을 분리할 때는 다음 식을 시험할 수 있다.

```text
alpha(dt) = 1 - exp(-dt / tau)
```

dt는 새 유효 관측 사이의 초 단위 간격이다.
tau는 반응 시간 상수이며 단위는 초다.
이는 1차 보정 예시이며 EKF 이득 공식이 아니다.
장시간 단절은 별도 복구 규칙으로 처리한다.
이유: 큰 dt를 그대로 쓰면 복귀 때 보정이 급해진다.
alpha·tau의 운용값은 선정하지 않았다.

## 5. 평가와 후속 판단

조정 자료와 평가 자료를 세션 단위로 나눈다.
[공통 비교 절차](90_evaluation.md)의 자료 분리를 따른다.

| 평가 항목 | 보고할 값 |
|---|---|
| 위치·이동량 | 축별 편향·RMSE·p95·최대 오차 |
| 정지·반전 | 목표 통과량·정착시간·위치 흔들림 |
| 시간 | 관측 나이·잔여 지연·계산 시간 |
| 단절·가림 | 새 관측 가용률·최대 점프·복구 시간 |

관측과 예측이 가까워진 것만으로 개선을 판정하지 않는다.
독립 기준값 대비 오차를 함께 확인한다.
같은 로그 재생은 추정 성능의 비교다.
보정으로 비행 경로가 바뀌는 효과는 SITL에서 확인한다.
SITL에서는 같은 임무·외란 조건으로 후보를 비교한다.
실기 검증은 별도 완료 항목이다.

고정 설정으로 충분하면 속도별 정책을 추가하지 않는다.
시간·좌표 정렬 뒤에도 오차가 남으면 원인을 분류한다.
스무딩의 추가 효과는 같은 로그에서 먼저 비교한다.
미래 관측을 이용한 과거 오차와 실시간 오차를 구분한다.
