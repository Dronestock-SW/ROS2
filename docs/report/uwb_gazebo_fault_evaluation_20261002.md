# Gazebo 이상·복구 평가 확인 기록
이 문서는 2026-10-02 구간 평가의 확인 기록이다.
실제 시행을 평가하기 전 코드·배포본의 범위를 확인할 때 읽는다.

## 구현 결과

전체 통계를 유지하며 정상·이상·복구를 분리했다.
새 관측의 복구 시간을 표본 시각으로 기록한다.
실제 기체의 복구·융합·7cm 달성은 미검증이다.

| 항목 | 반영 내용 |
|---|---|
| 공통 통계 | flight_metrics 모듈로 분리 |
| 구간 평가 | flight_fault_evaluation 모듈 추가 |
| 구간 기록 | scenario_metrics.csv와 표본별 구간 ID |
| 주입 근거 | 원래 RAW·변경 RAW·계획·발행 기록 대조 |
| 복구 초기값 | 관찰 2초, 신선도·7cm 조건 유지 0.5초 |
| 누락·실패 | 전체 분모 유지. 미상 복구 시간은 null |
| 과거 자료 | 이상 계획이 없으면 unclassified |
| 검증 한계 | 합성 기록·모의 통신. WSL 비행 미실시 |

## 확인 결과

관련 시험 44개가 2.22초에 통과했다.
기본 ZIP과 누적 파일의 별도 폴더에서는 68개가 통과했다.
소요 시간은 15.42초다. 두 시험 수를 합산하지 않는다.
전체 빌드는 5개 패키지가 9.72초에 성공했다.
설치 경로에서 새 모듈을 불러오는 것도 확인했다.
CLI 도움말 3개와 별도 폴더의 로딩 경로도 확인했다.

단절 누락·복구 중 재이상·짧은 기록을 시험했다.
다음 이상이 복구 구간을 자르는 경우도 확인했다.
마지막 평가 시각의 경계와 RAW 변조 거부를 확인했다.
이 결과를 실제 비행 성공으로 사용하지 않는다.

## 남은 작업

Windows의 WSL 실행 접근과 현 상태 확인이 필요하다.
현재 대화의 셸은 SSH 대상 Jetson에서 실행된다.
WSL의 같은 세션에서 센서·시계·관측·PX4를 기록해야 한다.
정상 이동 뒤 별도 이상 시행을 실제로 평가한다.
관측 복구와 제동·착륙·임무 재개는 각각 검증한다.
