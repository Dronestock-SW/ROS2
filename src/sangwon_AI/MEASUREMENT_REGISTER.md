# 확정값·실측값·보류 항목
이 문서는 상세 명세의 파라미터와 미결정을 한곳에서 관리한다.
구현 설정을 만들거나 시험 결과로 값을 승인할 때 읽는다.

상태: 내부 정책 확정, 실기체 프로파일 실측 대기 / 2026-10-02.
‘시험값’은 사용자와 정한 첫 시험 기준이며 실비행 성능 승인값이 아니다.
미정값의 null은 설정 누락이다. 0·무한대·임의 기본값으로 실행하지 않는다.

## 1. 정해진 정책·시험값

| 항목 | 값 | 상태 |
|---|---|---|
| 장애물 우회 불가 대기 | 10초 | 사용자 결정 |
| 위치 복구 최대 대기 | 8초, 유지 불가면 즉시 Land | 사용자 결정 |
| Jetson 저전력 복귀 | 유효 잔량 30% 이하 | 사용자 결정, 복귀 에너지 검증 필요 |
| 웹 명령 신규 수락 | 생성 후 10초 미만 | 사용자 선택 초기 시험값, 현재 세션 조건도 필요 |
| yaw 도착 허용 | ±10° | 사용자 선택 초기 시험값 |

| 목표 도달 실패 | 해당 목표 실패→복귀, 복귀 불가 시 착륙 | 사용자 결정 |
| 비행 중 필수 기록 실패 | 복귀 후 착륙, 복귀 불가 시 착륙 | 사용자 결정 |
| 언어 분담 | 핵심 AI/BT·계획·비행 출력 C++, 보조 어댑터·웹·로그 Python | 사용자 결정 |

## 2. 측정 후 정할 파라미터

단위는 s, m, rad, m/s, Hz를 기본으로 한다.

| ID·기호 | 의미 | 확정 방법·근거 |
|---|---|---|
| M01 E_xy·E_z | 경유점 도착 오차(m) | UWB/PX4 융합 오차와 실제 목표 유지 분포·기체 여유 |
| M02 T_arrival·V_arrival_xy/z | 연속 안정 시간(s)·속도(m/s) | 통과 이동과 정지 도착을 구분하는 제한 비행 |
| M03 T_recover_stable | 복구 후 연속 정상 시간(s) | 단발 정상/재단절 로그와 좌표 불연속 검증 |
| M04 T_observation_stale | 마지막 새 관측의 최대 나이(s) | UWB 전체 사양·지연/공백 실측 뒤 결정 |
| M05 T_lease | 행동 의도 유효기간(s) | 정상 최대 지연+여유와 허용 이동거리/제동거리 비교 |
| M06 f_bt·f_setpoint | BT 평가·목표 송신률(Hz) | Jetson 부하/통신 시험, PX4 최소조건에 충분한 여유 |
| M07 T_prestream | Offboard 선행 송신 시간(s) | PX4의 1초 초과 조건·최대 송신 공백 확인 |
| M08 T_mode·T_arm·N_mode | 전환/시동 확인 시간(s)·재시도 한도(정수) | 수락·거부·응답 유실·늦은 전환 시험 |
| M09 T_takeoff·T_vertical·T_yaw | 상승/수직/회전 완료 한도(s) | 목표 변화량·실제 제한·정체 시험 |
| M10 T_plan·T_prepare | 계획/준비 계산 한도(s) | 지도 크기·최악 부하 시험 |
| M11 T_segment·T_progress | 구간 완료·진행 정체 한도(s) | 경로 길이·속도·정지 상황, D03 정책과 결합 |
| M12 T_land | 착륙 진행 경고 시각(s) | 고도별 하강·land detector·자동 disarm 시간 |
| M13 T_clock_error·T_link_stale | 웹 시계 오차·통신 단절 판정(s) | 왕복 지연·재연결·시계 점프 시험 |
| M14 margin_xy/z·회전 여유 | 충돌 검사 여유(m) | 프로펠러 포함 외형·측위 오차·제동거리·지도 오차 |
| M15 PX4 속도/가속/배터리 설정 | 실제 운용 제한 | 파라미터 스냅샷과 기체 시험, 위험 잔량 Land 검증 |
| M16 최소 기록 여유 | 새 비행에 필요한 저장공간(bytes) | 최대 임무 길이·실측 기록률·보존/수집량 |
| M17 복귀점·방향 확인 오차 | 시작/복귀 승인 기준(m, rad) | 출발점 실측·yaw 검증 구역·기체 설정 |
| M18 T_log_stale·큐 상한 | 필수 기록 생존/쓰기 지연(s)·기록 대기 상한 | 기록 부하·프로세스 중단·디스크 실패 시험 |
| M19 경로 탐색 설정 | 격자 해상도(m)·최대 노드/거리·진행 개선 기준 | 장애물 형상·최악 지도 부하·실제 정체 측정 |
| M20 PX4 품질 입력 나이 | 자세/위치·모드·품질·배터리별 최대 나이(s) | 실제 송신률·통신 공백·실패 검출 지연 |

T_lease는 숫자가 바뀌는 간격이 아니라 판단의 유효기간이다.
정상 지연보다 길어야 하고, 만료까지 이동한 거리와 제동거리가 안전 여유 안에 있어야 한다.
두 조건을 함께 만족하지 못하면 단순히 timeout을 늘리지 않고 구조·속도를 재검토한다.
실측에는 평균만 쓰지 않고 최대 공백·지연 분포·차폐/부하 조건을 남긴다.

## 3. 결정 상태와 외부 적용 조건

| ID | 항목 | 현재 처리 |
|---|---|---|
| D01 | 8초 이내 위치 복구 후 재개 승인 | 확정: 연속 정상·PX4·좌표계·남은 경로 재검증 후 자동 재개 |
| D02 | 비행 중 행동·센서 기록 실패 | 확정: 복귀 후 착륙. 복귀 불가 시 현재 위치 착륙 |
| D03 | 장애물 없이 이동/회전 정체 | 확정: 해당 목표 실패·복귀, 복귀 불가 시 착륙. 물리 한도는 M09/M11 |
| D04 | Python/C++·BT 라이브러리 | 확정: 핵심 C++, 보조 Python. BehaviorTree.CPP 4 계열 채택·패치 버전 빌드 시 고정 |
| D05 | UWB 입력·PX4 융합 | 전체 사양 수령 뒤 어댑터·메시지·담당·불확실성 모델 설계 |
| D06 | 웹 JSON·버전·좌표 표기 | WEB_JSON_DRAFT의 구체안으로 웹팀과 합의 |
| D07 | PX4 품질·reset·RC/failsafe 판정 신호 | 수신 설계와 필드 대응은 PX4_INTERFACE 기준, 실장/품질 매핑 승인 필요 |
| D08 | pause/선점 후 임무 호버 시간 | 확정: 기존 연속 체류 요구에 따라 중단/조건 이탈 뒤 안정 판정·체류를 처음부터 계산 |

내부 구현은 [IMPLEMENTATION_BASELINE.md](IMPLEMENTATION_BASELINE.md)의 SIM-01로 재현한다.
M01~M20은 실기체 프로파일 승인 항목이다. 합성 시험값으로 실측 완료 표시를 하지 않는다.
D05는 UWB 전체 사양 수령 후, D06은 웹팀 회신 후 해당 어댑터를 확정한다.

## 4. 값 승인 기록 형식

2026-10-04 QR 보완은 [QR_SCAN_SPEC.md](QR_SCAN_SPEC.md)를 함께 따른다.
스캐너 최대 3회→카메라→성공/실패 기록→접근 대기점 복귀→다음 목표는 확정이다.
마커 획득 한도 실패·카메라 고장도 비행·이탈 정상 시 실패 기록→대기점 복귀→다음 목표다.
웹 scan XYZ는 라벨 위치로 확정했다. 기체 목표는 방향·거리·장착 변환으로 따로 계산한다.
웹에 라벨별 접근·작업 허용 구역을 요청하기로 확정했다(RV03).
라벨 정면 방향/기준점 표현·허용 구역 JSON은 웹 회신 항목(QS-W7/QS-W8)이다.
ArUco 미세 조정·호버 중 판독도 확정이다.
카메라·스캐너 전방 장착, 판독 0.40~0.60m는 초기 시험 범위다.
정밀 장착 오프셋·거리 기준·판독 성능·기체 여유를 실측한다.
시간·보정량·속도·안정 오차·관측 나이는 QS-M1~M5 실측 항목이다.
판독 실패와 기존 D03 이동 목표 실패를 구분한다.

각 값에 후보값·단위·근거 로그·시험 조건·기체/펌웨어/지도 개정·승인자·일자를 기록한다.
적용 가능한 운용 범위와 다시 측정해야 하는 변경 조건도 남긴다.
실측 없는 값은 ‘미정’ 또는 ‘시험값’ 상태를 유지한다.
UWB 정확도·융합, 고도·yaw, PX4 실패 동작 승인 전 자율 좌표 실비행은 보류한다.
