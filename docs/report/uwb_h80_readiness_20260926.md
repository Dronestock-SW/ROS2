# H80 입력 준비·로그 확인·합성 샘플 결과

2026-09-26 H80 착수 조건과 GitHub 최신화 결과를 기록한다. 실제 로그로 시험할 수 있는 범위와 남은 입력을 확인할 때 읽는다.

## 판단

**H80 수식 시험과 기존 거리 로그의 구조 확인은 가능하다.**
H80의 입력은 최근 거리 이력이다. 비행을 먼저 수행할 필요는 없다.
최근 약 0.8초의 앵커별 거리·측정 시각을 유지한다.
지상 정지·손으로 이동한 태그의 자료도 사용할 수 있다.
비행 경로·기존 추정 XY·자이로 적분값은 H80 회귀의 직접 입력이 아니다.

사용자는 A의 네 앵커 동일 가중 풀이를 비교 기준선으로 정했다.
현재 수행한 계산은 기존 Python 함수의 제한된 합성 시험이다.
실측 A/H80 정확도 비교와 전체 시험 실행기 구현은 남아 있다.

| 자료·조건 | 용도 | 현재 확인 |

| 앵커 좌표와 좌표계 | 거리의 공간 관계 | 저장소 지도 있음. 독립 측량 검증은 별도 |

| 네 앵커 각각 최소 3표본, 총 12표본 | ZIP 참고 구현의 최소 개수 | 초기 표본 수집 이후 충족 |
| 서로 다른 표본 시각·행렬 rank 7 | 일곱 회귀 계수 구분 | 기존 로그 구조 검사에서 충족 |

| 독립 기준 위치 | A 대비 실제 오차 평가 | 기존 사용자 보고 위치의 독립 검증 필요 |

0.8초는 보관할 최대 창 길이다.
자료가 0.8초 모두 쌓여야 수학적으로 시작하는 것은 아니다.
최소 표본·기하 조건과 실제 운용의 warmup 조건을 별도로 확인한다.
완성된 출력 경로의 시각 매핑·게이트·상태 검증도 별도다.
표본 수 충족을 최종 위치의 사용 가능 판정으로 바꾸지 않는다.

## 작은 합성 시험

기존 `solve_raw_xy`와 `fit_h80`을 파일 시험에서 직접 호출했다.
운용 파이프라인과 외부 출력 게이트는 열지 않았다.
ZIP 바이너리의 실행 결과나 C++ 완전 재현으로 표시하지 않는다.

| 시험 조건 | 값·범위 |
|---|---|
| 길이·주기·난수 | 8초, 40Hz, seed 7 |
| 거리 시각 | 네 앵커의 동시 표본. 실제 순차 측정은 후속 시험 |
| Z | `1.10 + 0.02*t`의 합성 입력. 잡음 시험의 관측 잡음 0.002m |
| 거리 편향 | 합성 RAW에 참고 네 값을 더하고 같은 값을 차감 |
| H80 | 창 0.8초, sigma 0.04m, Huber 0.12m, Python 반복 상한 8 |
| A | 네 앵커 동일 가중 비선형 풀이 |
| 추가 게이트 | 없음. A의 잔차·영역 거부 한도를 시험에서만 완화 |
| 평가 | 처음 0.8초 제외. 같은 시각·기준 위치로 288쌍 비교 |

| 상황 | A RMSE | H80 RMSE | A 대비 변화 |
|---|---:|---:|---|
| 정지 + 거리 잡음 σ=4cm | 4.23cm | 1.52cm | 약 64.0% 감소 |
| 위 잡음 + A2에 단발 60cm 튐 | 8.76cm | 1.68cm | 약 80.8% 감소 |
| 0.6m/s 이동 중 방향 반전 + σ=2cm | 2.14cm | 3.10cm | 약 45.0% 증가 |

각 상황에서 두 모델의 평가 구간 출력 비율은 100%였다.
무잡음 기하 시험은 두 함수의 최대 오차가 1μm 미만이었다.
표본 부족 시 H80 실패 반환도 확인했다.
개선율은 `100*(RMSE_A-RMSE_model)/RMSE_A`다.
A 오차가 사실상 0이면 개선율을 산출하지 않는다.

이 결과는 한 배치·한 seed의 계산 예시다.
실측 정확도나 일반적인 개선율로 사용하지 않는다.
방향 반전 결과는 시간창 안의 운동 근사가 깨질 때의 사례다.
따라서 정지 결과만으로 H80을 채택하지 않는다.
