# M12 RF·CIR 기반 거리 신뢰도

무선 진단값으로 거리의 예상 오차를 정하는 명세다. 단순 거리 가중과 무선 품질 가중을 비교할 때 읽는다.

## 목적과 현재 상태

무선 품질을 거리 분산의 입력으로 시험한다.
현재 입력이 CIR 전체를 제공한다고 가정하지 않는다.
펌웨어 필드·단위·지원 여부를 먼저 확인한다.
AI 모델 도입은 이 시험안의 범위에 포함하지 않는다.

## 입출력

| 방향 | 파라미터 | 형식·단위·조건 |
|---|---|---|
| 입력 | `observation` | Observation과 같은 obs_id |
| 입력 | `native_rf_fields` | 장치 원래 이름·단위·값의 object |
| 입력 | `cir_samples` | 복소/진폭 표본 배열 또는 null |
| 입력 | `capability_map`, `device_calibration_id` | 필드 매핑·장치/채널 버전 |
| 출력 | `quality_features` | 검증한 특징값·유효성·계보 |
| 출력 | `sigma_range_m`, `quality_class` | 예상 거리 오차·unknown/nominal/suspect |
| 출력 | `reason`, `quality_model_id` | 적용 근거·교정 버전 |

## 설정

| 파라미터 | 단위·범위 | 초기 상태 |
|---|---|---|
| `feature_set` | 지원 필드 ID 목록 | 자료 확인 전 미확정 |
| `quality_mapping` | none/calibrated_bins | none 기준선 |
| `sigma_floor_m`, `sigma_cap_m` | m | 교정 자료로 결정 |
| `missing_policy` | unknown/calibration_baseline | 실행 전에 고정 |
| `quality_max_age_s` | s | 같은 측정 연결 기준. 미확정 |

## 처리 구조와 산식

```text
장치 진단 → 필드·단위 검사 → 특징값 계산
         → 교정표 조회 → sigma_range → M09/M04 품질 입력
```

가능한 특징은 초기 경로·전체 수신 에너지의 관계 등이다.
장치가 제공하지 않는 값을 임의 생성하지 않는다.
교정 구간별 `sigma_m = spread(range_error)`를 추정한다.
중앙 편향은 M03의 교정 항목과 분리해 기록한다.
실행 시에는 위치 정답을 입력받지 않는다.
같은 tag·anchor·채널의 자료에 적용 가능한지 검사한다.
가중 풀이에서 `1/sigma^2`로 사용할 수 있다.
무선 품질 점수를 거리에서 직접 차감하지 않는다.

## 실패와 상태

강한 수신 신호만으로 직접 경로라고 확정하지 않는다.
필드 부재는 unknown이며 좋은 품질의 0 오차가 아니다.
오래된 진단값을 새 거리와 연결하지 않는다.
다른 장치에서 만든 교정표의 재사용은 별도 평가군이다.

## 테스트와 평가

| 시험 | 확인할 결과 |
|---|---|
| 누락·단위 변경·범위 밖 진단 | unknown과 사유 |
| 거리/진단 순서 어긋남 | obs_id 연결 실패 검출 |
| 직접 경로·사람 가림·금속 반사 | 품질 구간별 실제 거리 오차 |
| 장치·태그·장소 변경 | 오차 모델의 이전 가능성 |
| 기본 sigma 대비 적용 | 위치 오차·출력률·과신 비율 |

CIR 수집 가능 여부부터 미확정이다.
관련 자료가 없으면 이 모듈을 제외한 비교군을 먼저 구성한다.
