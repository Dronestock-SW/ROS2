# UWB·수평 LiDAR 후속 작업 절차
오프라인 분석 뒤 SITL을 준비하는 절차다.
다른 작업 세션에서 연구·구현을 이어갈 때 읽는다.

## 시작 상태

분석은 끝났고, SITL 실행은 아직 하지 않았다.
[지상 분석 기록](../report/lidar_ground_analysis_20261012.md)을 먼저 읽는다.
[로드맵](../roadmap.md)의 EKF2 단일 책임을 유지한다.
[고도 원칙](../altitude_policy.md)과 기존 C++ 경계를 따른다.

| 구분 | 뜻 | 현재 상태 |
|---|---|---|
| SITL | PC에서 PX4와 가상 기체로 시험 | 이 후보는 미실행 |
| Sim-to-Real | 가상 시험 결과를 실기로 옮겨 검증 | 이번 작업에서 미수행 |
| 이번 문서화 | 지상 결과와 시험 계획 전달 | 완료 |

SITL 성공은 실기 성공이 아니다.
가상 센서가 실제 반사·진동을 모두 재현하지 못한다.

## 1. 입력과 기준점을 확인한다

최신 브랜치와 원본 해시를 먼저 확인한다.
다른 사람의 수정이 있으면 별도 작업 공간을 쓴다.

1. `feature_uwb`의 최신 상태와 `AGENTS.md`를 읽는다.
2. 보고서의 capture ID와 SHA-256을 확인한다.
3. 원본을 못 찾으면 누락 항목을 기록한다.
4. 실기 펌웨어 조회 근거와 SITL 커밋을 대조한다.
5. 수평 LiDAR와 하향 TFmini Plus를 구분한다.
6. UWB 아래 약 10cm는 추정값으로 보존한다.

실기 확인 커밋:

```text
d6f12ad1c4f70ad3230afd7d86e971421e02fef4
```

다른 beta 커밋으로 이 검증을 완료 처리하지 않는다.
이유: 시작·리셋·분산 처리 경로가 다를 수 있다.
도구·소스가 없으면 환경 준비까지만 완료로 적는다.

## 2. 이동량 기준선을 재현하고 개선한다

연속 누적 회전 문제를 재현한 뒤 개선한다.
기존 간이 구현을 정답으로 취급하지 않는다.

| 작업 | 확인할 결과 |
|---|---|
| 기존 기준선 재현 | 연속 누적 yaw 약 −267°와 첫 스캔 정합 차이 |
| 변환 방향·부호·대응점 점검 | 동일 입력 0, 알려진 이동 복원, 양방향 일관성 |
| 드라이버 시각 점검 | 430개 점과 광선 시간 합의 불일치 원인 |
| 기준 스캔·지역 지도 정합 | 단순 연속 누적 대비 장기 안정성 |
| IMU 회전 일관성 | LiDAR 회전을 실제 기수 변화로 오인하지 않음 |
| 별도 이동 기록 평가 | 알려진 X/Y 왕복과 회전에서 성능 유지 |
| 불리한 환경 평가 | 평행 벽·반복 선반·가림·움직이는 물체 |

같은 정지 자료에 맞춘 임계값을 일반화하지 않는다.
이유: 실제 이동을 제거해도 정지 결과는 좋아질 수 있다.
정합 잔차·조건수만으로 공분산을 확정하지 않는다.
지상 반복성과 독립 정답 대비 오차를 따로 기록한다.
새 코드가 필요하면 `src/` 패키지에 둔다.

## 3. 외부 입력 후보를 격리 설계한다

1번 후보는 UWB 위치와 LiDAR 속도의 EKF2 융합이다.
2번 companion 위치 필터로 자동 전환하지 않는다.
이유: 로드맵 결정 10과 상관관계 검토가 필요하다.

| 계약 | 후보·검증 항목 |
|---|---|
| 기준점 | LiDAR 속도를 UWB 안테나 속도로 보정 |
| 장착 벡터 | body FRD의 UWB→LiDAR `(0,0,+0.10)m`, 추정 |
| 민감도 | 0.05/0.10/0.15m에서 roll/pitch 영향 비교 |
| 속도 관계 | `v_UWB = v_LiDAR - ω × r_UWB→LiDAR` |
| 이중 보정 | 기존 PX4 UWB→IMU 보정과 중복하지 않음 |
| 시각 | 위치와 구간 평균 속도의 실제 관측 시각 대응 |
| 발행자 | 하나. UWB와 LiDAR를 임의 교대 발행하지 않음 |
| 데이터 공백 | 오래된 값을 새 시각으로 반복하지 않음 |
| 수직 속도 | 유한 자리값+큰 분산은 SITL 후보일 뿐 |
| 고도·자세 | 기존 PX4 책임 유지. companion 제어 추가 없음 |

2D 스캔에 없는 수직 운동을 측정값으로 만들지 않는다.
기울어진 스캔의 기하·공분산 변환도 평가한다.
위치와 속도를 묶기 위한 시각 처리를 명시한다.
보간·필터를 쓰면 상관관계와 원본 이력을 남긴다.
PX4 추정치를 독립 관측으로 되먹이지 않는다.

## 4. 같은 커밋에서 SITL을 실행한다

14개 시험은 설계 상태다. 결과를 채워야 한다.
[기계 판독 명세](../report/evidence/lidar_ground_20261012/sitl_plan.json)를 따른다.
기본 120초와 seed 11/22/33/44/55를 사용한다.
0–20초 정렬, 20–40초 정상 구간을 둔다.
40초에 조건을 주입하고 복구를 관찰한다.
각 시험에 맞게 구간을 조정하고 변경을 기록한다.

| ID | 시험 | 반드시 확인할 항목 |
|---|---|---|
| S01 | 기본 수신·축·시각 | 전송과 실제 융합 구분 |
| S02 | 공급 분산·noise mode | z 분산 1/100/1e4/1e6 전달 |
| S03 | NaN·잘못된 입력 | 3축 유효성·frame·timestamp 거절 |
| S04 | 정지·이동 중 시작 | 속도 평균 리셋·수직 운동 손실 |
| S05 | 0/5/10/20° 기울기 리셋 | 큰 z 분산의 수평 투영 |
| S06 | LiDAR 중단·복구 | UWB 유지·오래된 속도 처리 |
| S07 | UWB 중단·복구 | 절대 위치의 잘못된 유지 방지 |
| S08 | 공통 샘플 발행 정책 | 공통 시각·quality·reset 영향 |
| S09 | 지연·중복·시계 점프 | innovation·timeout·복구 |
| S10 | UWB 아래 장착 거리 | 5/10/15cm·회전·이중 보정 |
| S11 | 불리한 장면 | 작은 잔차의 잘못된 정합 검출 |
| S12 | 기존 UWB+광류와 비교 | 정상·광류 저하·UWB 편향의 추가 가치 |
| S13 | 수직 aiding 부수 효과 | vertical last-fuse 갱신 영향 |
| S14 | 추정기 통과 뒤 폐루프 | Position·Offboard 추종·실패 전환 |

UWB+광류 기준선과 LiDAR 추가안을 같은 seed로 비교한다.
시뮬레이터 정답은 평가에만 쓴다.
실제 임무의 허용 오차는 실행 전에 정한다.

| 평가 | 기록할 내용 |
|---|---|
| 위치·속도 | 정답 대비 RMS·p95·최대 오차 |
| 가용성 | 실제 융합률·관측 거절·공백 |
| 리셋 | 평균·공분산·reset counter·이벤트 |
| 수직 상태 | 고도·수직 속도·마지막 융합 시각 |
| 복구 | 중단 뒤 정상 회복까지 시간 |
| 폐루프 | 궤적 추종·기울기·고도·실패 전환 |

정상 성능을 악화시키는지 먼저 확인한다.
목표 고장 상황에서 개선되는지도 확인한다.
수직 리셋·오래된 입력 오인이 남으면 채택하지 않는다.
이유: 관측 추가가 기존 추정을 훼손할 수 있다.
SITL 실패와 미실행을 구분해 보고한다.

## 5. 실기 이전의 남은 자료를 구분한다

비행 성능 판정에는 실제 비행 원본이 필요하다.
원격 기록 목록만으로 공중 구간을 확정하지 않는다.
동일 시행의 ULog·LiDAR·UWB·IMU를 맞춘다.
17:29 왕복의 ROS 기록은 비행 전 끝난 정황이 있다.
다른 시행의 기록으로 이 공백을 채우지 않는다.

이 절차의 다음 작업 범위는 오프라인·격리 SITL이다.
실기 설정·서비스·비행 변경은 별도로 다룬다.
현재 운영 중인 기체나 main 작업을 중단하지 않는다.

아래 내용을 새 작업 세션에 전달한다.

```text

다음 두 문서를 작업 인계 기준으로 사용해줘.
- docs/report/lidar_ground_analysis_20261012.md
- docs/runbooks/lidar_uwb_sitl_handoff_20261012.md

목표는 수평 LiDAR 관측의 신뢰성을 개선하고,
UWB 위치+LiDAR 속도를 PX4 EKF2에 넣는 1번 후보를
오프라인과 격리 SITL에서 검증하는 것이야.

센서는 두 개야. 하향 TFmini Plus와 360도 T-mini Pro를 구분해줘.
수평 LiDAR는 UWB 안테나 바로 아래 약 10cm라는 추정이야.
FC 바로 아래 10cm나 실측 완료로 해석하지 마.

지상 1,781스캔 분석은 완료됐고 SITL은 14개 항목 설계만 됐어.
연속 정합 누적 yaw 약 -267도는 간이 구현의 결과야.
실제 기체 회전이나 센서 고장으로 확정하지 마.
원본 해시와 분석 방법을 확인하고 이 결과부터 재현해줘.
대응점·부호·시각/각도 재표본화 원인을 조사해줘.

원본이나 실행 환경이 없으면 누락 항목과 가능한 작업을 나눠 보고해줘.
미실행을 통과로 표시하지 마. 가능한 오프라인 준비는 계속해줘.
실기 FC 파라미터·서비스·비행은 변경하지 마.
```
