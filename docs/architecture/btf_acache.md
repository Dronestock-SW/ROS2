# B_TF 순간 XY 기하 캐시 계약
고정 앵커 기하의 재사용 범위와 수명을 정하는 기준이다.
앵커 설정을 바꾸거나 B_TF 계산을 수정할 때 읽는다.

## 채택 범위

**같은 배치의 계수는 한 번 만들고 현재 거리로 XY를 계산한다.**
4앵커 순간 XY의 매회 lstsq를 초기 lstsq(M,I)로 옮겼다.
거리·rhs·XY·잔차는 매 주기 새로 계산한다.
ToF·IMU 선택과 창 기반 B_TF native 계산은 유지한다.
최신 브랜치의 3앵커 native 경로는 먼저 반환한다.
이 경로에는 순간 XY 캐시를 사용하지 않는다.

| 구분 | 계약 |
|---|---|
| 소유 | MeasuredBtf 인스턴스마다 한 개 |
| 입력 | 앵커 설정의 사본, 앵커 순서 0·1·2·3 |
| 보존 | 기하 행렬·상수항·분모·변환 계수는 읽기 전용 |
| 거부 | 기존 rank 2·조건수 30 기준 유지 |
| 잔차 | 기존 정규화 최대 잔차, 물리 거리 RMS가 아님 |
| reset | ClockMap·모델 reset 후 같은 캐시 유지 |
| 배치 변경 | 관련 설정을 맞춘 뒤 프로세스 재시작 |
| 식별 | 시작 로그·주기 status의 instant_xy_cache |
| 유효 범위 | 유한 좌표·거리, 인스턴스 수명 중 고정 설정 |

실행 중 config dict를 바꿔 배치를 적용하지 않는다.
이유: 캐시뿐 아니라 기존 native와 이력도 함께 갱신해야 한다.
비유한 좌표가 있으면 초기화 시점에 실패할 수 있다.
이 경우는 기존 경로와 실패 시점이 같다는 주장 범위 밖이다.

## 효과와 비용

**현재 부분 입력에서 순간 XY 중앙값 약 0.44~0.46ms를 줄였다.**
같은 기준의 A C C A A C C A 순서로 비교했다.
4쌍 XY wall p50 절감은 69.65~71.19%다.
전처리 전체 p50 절감은 27.09~30.87%다.
process p50 절감은 4.33~7.12%다.
p95/p99와 출력 공백은 개선·악화가 섞였다.
캐시를 큰 지연의 해결책으로 보지 않는다.
새 C++ 라이브러리·ABI는 추가하지 않았다.
기존 NumPy로 계산하고 캐시 생성은 프로세스당 한 번이다.
[A/B 결과](../report/btf_acache_ab_20261015.md)와
[비용 구분](../report/btf_acache_cost_20261015.md)을 따른다.

## 기준별 검증

**시험·통합·실제 운영의 기준 커밋은 서로 다르다.**

| 대상 | 기준 | 확인 범위 |
|---|---|---|
| A/B 시험 | 563960e + 공통 계측 / 같은 기준 + 캐시 | 계약 2,763·고정 시퀀스 4쌍·ROS 재생 8회 |
| 운영 적용 | 캡처한 0110da8 운영 소스 + 제품 3파일 | 계약 2,763·관련 검사 111·drone_uwb colcon·기동·센서 수신 |
| 이번 통합 | a029476 + 제품 3파일 | Windows Python 경로 관련 검사 116개, 아래 영구 검사 포함 |

이번 통합은 기존 IMU·epoch·3앵커·거리 진단 변경을 보존했다.
계측용 타이머와 시험 probe는 제품에 넣지 않았다.
새 통합 전체를 운영 슬롯에 다시 배포한 것은 아니다.
새 통합의 ROS 전체 빌드·native 실행·재생은 미실시다.
이전 운영 조합의 빌드·시험을 새 조합 검증으로 대체하지 않는다.

영구 검사: `src/drone_uwb/test/processing/test_cached_xy.py`.
기존 solve_xy를 기준으로 2,763개 수치·거부 사례를 대조한다.
조건수 경계·순서·3앵커 함수 조합·회전·이동·잔차를 포함한다.
3앵커 검사는 함수 계약이며 제품 부분 프레임 경로를 바꾸지 않는다.
입력 사본·배열 쓰기 금지·거리 갱신·reset 유지도 확인한다.
별도 OS 프로세스로 설정 파일 변경·재시작을 검사한다.
현재 영구 수명 검사는 Python backend를 사용한다.
이전 운영 계약은 실제 native backend로 수행했다.

Windows 체크아웃의 config 심볼릭 링크는 텍스트로 생성됐다.
검사용 사본에서만 실제 대상 내용으로 복원했다.
저장소 링크와 제품 소스는 변경하지 않았다.
관련 6개 검사 파일 결과는 116 passed, 11.04초다.
[검사 출력](../report/evidence/btf_acache_20261015/integration-pytest.txt)을 보존한다.
남은 solve_xy 호출과 해당 monkeypatch는 검색 결과 없었다.
제품 3파일과 새 검사의 AST 구문 확인도 통과했다.
캐시 모듈은 실제 배포본과 바이트 단위로 일치했다.
[통합 검증 식별값](../report/evidence/btf_acache_20261015/integration-verification.json)을 보존한다.
[Claude 50차](../report/evidence/btf_acache_20261015/claude-50.md)는 이식 차이를 검토했다.

## 남은 확인

큰 지연은 공통 정지 가설과 구간별 비용을 분리해 본다.
실제 운영에서는 RAW 거리 주기가 없어 cache calls=0이었다.
실측 XY 계산·발행과 비행 검증은 완료하지 않았다.
