장착값은 사용자의 최종 수정으로 반영했다.
FC 기준 LiDAR FLU는 `(0, 0, +0.10)m`다.
태그 FLU는 `(-0.10, 0, +0.07)m`다.
태그 높이는 사용자 추정이다.
거리의 독립 실측은 하지 않았다.
기존 ±15cm LiDAR 추정보다 이 기록이 우선한다.

yaw는 사용자가 놓은 표적 방향에 의존한다.
독립 각도 기준기로 교정한 값은 아니다.
수평면과 동적 시각 검증을 대체하지 않는다.
설정은 yaw만 반영하고 비활성 상태를 유지한다.

지상 TFmini Plus 범위는 약 0.02m였다.
유효 최소 거리 0.1m보다 작았다.
이 구간의 속도는 실제 비행 정확도 근거가 아니다.

펌웨어는 PX4 `d6f12ad1c4f70ad3230afd7d86e971421e02fef4` 기반이다.
실물과 같은 FMUv6C 대상으로 빌드했다.
실물 patch에는 SITL/HIL 변경을 넣지 않았다.
재현 도구는 `prepare_lidar_hardware.py`다.
별도 `PX4-lidar2d-fmu` 작업 트리만 허용한다.
빌드 명령은 `make px4_fmu-v6c_lidar2d -j2`다.

근거는 [evidence 폴더](evidence/lidar_physical_20261012)에 있다.
펌웨어·patch SHA256은 manifest에 기록했다.
원시 표적 데이터는 해당 JSON의 경로·해시로 식별한다.
Jetson의 기존 서비스와 원시 기록은 유지했다.
실행 계정에서 기존 센서 service 관리 권한이 없었다.
따라서 실제 배포와 재시작은 진행하지 않았다.

다음 작업은 펌웨어 설치와 남은 계측 확인이다.
그 뒤 지상 FC 수신·융합 기록을 확인해야 한다.
설치만으로 정확도나 비행 검증을 완료 처리하지 않는다.
