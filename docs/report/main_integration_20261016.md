# 단일 태그 통합본의 main 병합 검증
2026-10-16 전체 통합 내용의 병합 근거를 기록한다.
충돌 해소와 검증 범위를 확인할 때 읽는다.

## 통합 범위

**기존 기능별 커밋과 시험 원본의 판본을 보존한다.**
통합 시작점은 `88f08a0`이다.
main 시작점은 `45fffc9`다.
main 고유 커밋 17개와 통합본 고유 커밋 93개를 연결한다.
공통 조상이 여러 개이므로 실제 3방향 병합으로 확인했다.
공유 이력을 재작성하거나 강제 push하지 않는다.

| 기존 커밋 | 내용 |
|---|---|
| `b61f1b2` | 태그·앵커·companion의 단일 태그 구현 |
| `d1325c9` | 전체 재기록 검증과 수집기 저장 분리 |
| `8dafa3f` | 최종 50Hz 시험과 복구 자료 보존 |
| `88f08a0` | 책상 위 시험 조건과 물리 검증 한계 |

이전 통합의 B_TF·LiDAR·ToF·C++ 실행기 이력도 포함한다.
기능별 원래 커밋과 당시 검증 문서를 유지한다.
최신 심사 보고서는 별도 문서 커밋으로 추가한다.

## 충돌 해소

**최신 코드의 동작을 과거 main 설정으로 되돌리지 않는다.**

| 파일 묶음 | 판단 |
|---|---|
| 문서 색인 | 양쪽 근거를 연결하고 동일 행만 중복 제거 |
| 로드맵 | 10월 11일 main 기록을 날짜 구간으로 보존 |
| 용어집 | 양쪽 용어 보존과 현행 점프 거절 제거 설명 |
| local_odometry 및 ROS bridge | 최신 지상 시작 조건·즉시 재획득·LiDAR 공존 유지 |
| manual_capture | main의 상태 토픽과 최신 LiDAR·FC 피드백 수집 유지 |
| observation_guard | 변위 점프 거절 제거와 시각·유한값 검사를 유지 |
| setup.py | UWB 및 LiDAR 진입점 모두 유지 |
| 대응 시험 2개 | 최신 계약과 회귀 검사를 유지 |

main의 설치 도구와 이전 시험 근거는 새로 포함한다.
설치 도구를 실행하거나 운영 서비스를 재시작하지 않는다.

## 병합 전 확인

관련 Python 검사에서 91개 통과·1개 건너뜀을 확인했다.
검사 대상은 로컬 관측 전달·관측 승인·단일 태그 수신이다.
B_TF·시계·태그 계약과 배치 설정도 함께 확인했다.
Windows의 pymavlink 부재로 MAVLink 직렬화 검사를 건너뛰었다.
해당 검사는 의존성이 있는 Linux CI에 포함한다.
충돌 표식과 `git diff --check` 오류는 없다.
이후 CI 결과는 PR의 최종 커밋 검사에 연결한다.

CI는 main 대상 PR과 main push에서도 실행한다.
단일 태그 수신·기존 전달기 호환·MAVLink 직렬화를 포함한다.
C++ 무선 계약은 길이·판본·주소·세션을 검사한다.
순번 wrap과 기한 검사도 실행한다.
기존 ROS·C++·합성 FC 지상 검사는 그대로 유지한다.

Windows 전체 UWB 수집은 환경 문제로 중단됐다.
Git 심볼릭 링크가 일반 파일인 설정 경로 16개와
ROS launch 의존성 1개에서 수집 오류가 발생했다.
원본 파일을 바꾸지 않고 Linux CI에 전체 UWB 검사를 추가했다.
이 Windows 결과는 코드 검사 통과로 집계하지 않는다.

## 결과 해석

저장소 병합은 기체 배포나 비행 검증을 뜻하지 않는다.
최종 50Hz는 1,800초의 원본 90,000회차 결과다.
실제 배치 좌표 미확인으로 위치 발행은 차단한 시험이다.
위치 정확도·물리 전원 복구·실물 LoRa 수신은 별도다.
