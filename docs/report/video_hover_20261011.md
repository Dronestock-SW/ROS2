## 결론

**영상에서도 완만한 이동·회전이 관찰된다.**
카메라 움직임을 보정한 뒤에도 특징점이 이동한다.

이번 비행에서 UWB 장기 출력 공백은 재현되지 않았다.

사용자가 다음 조작 순서를 확인했다.
Altitude 이륙 → Position 중립 호버 → Land다.
RC 로그에서도 중립·고정 목표 구간을 확인했다.
이 구간은 이륙·하강·지면 부근 이동과 분리했다.

다음 원인 분리는 FC 위치 추정과 외부 관측을 우선한다.
FC는 고정 목표에 가까운 위치라고 추정했기 때문이다.
영상의 실제 이동량 확정에는 고정 카메라 보정이 필요하다.

UWB에는 태그의 알려진 XY·높이 기준점이 필요하다.
이 근거 없이 광류 부호나 FC 파라미터를 재변경하지 않았다.
