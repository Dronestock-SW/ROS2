# UWB·수평 LiDAR 지상 검증 절차
실기 반영 전에 필요한 측정 순서다.
장착·시간·공분산의 미확인 값을 해소할 때 읽는다.

## 실행 경계

이 문서는 시험 절차이며 실행 기록이 아니다.
실제 FC 설정·ARM·비행은 별도 지시 후 수행한다.
격리 SITL 결과를 실제 비행 승인으로 바꾸지 않는다.
이유: 실제 광선 시각과 장착값이 미확정이다.

## 1. 기록과 시행을 연결한다

| 항목 | 보존할 값 | 확인 기준 |
|---|---|---|
| RAW | 원본 bytes·SHA-256 | 분석 전후 동일 |
| 기체 | FC·Jetson boot ID | 다른 부팅 기록 혼합 없음 |
| 시각 | KST·monotonic·FC boot time | TIMESYNC와 공통 이벤트 대조 |
| 비행 상태 | ARM·POSCTL·IN_AIR | 동시에 신선한 구간 존재 |
| 전달기 | 실행 인자·설정·로그 | sender gate OFF 직접 확인 |
| 융합 | ULog aid-source timestamp·fused | fresh sample 증가와 실제 융합 |

확보한 4개 원본은 시간·정합 진단에 사용했다.
일부 기록의 비행 상태와 전원 연속성은 불명확하다.
사용자 지시에 따라 센서 개선 목적에 활용한다.
비행 성능 비교에만 추가 시행 연결이 필요하다.

## 2. 장착을 측정한다

프로펠러를 제거한 비행 불가 상태에서 측정한다.
기존 센서 서비스와 RAW 기록은 보존한다.

| 변환 | 필요한 측정 | 현재 상태 |
|---|---|---|
| FC/IMU→UWB | XYZ 거리·FRD 부호 | 해당 기체의 실측 대조 필요 |
| UWB→수평 LiDAR | XYZ 거리·회전 | 약 10cm 아래, 윗면 천장 방향 |
| IMU→scan | 회전 행렬·축별 방향 | 정밀값 미확정 |
| TFmini Plus→UWB | 별도 수직 센서 변환 | 수평 LiDAR의 10cm와 혼동 금지 |

정지·양/음 yaw·양/음 roll·pitch 기록을 만든다.
알려진 회전 방향과 scan-Z gyro 부호를 대조한다.
약식 장착 설명을 정밀 행렬로 확정하지 않는다.
이유: 속도·레버암 보정에 직접 영향을 준다.

## 3. 드라이버 시각을 확인한다

설치 드라이버와 SDK의 정확한 커밋을 저장한다.
회전 반전·고정 해상도 설정도 함께 보존한다.

| 값 | 측정 방법 | 통과 조건 |
|---|---|---|
| header 의미 | SDK 소스·원 패킷 대응 | 첫/끝/대표 시각을 명시 |
| 광선 순서 | 원 패킷 index→각도 배열 대응 | 재배열·padding을 추적 |
| time_increment | 실제 광선별 획득 간격 | 배열 index에 적용 가능한지 확인 |
| 수신 지연 | 취득·수신·처리·FC 도착 분리 | 한 시계로 비교, 오차 범위 명시 |
| IMU 보간 | 공통 clock·gap 검사 | 범위 밖 외삽 금지 |

시간 합 1.0725배의 원인을 먼저 해결한다.
임계값을 올려 정상으로 표시하지 않는다.
이유: 광선별 시각이 틀리면 deskew도 틀린다.

## 4. 상대이동과 불확실성을 측정한다

알려진 지상 이동·회전 기준을 준비한다.
FC 위치를 독립 정답으로 사용하지 않는다.
이유: 같은 관측이 EKF에 이미 포함될 수 있다.

| 조건 | 기록·평가 |
|---|---|
| 정지 | 자체 평균 분산·출력 공백·gyro bias |
| 알려진 XY 이동 | 구간 변위·속도 오차·유효 관측률 |
| yaw | 누적 회전·역방향 정합·재획득 |
| roll/pitch | 평면 변화·레버암·관측 중지 조건 |
| 고도 변화 | 벽 단면·가림 변화에 따른 정합 오류 |
| 복도·반복 선반 | 취약 방향·오정합·공분산 팽창 |
| 이동 물체 | 정적 구조 비율·이상치 거절 |
| 센서 단절 | gap 이후 reset·첫 변위 중지 |

개발 구간과 평가 구간을 먼저 나눈다.
공분산은 잔차만으로 생성하지 않는다.
별도 기준 오차와 시간 상관을 함께 평가한다.
실제 Jetson에서 처리 지연·최대값을 측정한다.

## 5. 제동 여유를 측정한다

수평 스캔 한 평면의 범위를 먼저 표시한다.
기체 전체 높이를 보호하는 센서로 간주하지 않는다.
프로펠러 최외곽부터 벽까지 최소 50cm를 확보한다.
중심 기준 거리에는 기체 반경을 더한다.
감속 개시 거리에는 정지 거리와 지연도 더한다.

| 필요한 값 | 사용처 |
|---|---|
| 프로펠러 포함 반경 | 통과 가능한 경로 폭 |
| 방향별 감속도 하한 | 최악 정지 거리 |
| 관측~명령~기체 반응 지연 | 지연 중 이동 거리 |
| 속도 추정 오차 | 실제 운동량의 보수적 범위 |
| 관측·장착 오차 | 장애물 거리 여유 |
| 움직이는 장애물의 접근 한계 | 정지 중 상대 거리 변화 |

위 값이 미측정이면 SITL 값을 실기에 복사하지 않는다.
이유: 후보의 0.5m/s² 감속도는 합성 조건이다.
실기 시험안에는 접근 속도·중단 거리·조종권을 명시한다.
검토한 결과와 시험안을 제시한 후 실행 지시를 받는다.
