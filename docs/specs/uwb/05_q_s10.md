# M05 Q_S10 단절 후 복구 모델

짧은 복구 구간에서 거리 편향과 위치를 푸는 명세다. H80 단독과 복구 보조 모델을 비교할 때 읽는다.

## 목적과 현재 상태

단절 직후에만 추가 풀이를 시도한다.
기존 `qs10.py`는 실행 경로에서 호출하지 않는다.
표본별 Z를 받는 어댑터와 수렴 검증이 필요하다.
임시 편향은 M03의 태그 교정값과 분리한다.

## 입출력

| 방향 | 파라미터 | 형식·단위·조건 |
|---|---|---|
| 입력 | `window`, `anchors`, `z_samples` | 표본별 보정 사거리·앵커·Z |
| 입력 | `recovery_state` | 단절 시각·복구 시작·앵커별 span |
| 입력 | `initial_estimate` | 시각과 유효성이 확인된 초기 위치·이동량 |
| 출력 | `estimate` | Candidate 또는 null |
| 출력 | `temporary_bias_m` | 앵커별 비음수 임시 편향 |
| 출력 | `fit` | converged·반복·cost·잔차·rank |
| 출력 | `recovery_decision` | 미실행/복구 풀이/보류/종료 |

## 설정

| 파라미터 | 단위·범위 | 참고값 / 상태 |
|---|---|---|
| `gap_threshold_s` | s | 0.15 참고값 |
| `recovery_span_limit_s` | s | 0.40 참고값 |
| `warmup_s`, `bias_hold_s` | s | 0.10 / 0.80 참고값 |
| `bias_max_m`, `bias_prior_sigma_m` | m | 1.0 / 0.10 참고값 |
| `bias_hold_threshold_m` | m | 0.08 참고값 |
| `sigma_range_m`, `huber_delta_m` | m | 0.08 / 0.12 참고값 |
| `velocity_prior_sigma_m_s` | m/s | 규제 강도는 비교 전에 명시 |
| `iterations`, `step_halvings` | 정수 | 40 / 14 참고값 |
| `convergence_tol`, `max_init_age_s` | 단위별 구분 | 미확정 |

## 처리 구조와 산식

```text
정상 수신 → 단절 검출 → 새 창 초기화 → 복구 대기
          → Z·표본·초기값 확인 → Q 풀이 → 후보 품질 검사
          → 복구 span 종료 → H80 경로
```

`u=(t_j-t_ref)/window_s`로 정규화한다.
미지수는 `[x0,y0,x1,y1,b1,b2,b3,b4]`다.
`x1,y1`은 속도가 아니라 창 길이 동안의 이동량이다.

```text
d_j = sqrt((x0+x1*u-ax)^2 + (y0+y1*u-ay)^2 + (z_j-az)^2)
e_j = d_j + b_anchor - r_cal_j
J = sum(Huber(e_j)/sigma_r^2)
    +(x1^2+y1^2)/(2*window_s^2*sigma_v^2)
    +sum(b_i^2/(2*sigma_b^2))
0 <= b_i <= bias_max
```

위 목적함수는 시험안이다. 원본 규제식과 따로 대조한다.
한 창에서 위치와 여러 편향을 모두 식별하기 어려울 수 있다.
낮은 잔차만으로 참 위치를 얻었다고 판정하지 않는다.
Q가 실패하면 시각·품질을 통과한 H80 후보만 대안으로 쓴다.
대안이 없으면 null을 기록한다.

## 실패와 상태

Z 누락·노후, 부족 표본, 불량 기하에서는 실행하지 않는다.
반복 한도 도달만으로 수렴 성공 처리하지 않는다.
편향 상한 도달과 수렴 실패를 별도 기록한다.
추정 편향을 다음 창의 교정값으로 누적하지 않는다.
복구 hold는 진단 상태이며 새 관측의 유효성으로 바꾸지 않는다.

## 테스트와 평가

| 시험 | 확인할 결과 |
|---|---|
| 연속 정상 입력 | Q 호출 0회 |
| 임계값 전후 단절 | 엄격한 `gap > threshold` 조건 |
| 복구와 양의 편향 | H80 단독 대비 복구 오차·지연 |
| 이동 중 단절·초기값 불량 | 오복구·실패율·최대 점프 |
| Z 누락·상한 편향·비수렴 | 부당한 성공 출력 없음 |

정상 구간과 복구 구간의 지표를 분리한다.
Q 시험은 필요한 Z가 준비된 이후에 수행한다.
