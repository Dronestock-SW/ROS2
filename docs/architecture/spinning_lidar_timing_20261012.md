# 회전 LiDAR의 시간·정합 설계
2026-10-12 격리 SITL 구현을 설명한다.
광선 시각과 부분 가림 처리를 검토할 때 읽는다.

## 적용 범위

**광선별 이동을 반영한 연구용 관측 경로다.**
실기 드라이버나 FC 파라미터에 배포하지 않았다.
기체 자세·고도 제어는 PX4가 맡는다.
수평 LiDAR는 관측하지 않은 vz를 만들지 않는다.
새 기능은 명시한 `--lidar-source spinning`에만 적용한다.
검증 결과는 [수행 기록](../report/spinning_lidar_20261012.md)에 둔다.

```text
SIH 원시 궤적 ──> 가상 센서 ──> 광선별 거리·측정 시각
     │                              │
     └──> 오프라인 오차 평가         │
                                    v
시계 왕복 교환 ──> 센서/FC 시각 변환 ─┤
FC 측정 자이로 + FC 자세 기준 ────────┤
직전 수용 스캔의 속도 ────────────────┤
                                    v
                     중간 광선 시각으로 deskew
                                    │
                   공간 지지·관측 가능성·시간 일관성
                                    │
                     상대이동 / 구간 평균 XY 속도
                                    │
                     전용 LiDAR2D 입력 → PX4 EKF2

보정 광선 + 같은 시각 FC 위치 → 수평 장애물 guard
```

원시 궤적은 가상 센서와 평가기만 사용한다.
정합기는 UWB·FC·정답 속도를 입력받지 않는다.
deskew의 병진 성분은 직전 스캔 속도를 쓴다.
사용할 과거 관측이 없으면 추가 불확실성을 붙인다.
이는 관측된 속도 0을 의미하지 않는다.

## 광선 측정과 시간

회전 주파수와 세계 좌표 방향은 별개다.
한 스캔을 한 시각의 360도 관측으로 취급하지 않는다.

| 항목 | 구현값·계약 |
|---|---|
| 광선 수·회전율 | 430개, 초당 10회 |
| 측정 간격 | FC 시계에서 0.1/430초 |
| 스캔 원본 시각 | 첫 광선 시각 |
| 보정 기준 | 첫·마지막 광선의 중간 시각 |
| 속도 시각 | 두 스캔 보정 시각 사이의 중점 |
| 거리 잡음 | 광선별 1cm, 스캔 공통 3mm |
| 장착 | 가상 IMU와 LiDAR 원점 일치 |
| 이동 물체 | 광선별 시각에서 원통과 교차 계산 |
| 바닥·천장 | 3D 광선 추적으로 교차 계산 |
| 정합 유효 거리 | 0.2–4m |
| 바닥 높이·기울기 | 측정 높이 0.75–2.25m, 10도 이내 |

ROS `LaserScan`은 첫 광선 시각과 간격을 구분한다.
[공식 메시지 정의](https://github.com/ros2/common_interfaces/blob/rolling/sensor_msgs/msg/LaserScan.msg)를 따른다.
실물 `time_increment`의 정확성은 아직 확인하지 않았다.

가상 센서는 FC와 다른 시계를 갖는다.
오프셋 37ms, 주파수 차이 35ppm을 넣었다.
편도 지연은 각각 0.15–0.70ms로 생성한다.
추정기에는 오프셋 정답을 전달하지 않는다.

| 시각 변환 조건 | 처리 |
|---|---|
| 최근 왕복 교환 | 최대 64개 |
| 선택 | RTT가 작은 절반, 최소 8개 |
| 시간 범위 | 최소 0.15초 |
| 주파수 차이 | 1,000ppm 이내 |
| 불확실성 | 잔차 + RTT/2 + 외삽 항, 2ms 이하 |
| 갱신 만료 | 0.5초 |
| 5ms 이상 시계 점프 | 시계 epoch를 바꾸고 재준비 |
| 유효 변환 없음 | 속도 발행 보류, 연속성 초기화 |

이는 합성 시계 교환의 검증이다.
실물 하드웨어 시계 동기화의 측정 결과가 아니다.
센서·companion·FC의 실제 지연은 별도 보정한다.

## IMU와 deskew

회전은 수신 시각 대신 FC 측정 시각으로 적분한다.
`HIGHRES_IMU`의 측정 자이로를 사용한다.
세계 좌표 초기 자세는 FC 자세로 고정한다.
이 적분은 한 스캔의 왜곡 보정에만 사용한다.
독립 비행 자세 추정기나 자세 제어기가 아니다.

| 조건 | 처리 |
|---|---|
| 자세 기준 시각 | 첫 광선 이전, 40ms 이내 |
| IMU 구간 | 모든 광선 시각을 앞뒤로 감쌈 |
| IMU 최대 간격 | 25ms |
| 외삽 | 허용하지 않음 |
| 최근 속도 prior | 중간 광선 기준 250ms 이내 |
| 수용 실패 | 속도 prior와 구간 연결을 지움 |
| 수신 순서 지연 | 끝 IMU를 기다리되 첫 광선+140ms 제한 |

처리가 끝난 시각을 측정 시각으로 바꾸지 않는다.
정상 구간도 중점부터 수신까지 약 0.13초다.
SITL 입력 허용 나이를 150ms에서 200ms로 조정했다.
EKF 지연 버퍼도 200ms로 고정했다.
실물 지연 값을 200ms로 정한 것은 아니다.

## 부분 가림과 정합

남은 형상의 독립 이동 정보를 검사한다.
남은 각도 하나로 통과 여부를 정하지 않는다.

| 검사 | 의미 |
|---|---|
| 법선 | 연속 유효 광선 9개 이내에서 계산 |
| 공간 지지 | 0.5m 셀, 셀당 가중치 최대 8개분 |
| 강건 잔차 | Huber 가중치와 trimming 유지 |
| 양방향 정합 | 앞·뒤 정합의 일관성 유지 |
| 공통 거리 편향 | 병진과 별도로 추정, 최대 3cm |
| 방향별 정보 | yaw·거리 편향을 제거한 XY 정보 검사 |
| 작은/큰 고유값 비 | 0.06 이상 |
| 짧은 시간 검사 | 이전·현재·keyframe 변환 비교 |
| 시간 일관성 허용 | 병진 2.5cm, 회전 0.5도 |

공간 검사 비활성 대조는 시간 검사도 끈다.
따라서 두 검사의 개별 기여를 분리하지 못한다.
이번 자료로 공간 검사의 정확도 향상을 단정하지 않는다.
평행한 두 벽만 남으면 한 방향 이동을 구분하지 못한다.
이 경우 속도 보류가 기대 동작이다.

## 장애물 경로

위치 관측 수용과 이동 허가는 다른 판단이다.
가림 뒤의 빈 영역을 자유 공간으로 바꾸지 않는다.
남은 벽으로 속도를 계산해도 이동은 제동할 수 있다.

보정 광선에는 원래 유효 여부를 남긴다.
guard는 첫 광선 시각으로 전체 나이를 계산한다.
장애물 배치에는 같은 시각 FC 위치를 사용한다.
취득 중 이동 오차 여유 12cm를 추가했다.
기체 반경 20cm와 외곽 여유 50cm를 유지했다.
반경은 실측 프로펠러 외곽값이 아닌 시험 가정이다.
이 시험은 3D 충돌 회피를 인증하지 않는다.

## 실기 전 남은 항목

| 항목 | 현재 상태 |
|---|---|
| 광선별 실제 시각·회전 방향 | 미측정 |
| LiDAR·IMU 레버암·장착 회전 | 실물 보정 미실시 |
| 시계 지연·변동 | 합성 교환만 검증 |
| 관측 공분산 | 합성 센서의 보수적 모델 |
| Jetson 처리 지연 | 미측정 |
| ROS 운영 입력 연결 | 미실시 |
| 지도 최적화·재방문 보정 | 미구현 |
| 독립 실물 위치 오차 | 미측정 |

RF2O와 SRF는 후속 비교 대상으로 남긴다.
RF2O 공식 ROS2 코드는 range flow를 사용한다.
검토한 정합 소스에는 `time_increment` 처리가 없다.
[공식 RF2O 저장소](https://github.com/MAPIRlab/rf2o_laser_odometry)를 참조한다.
SRF는 이전·현재·keyframe 세 스캔을 정합한다.
동적 환경에서 대칭 range flow를 사용한다.
[공식 SRF 저장소](https://github.com/MAPIRlab/srf_laser_odometry)를 참조한다.
이 환경에는 필요한 ROS·MRPT 구성이 없다.
둘의 실행 결과나 순위는 이번 보고서에 만들지 않는다.
