2. 원인과 통제 비교

관측 점프 검사는 B4/B3 전환보다 앞에 있다.
원본 XY와 직전 통과 XY의 변위를 비교한다.

  허용 변위 = 0.10m + 1.0m/s × min(이전 통과 이후 시간, 0.25초)
  최대 허용 변위 = 0.35m

거부된 위치로 기존 기준점을 갱신하지 않는다.
따라서 수동으로 다른 시험점에 옮긴 뒤 정지해도 격리가 계속될 수 있다.
이는 일관된 가짜 위치 점프를 자동 승인하지 않기 위한 보호 동작이다.

같은 실측 입력과 같은 설정으로 다음을 비교했다.
ROS를 초기화하지 않고 운영 BtfNode의 센서·시각·계산 콜백을 호출했다.
발행자는 메모리 카운터로 대체했다. 소켓·시리얼·FC I/O는 없다.
표본 전 10초를 시계·센서 준비 구간으로 제공했다.

새 세션                            1,856         0           525          16
기존 +X 평균 위치를 prior로 설정       0        1,872          525           0
위 prior에서 계산 모델만 초기화         0        1,872          525           0

이전 +X prior는 실제 이전 시험 평균 (4.11769264, 2.33091461)m를 사용한 통제 조건이다.
실행 중 프로세스 메모리의 실제 prior를 회수한 것은 아니다.
그러므로 실기 prior의 정확한 좌표를 확정했다고 해석하지 않는다.
동일 입력에서 raw guard 이력만으로 실기의 거부 분포를 재현했다.
모델만 초기화한 경우와 prior 유지 경우의 판정 해시는 같았다.

기존 reset_models()는 raw guard를 보존한다.
전체 reset(), 실제 태그 boot, TDMA 세션 변경 등은 raw guard를 초기화한다.
브리지에는 별도 guard가 있으므로 B_TF 초기화와 브리지 초기화는 같은 작업이 아니다.
거부 누적 또는 시간 경과만으로 운영 중 자동 초기화하면 안 된다.
실기 시험점 재배치는 명시한 시험 세션 경계에서 처리해야 한다.

3. '6cm'가 의미하는 것

실제 기준점 대비 XY 오차 6cm가 아니다.
같은 숫자가 서로 다른 두 잔차에 사용된다.

(1) 원본 네 거리 풀이의 순간 일관성 잔차 < 6cm:
    이 조건에서 raw guard의 위치 점프 검사를 수행한다.
    지표는 제곱거리 차이 방정식의 최대 정규화 잔차다.

(2) B4 H80의 적합 거리 RMS:
    6cm 미만이면 unchanged_B4로 유지한다.
    정확히 6cm 이상이면 B3 후보 검사를 시작한다.
    독립 XY 오차와 직접 비교하는 임계값이 아니다.

B3에서는 한 앵커씩 제외한 네 후보를 만든다.
최선 후보의 ToF 물리 거리 RMS < 6cm가 필요하다.
차선 후보와 차이는 최소 1.5cm여야 한다.
최근 0.1초 이내 prior와의 이동 연속성도 필요하다.
후보가 애매하거나 높이·이력이 없으면 보류한다.
실측 ToF B3는 cold start에서 최초 prior가 없으면 자동 승인하지 않는다.
지상 참조 B3에는 별도 2초·30표본·5cm 반경 초기화 조건이 있다.

실행 흐름:
원본·태그·TDMA·시각 검사
  → 네 앵커 측정시각별 ToF·IMU 선택
  → 원본 위치 점프 검사
  → 0.8초 창의 B4
  → B4 RMS < 6cm: B4 유지
  → B4 RMS ≥ 6cm: ToF B3 후보·유일성·연속성 검사
  → 높이·시각 나이·새 표본 여부에 따른 ROS 발행
  → 별도 브리지 좌표·시계·점프 검사
  → PX4 EKF2 실제 융합 검증

4. 새 이력으로 풀린 뒤에도 남은 문제

새 세션 재생에서 B4 승인 1,856개, XYZ 발행 모사 1,740개였다.
모든 승인 결과는 B4 유지였다. B3 전환은 이 구간에서 필요 조건에 도달하지 않았다.
B4 적합 RMS 평균 1.83998cm, 최대 2.47586cm였다.

그러나 B4가 승인한 XY와 실측 태그 높이로 네 거리를 다시 계산하면:
- 실측 높이를 사용한 승인 표본: 1,740개.
- 물리 거리 RMS 평균: 8.36249cm.
- 범위: 5.66210~12.11334cm.
- 물리 거리 RMS ≥ 6cm: 1,733개(약 99.6%).

이 물리 잔차는 정지 구간에서 현재 B4 XY·선택 높이와 RAW 거리를 비교한 진단값이다.
B3의 전체 시간 창 RMS와 같은 집계는 아니며, 독립 위치 정답도 아니다.
ToF 장착값·바닥·앵커 좌표·거리 편향의 불확실성을 포함한다.
현재 B4 경로는 내부 RMS가 작으면 ToF 물리 잔차 검사 전에 승인한다.
그래서 B4 RMS가 작다는 사실만으로 실제 거리가 맞다고 할 수 없다.

별도 합성 검증에서도 네 거리에 공통 -20cm 편향을 넣었을 때,
B4 내부 RMS는 약 2.49e-15m지만 ToF 물리 잔차는 20cm였다.
합성값을 실측이라고 해석하지 않는다.

추가로 지상 참조 높이 사용이 있었다.
- 높이 계산된 1,872개 중 measured_tof_imu 1,755개.
- ground_antenna_reference 117개.
- 승인 B4 중 실측 높이 1,740개, 지상 참조 높이 116개.
손으로 들고 있어도 FC의 ON_GROUND 판정은 유지됐다.
일부 ToF 시각 선택이 유효하지 않을 때 설정의 0.15m 지상 참조가 사용됐다.
이 표본을 실제 70cm 높이 측정으로 집계하면 안 된다.
기존 코드는 ground reference 표본의 XYZ 발행은 하지 않는다.

재생 발행 표본의 최대 간격은 약 0.325초였다.
재생에서 계산한 publish_age 평균 7.04ms, 최대 14.28ms다.
이는 수집기의 기록 시각을 대용한 값이다. 실기 고정 지연 보정 결과가 아니다.

5. 정상 오차판단 절차

다음 순서로 검사하며, 내부 잔차와 독립 정확도를 분리한다.

가. 시험 조건과 계보
   태그·boot·설정 해시·앵커 안테나 좌표를 고정한다.
   정확한 XY가 없는 구간은 절대 위치 정확도 평가에서 제외한다.
   새 시험점에서는 명시한 세션 초기화 절차를 사용한다.
   실제 비행 중 위치 점프는 자동으로 새 원점으로 승격하지 않는다.

나. 원본 입력
   전체 cycle, 앵커별 성공, 완전한 네 앵커 비율을 기록한다.
   TDMA 거부·순번 누락·시계 오류·수신 공백을 구분한다.
   기록기 파일 전환의 공백도 누락으로 표시한다.

다. 높이 입력
   ToF 범위뿐 아니라 age, IMU 시차, 기울기, 장착값을 검사한다.
   실측 높이와 지상 참조 높이를 별도 분모로 집계한다.
   손으로 든 시험에서 ON_GROUND만으로 실제 지상 높이를 확정하지 않는다.

라. 알고리즘 및 물리 일관성
   원본 점프 → B4 RMS → B3 물리 RMS → 후보 차이 → 연속성 순서로 기록한다.
   B4와 B3 모두 물리 거리 잔차를 진단한다.
   기존 6cm를 독립 XY 정확도의 합격선으로 바꾸지 않는다.
   B4 공통 물리잔차 차단은 현재 운영 코드에 미구현이다.
   이번 결과는 진단이며 임계값 또는 보정값을 운영 코드에 적용하지 않았다.

마. 독립 정확도와 가용률
   기준점별 평균 편향·RMSE·95백분위·표준편차를 계산한다.
   RAW → B_TF 계산 → ROS 발행 → 브리지 수락률을 같은 분모로 비교한다.
   마지막 좌표를 반복 표시한 것을 새 관측으로 세지 않는다.
   이번 높인 중앙 구간의 독립 XY 정확도는 판단 불가다.

바. 자율주행 적용
   PX4 EKF2가 유일한 비행 상태추정기다.
   B_TF는 XY 관측만 제공하고 companion은 고도·자세 제어를 추가하지 않는다.
   축·원점·FC 기준점 레버암·동적 지연을 먼저 확인한다.
   EV 실제 수신·융합·innovation·RC 인계와 비행 검증은 별도 단계다.
   현재는 이 조건을 충족하지 못하므로 자율주행 사용을 보류한다.
