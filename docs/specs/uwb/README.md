# UWB 수신·보정 비교 시험 프로젝트 명세

아이디어별 모듈과 비교 시험의 개발 명세다. 각 기능을 구현하거나 비교 모델을 선택할 때 읽는다.

전체 구조는 [단계별 적용과 선택안](stage_selection.md)부터 읽는다.
공통 처리, 대체할 위치 모델, 추가할 보조 기능을 구분했다.

## 결정과 범위

**동일 자료로 기능을 비교한 뒤 모델을 선택한다.**
2026-09-26 사용자 요청으로 작성했다.
기존의 보류 아이디어를 시험 설계 대상으로 전환했다.
실운용 모델의 채택과 구현 완료를 뜻하지 않는다.
초기 산출물은 명세 문서다.
후속 요청으로 A/H80의 제한된 합성 샘플을 실행했다.
당시 실측 다중 모델 비교·전체 실행기 검증은 미실시였다.
[로그와 샘플 확인 결과](../../report/uwb_h80_readiness_20260926.md)를 구분해 읽는다.
이후 A 전용 파일 계산기를 구현하고 합성 로그를 재생했다.
[A 계산 결과](../../report/uwb_baseline_a_20260926.md)에 근거를 보존했다.
후속 [실측 정지 로그](../../report/uwb_baseline_a_static_20260926.md)도 계산했다.
수기 기준점으로 편향 후보를 구하고 별도 수신에 적용했다.
ToF 연동·동적 비행·여러 위치의 정확도 검증과 구분한다.
2026-09-27에는 [B 파일 실행과 A/B 비교](../../report/uwb_h80_b_20260927.md)를 완료했다.
이후 [C 명세](06_anchor_triplets.md)를 구체화하고 C/D를 구현했다.
[C/D 정지·합성 비교](../../report/uwb_subsets_cd_20260927.md)를 완료했다.
C는 균등 평균, D는 반지름 확장 없는 첫 방식이다.
C/D 후보의 품질 가중·확장과 최종 선정은 남았다.
27일 후속으로 [M09 거리 가중 풀이](09_weighted_range_solver.md)를 구현했다.
[Gazebo 경로 비교](../../uwb_gazebo_shadow_runbook.md)도 준비했다.
합성 검증과 실제 Gazebo·PX4 비행 검증을 구분한다.
27일 ULog는 [센서 입력 준비](../../report/uwb_flight_inputs_20260927.md)에 반영했다.
같은 비행의 UWB RAW는 없다는 사용자 확인을 기록했다.

사용자는 9월 26일 비행 로그를 Z 입력 후보로 지정했다.
동시 UWB·시계 대응·센서 장착과 교정은 추가 확인이 필요하다.
현재 수치·좌표·장착값을 새로 확정하지 않는다.
수신 형식과 단위, 누락 처리를 먼저 정의한다.
계산에 필요한 입력이 없으면 `blocked`를 반환한다.
시뮬레이션 자료와 실측 자료는 별도로 평가한다.

기존 파일 파이프라인의 계산·전달 게이트는 닫혀 있다.
A/B는 별도 파일 실행기로 비교한다.
나머지 비교 시험은 해당 모델 연결 후 수행한다.
PX4 EKF2는 비행제어의 유일한 상태추정기로 유지한다.
시험 필터의 출력은 파일로만 기록한다.

## 전체 아키텍처

모델마다 상태를 분리하고 같은 입력을 재생한다.

```text
원본 파일 / 합성 자료 / 추후 실측 자료
                     |
           원본 보관 + M01 시간·입력
                     |
             M03 거리 편향 보정
                     |
      +--------------+----------------------+
      |              |                      |
  M02 Z·자세    M12 RF/CIR 오차       M15 LiDAR 대조
      |              |                (선택적 별도 시험)
      +--------------+----------------------+
                     |
      동일 자료를 각 독립 모델 인스턴스에 전달
      +--------------+----------------------+
      |              |                      |
  M09 거리 풀이   M04 H80            M06 / M07 후보 생성
      |              |                      |
  M11 선택적 검사 M05 조건부 복구           M08 결합
      +--------------+----------------------+
                     |
              M10 배치·계산 품질
                     |
        M13 시간 필터 / M14 위치 게이트 비교
                     |
             M17 좌표 변환 + 파일 기록
                     |
           평가기 ← 별도 기준 위치 자료

M16 GNSS·UWB 융합은 해당 자료가 있는 별도 비교군
외부 관측 전달: 닫힘
```

그림의 선택적 모듈은 모두 한꺼번에 켜지 않는다.
M10은 M11의 재계산 후보 검사에도 사용한다.
M03의 거리 게이트 유무는 실행 설정에서 고정한다.
각 분기에는 독립적인 이력과 초기 상태를 둔다.
기준 위치는 평가기만 읽는다.

## 개발 단위와 완료 조건

각 문서의 제안 함수는 아직 구현을 보장하지 않는다.

| 단계 | 완료 조건 | 현재 상태 |
|---|---|---|
| 명세 | 입출력·처리·실패·시험 정의 | 작성 완료 |
| 공통 시험 실행기 | 같은 입력·설정으로 재생 가능 | 미구현 |
| 개별 모듈 | 수학·상태·누락 시험 통과 | 기존 일부 함수 외 미구현 |
| 모델 비교 | 기준 위치가 있는 독립 평가 자료로 비교 | 실측 미실시. A/H80 합성 예시만 확인 |
| 모델 선정 | 사전 기준을 통과한 모델 선택 | 미선정 |
| 외부 연결 | 좌표·시간·책임 경계 검증 | 보류 |

제안 구현 경로는 `src/drone_uwb/drone_uwb/preimu/experiments/`다.
제안 시험 경로는 `src/drone_uwb/test/experiments/`다.
두 경로의 새 기능은 이번 작업에서 만들지 않는다.
기존 실행기는 [현재 설계](../../uwb_pipeline_design.md)를 따른다.
