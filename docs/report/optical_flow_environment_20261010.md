# 10월 10일 조명·그림자와 수동 호버 확인
현재 환경의 수동 비행 결과를 보존한 기록이다.
UWB 통합 측정과 저고도 전략을 정할 때 읽는다.

## 현재 판단

현재 환경의 1m 이상 Position/Hold를 다음 시험의 전제로 둔다.
사용자가 직접 수동 조종하며 안정성을 확인했다.
낮은 고도 호버 복구를 다음 시험의 선행 과제로 반복하지 않는다.
다음 단계는 [UWB 통합 관측 시험](../runbooks/manual_uwb_final_trial_20261010.md)이다.

## 사용자 보고

근거는 2026-10-10의 직접 대화다.
정확한 비행 시각·ULog·영상은 이번 기록에 첨부하지 않았다.

| 항목 | 사용자 확인 |
|---|---|
| 환경 | 야간, 위쪽 조명을 켠 상태 |
| 약 30cm 높이 | 기체 그림자로 광류 문제가 나타남 |
| 1m부터 | 센서 아래 그림자가 벗어나며 흐름이 없어짐 |
| 다음 시험 전제 | Position/Hold가 괜찮다고 보고 UWB 측정 진행 |
| 일반화 범위 | 현재 설치·조명 조건에 한정 |

이는 사용자 실비행 보고다.
이번 문서 작성 중 ULog를 재분석한 결과는 아니다.
MAG_TYPE 복원이 단독 원인이었다고 판정하지 않는다.
1m를 모든 장소의 센서 한계로 등록하지 않는다.
이유: 조명 위치·개수와 그림자 조건이 달라진다.
이전 기록의 호버 미확인은 당시 상태로 보존한다.

## 저고도 후속 전략

설치 환경에 맞춰 LiDAR 보완을 검토한다.
특히 1m 아래에서 광류가 불안정한 조건을 평가한다.
현재 시험을 조명 변경이나 저고도 재시험으로 지연하지 않는다.

후속 비교는 아래 순서로 설계한다.

1. 설치 장소의 조명·바닥·고도별 광류 상태를 기록한다.
2. T-mini Pro의 수평 스캔매칭 관측을 평가한다.
3. UWB와 함께 PX4 EKF2에 공급할 조건을 검증한다.
4. 저고도 이륙·착륙과 관측 상실·복구를 따로 시험한다.

하방 TFmini Plus의 거리만으로 XY 이동을 얻지는 못한다.
여기서 LiDAR 보완은 수평 스캔매칭을 검토한다는 뜻이다.
반복 선반·가림에 따른 스캔매칭 품질도 확인해야 한다.
고도만으로 센서를 자동 전환하는 구현은 확정하지 않았다.
PX4 EKF2가 유일한 비행 상태추정기라는 기준을 유지한다.
고도·자세 제어도 PX4가 담당한다.

## 별도 SSH 읽기 확인

19:47 KST의 짧은 지상 기록 상태를 읽었다.
위 사용자 보고의 비행 구간과 같은 것으로 취급하지 않는다.

| 항목 | 약 20.6초 수집 조각의 상태 |
|---|---|
| FC | 연결, DISARM, POSCTL |
| 수집 | recording, 오류 없음, 필수 토픽 누락 없음 |
| UWB 원본 토픽 | 1,646개 메시지, 최대 간격 약 25.3ms |
| B_TF pose | 377개, 최대 발행 간격 약 3.53초 |
| B_TF XYZ / FC 전달 전 EV 토픽 | 해당 조각에 없음 |
| 동일 시행 ULog 첨부 | 없음 |

원본 메시지 수는 완전한 네 앵커 cycle 수와 다르다.
B_TF 출력은 있으나 연속성 검증 완료는 아니다.
UWB의 FC 융합·자동 비행을 승인한 결과도 아니다.
