# 고도(z) 처리 원칙

고도의 측정·제어 책임을 정하는 기준이다.
고도 입력이나 데모 값을 연결할 때 읽는다.

## 현재 기준

드론 고도에는 실측 센서를 사용한다.
2026-10-04 사용자가 ToF 실측 가능을 확인했다.
공용 데모의 사인파 고도는 제거했다.
측정이 없으면 가상값이나 고정 높이로 대체하지 않는다.
이유: 생성한 값은 드론의 현재 높이를 나타내지 않는다.

1. UWB는 x·y 수평 위치를 제공한다.
   `/uwb_pose.z=0`은 메시지의 미관측 자리값이다.
2. 고도는 TFmini Plus와 Pixhawk IMU/EKF가 담당한다.
   PX4의 고도 융합·제어 책임을 유지한다.
3. companion은 z를 직접 제어하지 않는다.
4. 비행용 z 유효성 검사는 추가하지 않는다.
   `virtual_wall_node`의 기존 TODO를 유지한다.

## 측정값과 좌표의 구분

2026-10-09 사용자는 지상 참조 표시를 요청했다.
명시한 `ground_antenna_height_m=0.15`를 사용한다.
최신 FC 연결·ON_GROUND일 때만 적용한다.
ARM 상태여도 지상 판정이면 표시할 수 있다.
실측 ToF가 없을 때의 안테나 설치 높이 추정이다.
`current_z_trusted=false`, `xyz_valid=false`를 유지한다.
공중·이륙·착륙·상태 만료에서는 고정값을 쓰지 않는다.
실측이 돌아오면 바로 실측값으로 바꾼다.
PX4 고도·목표·ToF 입력에는 이 값을 넣지 않는다.
이유: 지상 설치 높이는 현재 비행 고도의 측정값이 아니다.

같은 지상 상태에서4개 앵커 XY가 통과하면 표시한다.
현장 설정 `allow_ground_xy_without_tof=true`가 필요하다.
기존 `unchanged_B4` 결과만 허용한다.
3개 앵커 ToF 선택·높이 측정 결과는 만들지 않는다.
상태 만료·공중에서는 원래 측정 높이 조건을 적용한다.

| 값 | 의미 | 사용 경계 |
|---|---|---|
| ToF 실측 거리 | 센서 광축을 따른 하방거리 | 원본 거리·시각·센서 기준점 보존 |
| 거리 후보정용 Z | 자세·바닥·레버암을 반영한 높이 | FC 또는 UWB 안테나 기준을 명시 |
| PX4 고도 | PX4 EKF가 추정한 위치 | 비행 상태·고도 제어에 사용 |
| 앵커 z=2.2m | 앵커 설치 높이의 기존 설정 | 드론 가상 고도와 별개 |
| Tag B 앵커 z=0.15m | 2026-10-07 임시 안테나 시험 설정 | 추후 2.2m 복원, 실측 완료 아님 |
| MIS_TAKEOFF_ALT=1.3m | 사용자 요청으로 FC에 저장한 기본 이륙 높이 | 앵커 높이·관측 z와 별개 |
| 메시지 자리값 z=0 | XY 전용 메시지의 필수 필드 | 실측 높이나 목표 고도로 해석하지 않음 |

ToF 거리만으로 지도상의 z를 채우지 않는다.
이유: 기울기·장착 오프셋·바닥 기준을 반영해야 한다.
변환식과 연결 조건은 [M02 명세](specs/uwb/02_tof_z_adapter.md)를 따른다.

2026-10-08 실물 경로는 `/uwb/btf_xyz`를 표시한다.
XY와 같은 시각의 바닥 기준 태그 높이를 담는다.
FC에 전달하는 `/uwb/btf_pose`는 XY 전용이다.
높이 누락 때 시험용 관측 발행을 중지한다.
이는 관측 기하 검사다. 목표 z 판정·고도 제어가 아니다.
웹 이륙은 PX4 `MIS_TAKEOFF_ALT`를 사용한다.
명령의 altitude는 NaN이다. 웹 경유지 z는 사용하지 않는다.
[비행 시험 구조](architecture/web_test_flight.md)를 따른다.

## 공용 데모와 실측 입력

`drone_demo`는 XY 경로·목표·공백 시험만 제공한다.
가상 고도에 의존하던 사선거리 RAW 생성도 제거했다.
ROS Pose의 z는 0 자리값이며 상태의 `z_m`은 null이다.

`/tof/range`의 `sensor_msgs/Range`를 구독한다.
토픽은 `real_tof_topic`으로 지정한다.
측정은 `/demo_status.tof`에 하방거리로 표시한다.
누락·오류·노후 입력은 `range_m=null`이다.
`tof_timeout_s=0.2`는 데모 표시의 기본 만료 시간이다.
비행용 z 판정 임계값이 아니다.
ToF 수신 후에도 XY 데모는 계속 실행된다.

DOMAIN_ID 99·localhost 제한을 유지한다.
실측 토픽 연결·단위·시각·장착 확인은 장치에서 수행한다.
이번 수정은 그 연결이 완료됐다는 뜻이 아니다.
[공용 데모 기준](architecture/demo_design.md)을 따른다.

## UWB 파일 계산 경로

2026-09-21에는 실측 부족으로 합성 자료를 만들었다.
그 자료와 Gazebo 시험은 재현용으로 보존한다.
새 실측에는 `source=measured`와 원래 시각을 기록한다.
공용 파일 파이프라인의 계산·출력 게이트는 닫혀 있다.
실측 가능 여부만으로 정렬·장착 검증을 완료 처리하지 않는다.
이유: 동시 UWB·자세와의 시각 대응도 필요하다.
[파이프라인 기준](architecture/uwb_pipeline_design.md)을 따른다.

T-mini Pro는 전방 스캔 센서다.
하방 ToF 대신 고도 입력으로 사용하지 않는다.
