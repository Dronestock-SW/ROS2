# M03 편향 보정·거리 게이트

앵커별 거리 보정과 이상치 보류의 비교 명세다. 위치 모델 앞의 공통 거리 입력을 준비할 때 읽는다.

## 목적과 현재 상태

거리 편향과 순간 튐을 서로 다른 처리로 관리한다.
기존 `ranges.py`에 차감·게이트·이력이 구현돼 있다.
전체 모델에 대한 새 시험 형식 연결은 미완이다.
후속 A 정지 시험에는 1차 기록의 편향 후보를 연결했다.
2차 기록으로 차감 전후를 비교했다. 거리 게이트는 미적용이다.
[실측 A 기록](../../report/uwb_baseline_a_static_20260926.md)을 참고한다.
[공통 규격](00_interfaces.md)의 Observation을 사용한다.

## 입출력

| 방향 | 파라미터 | 형식·단위·조건 |
|---|---|---|
| 입력 | `observation` | Observation. raw_slant_m, 시각, 앵커 ID |
| 입력 | `calibration` | 태그–앵커별 bias_m, 출처, 버전 |
| 입력 | `previous_state` | 앵커별 수용 거리·최근 관측 시각·보류 군집 |
| 출력 | `cal_slant_m` | float/null, m |
| 출력 | `accepted_range_m`, `gate_decision` | 수용값과 보류 사유 |
| 출력 | `history` | 수용된 표본만 포함한 RangeWindow |

## 설정

| 파라미터 | 단위·범위 | ZIP 참고값 / 시험 설정 |
|---|---|---|
| `bias_m[anchor_id]` | m, 유한값 | 시험 태그별 명시. 없으면 blocked |
| `range_gate_mode` | off/reference | 두 비교군. off도 형식 검사는 유지 |
| `margin_m`, `speed_m_s` | m, m/s | 0.20 / 1.20, 참고값 |
| `dt_cap_s` | s | 0.50, 참고값 |
| `cluster_radius_m`, `confirm_count` | m, 정수 | 0.15 / 3, 참고값 |
| `window_s`, `capacity` | s, 표본 수 | 0.8 / 192, 참고값 |

## 처리 구조와 산식

```text
RAW 보존 → 편향 차감 → 범위 검사 → 거리 게이트
                                 ├─ 수용 → 이력 추가
                                 └─ 보류 → 군집 확인·진단 기록
```

```text
bias = RAW - 기하학적 기준 거리
r_cal = r_raw - bias
allowed_change = margin + speed*min(dt, dt_cap)
accept when abs(r_cal - last_accepted) <= allowed_change
```

ZIP의 dt는 직전 관측 시각과의 차이다.
직전 수용 시각과 혼용하지 않는다.
게이트 밖 거리도 군집 반경 안에서 정해진 횟수 확인한다.
확인 후 군집 평균을 새 거리로 수용한다.
참고 편향이 현재 장치의 교정 완료를 뜻하지 않는다.

## 실패와 상태

누락·범위 밖·역행 시각은 이력에 추가하지 않는다.
이전 수용 거리를 새 관측으로 복제하지 않는다.
단절 후 창 초기화와 앵커 게이트 상태 유지 여부를 기록한다.
현재 구현은 단절 때 창을 비우고 게이트 상태는 유지한다.
다른 초기화 정책은 별도 variant로만 비교한다.

## 테스트와 평가

| 시험 | 확인할 결과 |
|---|---|
| 양·음 편향 | RAW−편향의 부호와 RAW 불변 |
| 한 번의 거리 튐 | 보류 후 정상 복귀 |
| 실제 새 거리 수준 | 확인 횟수와 재획득 지연 |
| 지속 편향·빠른 이동 | 오수용·정상 이동 거부를 구분 |
| 게이트 off/reference | 같은 위치 모델에서 정확도·가용률 비교 |

Z 없이 거리 단계 시험을 설계할 수 있다.
과거 파이프라인 시험과 새 모델 비교 결과는 분리한다.
