# 수동 비행의 최종 UWB 통합 관측 시험
Position/Hold가 안정된 상태의 측정 절차다.
UWB·ToF·IMU·PX4를 같은 비행에서 비교할 때 읽는다.

## 목적과 완료 범위

UWB 관측의 정확도·연속성·동적 지연을 평가한다.
현재 환경의 1m 이상 호버는 사용자 확인을 전제로 둔다.
근거는 [조명·그림자 기록](../report/optical_flow_environment_20261010.md)이다.
저고도 조명 재시험은 이번 선행 과제가 아니다.

이번 시험은 RC 수동 조종으로 관측 자료를 모은다.
UWB→FC 전달과 자동 미션은 별도 후속 검증이다.
이유: 안정된 기존 위치 유지와 미검증 UWB의 영향을 구분한다.
기존 수집 경로는 [부팅 기록](manual_capture_boot.md)을 따른다.

```text
RC 조종 → PX4 Position/Hold → 실제 기체 이동
                          ├─ PX4 ULog
                          └─ IMU·ToF·광류·위치·RC 기록
UWB 거리 → B_TF 판정·좌표 ──── 같은 시행으로 묶기
독립 영상·실측 기준점 ───────── 실제 이동과 비교
```

## 1. 시험 조건과 기록 준비

시험 시작 전에 비교 기준을 고정한다.

1. 중앙 P0, +X 1m의 PX, +Y 1m의 PY를 표시한다.
2. 여유 공간에 맞춰 거리를 줄이면 실제 거리를 기록한다.
3. 앵커 XYZ·ID·태그·장착값과 설정 해시를 보존한다.
4. 현재 환경에서 이미 안정된 1m 이상 높이를 선택한다.
5. 기체 방향과 바닥·조명을 이번 시행에서 유지한다.
6. Jetson 기록과 FC ULog의 실제 증가를 확인한다.
7. 영상과 로그의 시간 대응을 남긴다.

고도는 조종자가 유지하고 PX4가 제어한다.
이번 절차는 MIS_TAKEOFF_ALT 변경을 요구하지 않는다.
RAW·B_TF 판정·IMU·ToF·PX4 위치·RC를 함께 기록한다.
광류 원본과 실제 융합 상태도 ULog에서 확인한다.
파일명 날짜만으로 같은 비행의 ULog라고 판단하지 않는다.

정확도 기준점은 UWB 안테나 위치에 대응시킨다.
눈금 위 호버 지시만으로 실제 위치를 확정하지 않는다.
영상은 원근·시차와 비행 높이를 반영한다.
독립 기준의 오차가 크면 cm 단위 정확도는 미판정이다.

## 2. 지상 수신과 이력 확인

먼저 20초 동안 기록이 갱신되는지 확인한다.
지상 ToF가 최소 거리보다 작을 수 있다.
지상 참조 높이를 공중 실측 높이로 집계하지 않는다.

B_TF가 이전 위치 때문에 계속 격리되는지 확인한다.
격리되면 지상·DISARM에서 관측 이력을 정리해야 한다.
표준 초기화 절차는 아직 미구현이다.
수집기 재시작과 B_TF 이력 초기화를 구분한다.
모델만 초기화해도 이전 위치 guard는 남을 수 있다.
실제 재시작·초기화는 별도 준비 작업으로 기록한다.
기록 조각 전환은 관측 세션 초기화가 아니다.
비행 중 자동 초기화나 거부 문턱 완화로 통과시키지 않는다.
이유: 잘못된 위치 점프를 정상 관측으로 승인할 수 있다.

## 3. 첫 비행: 기준 자료 수집

안정된 높이에서 정지와 한 축 이동을 차례로 기록한다.
아래 시간·거리는 이번 자료 수집을 위한 제안이다.
기체 heading과 높이는 왕복 중 유지한다.

| 순서 | 조종 동작 | 기록 목적 |
|---|---|---|
| 1 | P0 위 안정된 높이에서 20초 호버 | 공중 정지 분산·실측 높이·발행률 |
| 2 | P0→PX 1m를 천천히 이동, 10초 정지 | +X 방향·이동량·정지 후 회복 |
| 3 | PX→P0 복귀, 10초 정지 | 반대 방향 지연·복귀 편차 |
| 4 | P0→PY 1m를 천천히 이동, 10초 정지 | +Y 방향·이동량 |
| 5 | PY→P0 복귀, 20초 호버 | 반복 위치 편차·종료 안정성 |
| 6 | 착륙·DISARM, 기록 종료 확인 | 하강·착륙 상태와 기록 완전성 |

왕복 이동 속도는 약 0.2~0.3m/s를 제안한다.
조종자의 실제 이동 시간과 궤적을 기준으로 분석한다.
위 계획은 대략 2분 내외다. 배터리·현장 여유를 우선한다.
이미 확인한 Position/Hold를 별도 장시간 재시험하지 않는다.
공중 B_TF가 계속 없으면 관측 실패 구간으로 기록한다.
그 상태로 왕복을 반복해도 보정 성능을 입증할 수 없다.
기체의 위치 유지가 무너지면 조종자가 시험을 끝낸다.

## 4. 두 번째 비행: 독립 확인

첫 비행과 같은 조건으로 왕복을 한 번 더 기록한다.
첫 자료에서 얻은 보정 후보를 두 번째 자료로 확인한다.
운영 보정값을 비행 사이에 자동 적용하지 않는다.
이유: 같은 자료에 맞춘 결과를 독립 검증으로 볼 수 없다.

축별 왕복이 양호하면 별도 사각 경로를 추가할 수 있다.
P0→PX→(P0의 +X 1m,+Y 1m)→PY→P0 순서다.
각 모서리에서 5초 정지한다.
첫 왕복에 없던 조합 이동의 일관성을 본다.
이번 필수 시험에 yaw·높이 변경·고의 센서 단절은 넣지 않는다.
이유: 축별 이동과 시간 보정의 원인을 먼저 구분한다.

## 5. 기록 회수와 판정

모든 조각과 같은 비행의 ULog를 함께 회수한다.
자동 기록은 기본 180초마다 조각을 바꾼다.
같은 boot_id·원본 시각으로 이어 붙여 분석한다.
조각 경계의 실제 공백은 숨기지 않는다.
착륙 후 종료 상태와 PC 복사 해시를 확인한다.
첫 비행과 두 번째 비행의 설정·배치를 대조한다.

| 평가 축 | 남길 결과 |
|---|---|
| RAW 수신 | 전체 cycle, 네 앵커 비율, 앵커별 누락 |
| B_TF | 새 관측 발행률, 최대 공백, 거부 사유 |
| 높이 | 실측 ToF·IMU 비율, 지상 참조 사용 구간 |
| 위치 | 독립 기준 대비 평균 편향·RMSE·p95 |
| 방향·이동량 | X·Y 왕복 부호, 실제 거리와 차이 |
| 시간 | 축별·왕복별 지연 후보와 반복 일관성 |
| 거리 일관성 | B4 내부 RMS와 실측 높이의 물리 잔차 |
| PX4 | 스틱 중립 구간, 실제 융합, reset·innovation |

6cm 내부 잔차를 XY 정확도 합격선으로 쓰지 않는다.
PX4 추정 위치는 비교 신호이며 독립 정답이 아니다.
시간 보정이 축·방향마다 다르면 확정하지 않는다.
센서 지연과 수집 큐·파일 전환 공백을 구분한다.
가용률은 전체 cycle 등 분모를 명시한다.
거부 표본을 제외한 정확도만으로 성공을 선언하지 않는다.

이번 완료는 분석 가능한 통합 자료와 개선 판단 확보다.
정량 인수 기준은 비행 입력 승인 전에 별도로 고정한다.
FC 융합 승인에 관측 수신 성공만을 사용하지 않는다.

## 6. 다음 결정

좌표·시각·장착·가용률 근거가 모이면 지상 융합으로 간다.
미달 항목은 해당 수정 하나를 적용해 같은 경로로 재측정한다.
그 뒤 UWB XY의 실제 PX4 융합과 수동 호버를 비교한다.
자동 이착륙·목표 이동은 그 다음 별도 시험이다.
저고도 LiDAR 보완은 설치 환경별 후속 과제로 유지한다.
