- Pixhawk 6C Mini (2대 중 잔여분) — 1대는 이미 확보되어 W1-08 완료. 예비분 대기
- XT60 병렬 분배 커넥터 2종 — 전원 조립(W3 tether 환경) 전까지 필요
- 외주 기체 설계 — 프레임 없으면 W3-07 hover 테스트 불가. 납기 확인 필요

## 주의/확인 필요 사항

1. UWB 보드가 1개뿐임. DWM3000EVB 1개 = 태그 1개 분량. 위치추정에는 앵커 3~4개가 별도로 필요한데, WBS에 "UWB 좌표지정(anchor·좌표계) 완료"로 기재되어 있으므로 기존 보유 앵커 세트가 따로 있는지 확인 필요. 없다면 즉시 조달 이슈.
2. 하방 센서 모델이 WBS 표기(TFmini)와 다른 TFmini Plus임. 통신 방식은 동일(UART)하나 문서/코드 주석에는 Plus로 통일 권장.
3. PMW3901 광학 흐름 센서는 WBS에 없는 장비. PX4에 직결하면 UWB 없이도 위치보정이 가능한 물건이라, 활용할지(예: UWB 백업) 봉인할지 팀 결정 필요.
4. Jetson·Pixhawk·T-mini Pro가 각 2개씩 = 사실상 예비 기체 1대분 여유. 테스트 중 파손 대비가 되어 있음.
