## 처리 순서와 보정식

평가 로그를 편향 산출에 넣지 않았다.
기준 XY는 편향 산출용과 평가용으로 분리했다.

```text
1차 RAW + 1차 기준점 + 앵커 좌표
  -> 앵커별 평균 거리 차이 -> 편향 후보 잠금
                                      |
2차 RAW ------------------------------+---> 편향 차감
  |                                          |
  v                                          v
차감 전 A 계산                          차감 후 A 계산
  |                                          |
  +--------------------+---------------------+
                       v
          별도 평가 기준 XY로 차이 계산
                       |
          전체 / 가림 보고 구간 / 구간 밖
```

두 A 계산은 같은 앵커·높이·풀이를 사용한다.
달라지는 조건은 거리 편향 차감 여부뿐이다.

```text
d_ref_i = norm(1차 기준점 XYZ - 앵커_i XYZ)
bias_i = mean(1차 RAW_i) - d_ref_i
cal_slant_i = 2차 RAW_i - bias_i

d_i(x,y) = sqrt((x-ax_i)^2 + (y-ay_i)^2 + (z_recorded-az_i)^2)
(x_hat,y_hat) = argmin sum(i=1..4) (d_i(x,y)-cal_slant_i)^2
```

차감 전 비교군은 마지막 식의 거리에 RAW를 넣는다.
높이 기록은 `z_recorded`에 들어간다.
평가 XY는 위치 풀이의 초기값으로 사용하지 않는다.

| 앵커 | 1차 유효 거리 수 | 이번 편향 후보(m) |
|---|---:|---:|
| A1 | 2,533 | -0.144755 |
| A2 | 2,533 | +0.198235 |
| A3 | 2,532 | -0.175438 |
| A4 | 2,533 | -0.059137 |

음수 편향도 식 그대로 차감한다.
이 후보는 해당 지점의 반복 시험용이다.
거리 자체의 편향 외에 좌표·기준점 오차도 흡수할 수 있다.
따라서 운영용 교정 완료 값으로 등록하지 않았다.
9월 20일 다른 시험의 네 편향값은 사용하지 않았다.

## 후속 비교에 사용할 범위

이 자료로 편향 차감과 가림 처리의 효과를 비교할 수 있다.
H80·거리 게이트 등을 붙일 때 A를 같은 조건으로 유지한다.
2차 로그는 이미 결과를 확인한 개발용 평가 자료다.
이를 보며 새 임계값을 조정하면 별도의 최종 평가가 필요하다.
같은 지점의 반복 측정만으로 구역 전체 성능을 정하지 않는다.
ToF 연동과 비행 검증에는 동시 UWB·ToF·자세가 필요하다.
