# M16 GNSS·UWB 관측 융합 비교

GNSS와 UWB를 함께 평가하는 추가 센서 명세다. 동시 기록과 좌표 변환 자료가 준비됐을 때 읽는다.

## 목적과 현재 상태

실외·실내 전환 구간의 관측 연속성을 시험한다.
현재 장비 목록에 GNSS 시험 자료가 확보됐다는 근거는 없다.
따라서 기본 네 앵커 비교군의 필수 단계가 아니다.
로드맵의 비행용 상태추정기 책임은 변경하지 않는다.

## 입출력

| 방향 | 파라미터 | 형식·단위·조건 |
|---|---|---|
| 입력 | `gnss_position` | 측정 시각·위치·기준 좌표계·상태 |
| 입력 | `gnss_covariance`, `uwb_candidate` | 공분산·UWB 위치와 공분산 |
| 입력 | `R_W_ENU`, `origin`, `lever_arms` | 양 센서의 원점·방향·기준점 변환 |
| 입력 | `observation_lineage` | 공유 센서·사전 융합 유무 |
| 출력 | `estimate` | 같은 기준점의 결합 Candidate |
| 출력 | `fusion_weights`, `source_status`, `innovation` | 결합 근거 |
| 출력 | `outage_state`, `covariance_kind` | 단절·불확실성 상태 |

## 설정

| 파라미터 | 단위·범위 | 초기 상태 |
|---|---|---|
| `fusion_level` | position | 1차 시험 범위 |
| `covariance_policy` | independent/covariance_intersection | 계보에 따라 명시 |
| `max_time_skew_s`, `source_age_limit_s` | s | 미확정 |
| `ci_weight` | 0~1 | 실행 전 고정하거나 사전 탐색 규칙 명시 |
| `innovation_threshold` | 선언한 통계 단위 | 미확정 |

## 처리 구조와 산식

```text
GNSS 위치 → 지역 ENU → 창고 W → 기준점·시간 정렬 ─┐
UWB 위치 ───────────→ 같은 기준점·시간 정렬 ────┤
                    계보·공분산 검사 → 결합 → 파일 기록
```

독립 오차 가정이 입증된 경우의 XY 결합은 다음과 같다.

```text
P = inverse(inverse(P_gnss)+inverse(P_uwb))
p = P*(inverse(P_gnss)*p_gnss + inverse(P_uwb)*p_uwb)
```

상관이 미상일 때의 비교 후보는 공분산 교차 결합이다.
위 두 정보행렬에 각각 omega와 1−omega를 곱한다.
개별 공분산이 타당하다는 전제는 여전히 필요하다.
공분산이 없는 출처는 수치 결합을 차단한다.
PX4가 이미 결합한 위치를 다시 독립 GNSS라고 넣지 않는다.

이 명세는 수신기 위치 수준의 비교안이다.
논문의 원시 관측 융합을 완전히 재현한 것이 아니다.
의사거리 수준의 구현은 시계 상태·위성 정보 계약이 추가로 필요하다.
그 입력을 UWB 거리식에 그대로 넣지 않는다.

## 실패와 상태

좌표 원점·지오이드/타원체 높이·안테나 기준점을 확인한다.
축과 단위가 확인되지 않으면 계산을 차단한다.
한 출처 단절 시 남은 출처만 표시하고 융합 성공으로 세지 않는다.
실내 GNSS 품질 저하를 단순 평균으로 숨기지 않는다.

## 테스트와 평가

| 시험 | 확인할 결과 |
|---|---|
| 알려진 좌표 변환·장착값 | 축·원점·부호 확인 |
| 한 출처 편향·시간 지연 | 결합 오염과 이상 검출 |
| 실외→실내→실외 | 가용률·오차·복구 지연 |
| 상관된 출처 | 독립 가정과 보수적 결합 비교 |
| UWB 단독/GNSS 단독/융합 | 같은 구간·기준 위치로 비교 |
