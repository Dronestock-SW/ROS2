문서 재구성 검토 기록

대상은 원본 REPORT.md의 전체다. 수정 전 스냅샷은 REPORT.before.md이며 원고 해시와 각 문장 ID는 paragraph-packet.json에 고정했다. 원문에 있던 수치와 출처를 옮기면서 새 재생·비행·배포 결과를 만들지 않았다.

**실제로 바꾼 전개**

원문은 기준 표→지연 분류표→하드웨어 표→논문 소개→설계 목록으로 이어졌다. 현재 FREEZE의 동작을 설명하기 전에 여러 검토 항목이 나타났고, 독자가 각 항목이 왜 필요한지 연결해야 했다. 새 본문은 현재 목표 송신의 의미부터 설명한다. 목표 진행 정지와 실제 제동의 차이, 경로속도와 보정속도의 차이를 먼저 알린 뒤 감속·대기·위치 보정·재출발을 제안한다.

전체 57문단·191개 문장에 대한 역할과 조작은 paragraph-review.json에 직접 작성했다. 합친 문안은 9개 revision_groups에 한 번씩 저장했다. 제목·표·코드의 배치까지 달라지므로 원문 표를 그대로 보존하는 review apply는 사용하지 않고 최종 문서를 별도 조립했다.

**세 관점의 실제 점검**

논리 관점에서는 ‘거부가 정상’과 ‘입력이 정상’을 구별했다. 정상적인 거부를 유지하면서 거리 모순과 처리 만료를 각각 개선한다는 인과관계를 복원했다. ‘공백 0.7초’에서 바로 착륙으로 넘어가지 않고 실제 점프 판정과 복구 처리를 연결했다.

비전공 독자 관점에서는 FREEZE를 기체가 즉시 멈춘다는 말로 읽을 가능성을 수정했다. 기존 PX4도 고정 목표에 수렴하며 감속할 수 있다는 점을 명시하고, 부족한 부분을 정지거리·복귀 속도 보장으로 한정했다. 문단마다 ‘검증 필요’를 반복하지 않고 각 판단 뒤에 그 판단이 바꾸는 동작을 썼다.

전공자 관점에서는 실제 측정, 설명용 계산, 미적용 권고를 대조했다. 현재 통합 소스의 목표 생성·도착 판정·송신 mask·점프 판정을 다시 읽었다. 새 제동 경로와 0.25m/s FC 상한 후보는 구현·비행 검증이 끝난 사실로 바꾸지 않았다. 운영과 통합 소스의 판본 차이도 유지했다.

**수치·근거 보존**

수치 자동 대조는 문장 이동과 반복 횟수 변화 때문에 경고를 반환한다. 이를 자동 의미 검증 통과로 보고하지 않는다. 세부 경고는 guard.json에 있고, 수동으로 다음을 확인했다.

- 19.375/22.5/47.5cm는 원문의 동일한 속도·반응시간·감속 가정에서 나온 값이다. 실제 기체 제동성능이나 30cm 비행 승인으로 확대하지 않았다.
- 6.3m와 6.10296m, 2.360ms와 19.468cm는 같은 거리 모순 사례다. 약 526ms, 별도 부분 재생 364~384ms, 약 80ms GC, 초기화 3.86초를 하나의 지연으로 더하지 않았다.
- 50cm·0.95/s·0.475m/s는 제어식의 계산 예이며 실측속도가 아니다. 0.25m/s 상한은 적용 전 검토 후보이고, 0.5~0.75m/s 상향안을 채택하지 않은 이유는 그대로다.
- FC 15cm·UWB 25cm 도착 판정에 속도 0.1m/s 이하와 1초 안정화 조건을 최신 코드에서 보충했다. UWB 0.25초·FC 위치 0.2초, 송신 mask 2552도 같은 기존 코드의 설명을 추가한 값이다.
- 입력 나이 102~146ms, 0.8초 발행 주기 주장에 대한 정정은 기존 review_basis.md와 latest_corrections.md에서 보충했다. 새 실험값이 아니다.
- SIH 9.664초·18.573cm·24.384cm와 논문 평균 9.59cm·12.92cm의 평가 대상을 바꾸지 않았다. 실제 최대 오차 10cm가 검증됐다는 주장은 없다.
- 보드 사양·전체 부품·장착 벡터는 DETAILS.md에 보존했다. 과거 앵커 높이 2.2m와 log49의 실제 높이 0.15m, FC→태그와 ToF→태그 기준점을 혼합하지 않았다.
- 원문의 75개 자료 경로 수는 DETAILS.md와 SOURCE_INVENTORY.md에 유지했다. 장 번호 8·9의 등장 횟수 감소는 10개 절을 7개 절과 상세 근거로 재편한 결과이며 측정값 삭제가 아니다.
- 새 반복 숫자의 상당수는 표와 설명의 연결, 파일 경로, 장 번호다. 실제 의미가 보충된 값은 위 항목처럼 출처를 분리했다. 모든 기존 웹·로컬 근거 링크의 보존 여부와 파일 존재 여부를 별도로 검사한다.

문자상 자동 검사는 KSS 미설치로 regex 분리를 사용했다. 표 73행과 코드 10행은 원문 파서의 본문 검사에서 제외됐으므로 수동으로 확인했다. 코드 표기·링크·제목의 분리 오류도 원문과 대조했다. 문체 경고 수는 품질의 증명이 아니며, 이번 완료 기준은 사실 보존과 설명·행동의 연결이다.
