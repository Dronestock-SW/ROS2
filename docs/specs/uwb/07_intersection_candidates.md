# M07 앵커 조합의 12개 중간 교점 후보

묶음별 교점을 생성하고 결합하는 모델 명세다. 조합 수와 중간 후보 수를 구분해 구현할 때 읽는다.

## 목적과 현재 상태

네 묶음에서 각각 세 교점을 선택한다.
성공하면 중간 슬롯 12개와 묶음 위치 네 개가 생긴다.
서로 다른 독립 측정 12개가 생기는 것은 아니다.
Li 등 2017년 논문의 구조를 참고한 새 시험안이다.

## 입출력

| 방향 | 파라미터 | 형식·단위·조건 |
|---|---|---|
| 입력 | `frame`, `anchors`, `z_sample` | M06과 같은 시간·거리·Z |
| 입력 | `range_sigma_m`, `z_sigma_m` | m/null. 확장 variant에 필요 |
| 출력 | `pair_candidates` | 묶음 ID·앵커 쌍·선택 교점·분기 상태 |
| 출력 | `group_candidates` | 세 교점을 결합한 최대 네 Candidate |
| 출력 | `correction_m`, `ambiguity_flags` | 거리 확장량·모호한 선택 기록 |

## 설정

| 파라미터 | 단위·범위 | 초기 상태 |
|---|---|---|
| `intersection_policy` | strict/bounded_expansion | strict 기준선 |
| `expansion_limit_m`, `expansion_step_m` | m, 양수 | 확장 variant에서 필수. 미확정 |
| `tie_margin_m` | m, 0 이상 | 교점 점수 동률 판정. 미확정 |
| `min_horizontal_range_m` | m, 양수 | 불안정 투영 방지. 미확정 |
| `numeric_tolerance_m2` | m² | 부동소수점 오차 한정. 명시 필요 |
| `group_fusion` | mean | 논문 구조 기준선 |

## 처리 구조와 산식

```text
사거리와 Z → 수평 거리로 투영
  → 네 묶음 → 각 묶음의 세 앵커 쌍
  → 교점 두 개/한 개/없음 판정
  → 세 번째 앵커로 교점 선택
  → 중간 후보 최대 12개 → 묶음별 평균 → M08
```

```text
h_i^2 = r_cal_i^2 - (z_ant-az_i)^2
D = norm(center_B-center_A)
a = (h_A^2-h_B^2+D^2)/(2*D)
v = h_A^2-a^2
p_plus/minus = center_A + a*unit_AB ± sqrt(v)*perp(unit_AB)
```

원 중심 중복, 음의 h_i², 음의 v는 일반적으로 실패다.
수치 허용오차 이내만 0으로 정리하고 그 사실을 기록한다.
세 번째 앵커의 원래 사거리 잔차가 작은 교점을 선택한다.
동률이면 ambiguous로 남긴다. 정답 좌표로 고르지 않는다.
묶음 안의 세 교점을 평균한 뒤 네 묶음을 결합한다.
실패 슬롯을 복제해 12개를 채우지 않는다.

확장 variant는 최대 확장량과 중단 조건을 명시한다.
원본 거리와 가공 거리를 둘 다 기록한다.
논문의 신뢰구간 수식을 그대로 재현한 것으로 표시하지 않는다.
확장으로 교점이 생겨도 참 위치 검증은 별개다.

## 실패와 상태

Z 누락 또는 h가 너무 작으면 해당 투영을 차단한다.
접선 교점은 한 개로 기록한다.
후보마다 공유 앵커 쌍과 입력 ID를 보존한다.
M08에서 독립 후보 수로 공분산을 줄이지 않는다.

## 테스트와 평가

| 시험 | 확인할 결과 |
|---|---|
| 원 두 개의 교차·접선·분리·포함 | 분기와 교점 수 일치 |
| 세 번째 거리로 교점 선택 | 대칭 모호성 보존 |
| 네 앵커 정상 자료 | 중간 슬롯 12개·묶음 네 개 확인 |
| 지속 편향·확장 필요 | 보정량과 실제 오차를 함께 기록 |
| M06/M09와 같은 입력 비교 | 개선 여부·모호성 비율·계산량 |
