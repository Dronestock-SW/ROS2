# 웹 수직 이륙·POSITION 호버링 진단
2026-10-14 웹 이륙 목표의 구현·폐루프 검증 기록이다.
실기 적용 여부와 다음 시험을 판단할 때 읽는다.

## 결론

**무흐름 수직 이륙·제자리 호버링 목표는 아직 미달성이다.**
웹 이륙부터 POSITION 유지·웹 착륙까지 연결은 확인했다.
그러나 실제 PX4 SIH의 이동량·속도 기준을 통과하지 못했다.
R3는 지상 융합 확인용 후보로 보존한다.
운영 서비스 전환·실기 ARM·비행은 수행하지 않았다.

## 목표와 구현

이륙 순간의 XY를 유지하고 UWB 복구는 호버링에서 기다린다.

```text
웹 이륙 → 최초 XY 고정 → PX4 수직 상승
                        → 안정화 → POSITION → 제자리 유지
                                               ↓
                                     UWB 복구·5초 안정 확인
                                               ↓
                                     별도 웹 START 허용
```

초기 지상 UWB·FC 준비 확인은 유지한다.
상승·POSITION 전환에는 UWB 재안정화를 요구하지 않는다.
LiDAR 필수 설정에서는 북·동 속도 융합과 최신 상태를 요구한다.
PX4가 고도·자세·추력 제어를 담당한다.
수직 속도 미관측 값에 0을 넣지 않는다.

UWB 공백으로 상승 제한 시간이 계속 연장되던 경로를 수정했다.
LiDAR 이륙이 제한 시간 안에 안정되지 않으면 착륙한다.
최초 XY·조종자 우선권·관측 만료 검사는 유지한다.
수평 25cm 이탈 차단도 유지한다.

## 검증 범위

실행 코드·실제 PX4 동역학·실기 검증을 분리했다.

| 계층 | 수행 내용 | 결과 |
|---|---|---|
| C++ 실행기 | UWB 공백·미안정 상승 제한 포함 54개 계약 | WSL·Jetson 통과 |
| ROS 연계 | R3 수신 4개, 최종 시간 제한 반영 후 UWB 복구 1개 추가 | 모의 FC 통과 |
| PX4 EKF | 52개 사례, 독립 LiDAR 시작·소실·복구 포함 | 통과 |
| DISARM SIH | LiDAR 단독·UWB 복구·높이 소실 등 6회 | 통과 |
| 웹 폐루프 | HTTP → C++ → PX4 제어기 → SIH 기체 운동 | 엄격 기준 미통과 |
| 실제 R3 FC | 설치·융합·수직 이륙·POSITION 호버 | 미실시 |

웹 폐루프는 실제 `LocalPlatform` HTTP와 C++ 실행기를 사용한다.
PX4가 명령으로 SIH 기체를 움직인다.
기체 위치를 목표값에 맞춰 덮어쓰는 모의 FC가 아니다.
이 시험에 ROS/MAVROS는 포함되지 않는다.
해당 전송 경로는 위 Jetson 모의 시험으로 구분한다.

LiDAR·UWB는 SIH 진실값에 선언한 잡음을 더한 합성 입력이다.
실제 스캔 장면·동적 시각 보정·장착 정확도의 증거가 아니다.
하방 거리 입력도 선언한 센서 위치·cm 양자화를 사용한다.
실기 TFmini Plus 측정 또는 보정값이 아니다.
모든 시험은 기체와 분리된 loopback 네트워크에서 수행했다.

## 정량 결과

POSITION 도달과 무흐름 기준 통과는 별개다.
`web-takeoff-gap-v16`의 원본 ULog 진실값을 사용한다.

| 항목 | 기준 | 측정 | 판정 |
|---|---:|---:|---|
| POSITION 연속 유지 | 20초 이상 | 24.224초 | 통과 |
| 전체 상승·유지 수평 이탈 | 0.25m 이하 | 0.24384m | 통과 |
| POSITION 수평 이탈 | 0.15m 이하 | 0.24384m | 실패 |
| POSITION 수평 속도 최대 | 0.10m/s 이하 | 0.20225m/s | 실패 |
| 진실 높이의 1.7m 오차 최대 | 0.15m 이하 | 0.17610m | 실패 |
| FC 높이 목표 오차 최대 | 0.15m 이하 | 0.16232m | 실패 |
| UWB 부재 중 POSITION 유지 | 수행 여부 | 9.664초 | 수행 |
| UWB 부재 중 수평 이탈 최대 | 별도 관측 | 0.18573m | 기준 초과 |
| UWB 복구 후 수평 이탈 최대 | 별도 관측 | 0.24384m | 기준 초과 |
| 수평 위치 리셋 | 횟수 기록 | 1회 | 숨기지 않음 |
| 수직 위치·속도 리셋 | 횟수 기록 | 0회·0회 | 확인 |

25초 유지 예약은 호스트 시계 기준이다.
위 24.224초는 ULog의 시뮬레이터 시계 기준이다.
최종 웹 LAND 뒤 실제 SIH DISARM을 확인했다.
임무 START는 보내지 않았다.
따라서 결과의 `operator_cancelled`는 이 웹 착륙 경로다.
목표 실패 판정은 이동량·속도·높이 기준 초과 때문이다.

## 실패와 시험 연결 수정

실패를 제외하거나 허용 범위를 넓혀 통과 처리하지 않았다.

| 시도 | 확인한 내용 |
|---|---|
| v1 | 시험 Python 의존성 누락. PX4 실행 전 실패 |
| v2 | PX4 instance별 system ID·LiDAR 상태 나이 누락 수정 |
| v3 | pymavlink의 OFFBOARD 해석 오류. PX4 main-mode 직접 판독 |
| v4·v5 | UWB 소실·정상 각각 상승 중 수평 이탈 차단 |
| v6~v11 | 관측 불확실성·고도 기준·IMU 잡음 민감도 비교. 모두 실패 |
| v12 | 새 거리 입력을 추가했으나 기존 센서가 계속 선택됨 |
| v13 | 내장 거리 발행 중지 후 단일 합성 거리 입력 확인. 안정화 시간 초과 |
| v14·v15 | 기본 IMU 모델·출력 예측 시간 상수 비교. 실패 |
| v16 | POSITION 유지·웹 착륙까지 완료. 무흐름 기준 실패 |
| v17 | 출력 예측 시간 상수 변경. 안정화 시간 초과 |
| v18 | PX4 속도 피드백 2Hz 필터 비교. 안정화 시간 초과 |

SIH 기본 거리값은 지상에서 약간 음수가 될 수 있다.
PX4는 처음 선택한 거리 센서를 발행이 끊길 때까지 유지한다.
단순히 범위를 벗어나게 해도 다른 센서로 바뀌지 않았다.
`SIH_DISTSNSR_OVR=10000`으로 내장 발행을 중지했다.
새 합성 센서의 위치 보정도 시험 파라미터에 명시했다.

SIH IMU 잡음과 선언한 합성 관측 잡음의 민감도를 비교했다.
시험별 값은 manifest와 아래 증거 JSON에 보존한다.
이 값들을 실기 FC에 쓰지 않았다.
성공 사례만 뽑아 실기 권장 설정으로 만들지 않는다.
