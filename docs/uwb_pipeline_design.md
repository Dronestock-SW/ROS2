# UWB 파이프라인 개발 기준

시뮬레이션 입력부터 기록까지 잇는 설계 기준이다.
모듈을 추가하거나 계산 게이트를 검토할 때 읽는다.

## 현재 결정

**입력·보정·기록을 먼저 연결한다.**
2026-09-21 사용자 지시를 반영했다.
ToF 실측 자료는 아직 없다.
시뮬레이터 자료를 모은 뒤 실측을 추가한다.
좌표 계산과 외부 전달 게이트는 닫는다.

거리 보정식은 `RAW - 편향`이다.
ZIP README의 `fixed range bias is zero`는 오기다.
사용자가 작성자의 실수라고 확인했다.
원본 RAW와 보정 거리는 따로 보존한다.

2026-09-26에는 후속 아이디어의 [개별 시험 명세](specs/uwb/README.md)를 작성했다.
17개 모듈의 입출력·산식·구조와 비교 모델 선정 절차를 정의했다.
현재 파이프라인의 기능 추가나 게이트 개방은 수행하지 않았다.
ToF 기반 Z 자료는 대기 중이며 새 모델 시험은 미실시다.

## 처리 프로세스

실행 프로세스는 `uwb_pipeline` 하나다.
단계는 Python 모듈로 나눈다.
현재 입력은 파일 또는 합성 시뮬레이터다.

```text
합성 시뮬레이터 / 기록된 입력 파일
    |
    v
원본 저장 -> 입력 검사 -> 시간 기록
                            |
              +-------------+-------------+
              |                           |
           UWB RAW                   ToF / 자세
              |                           |
          편향 차감                  출처·시각 검사
              |                           |
          거리 게이트                  표본 버퍼
              |                           |
          승인 거리 이력 -----------------+
                            |
                  진단 기록 + 단계별 상태
                            |
                 [높이·좌표 계산: 닫힘]
                 [좌표 외부 전달: 닫힘]
```

| 단계 | 모듈 | 현재 동작 |
|---|---|---|
| 입력 생성 | `preimu/simulator.py` | 고정 XY·변화하는 Z로 합성 표본 생성 |
| 실행·원본 기록 | `preimu/runner.py` | 원문 바이트 저장 후 처리·재생 |
| 입력 검사 | `preimu/inputs.py` | schema·seq·mask·failure·측정 시각 검사 |
| UWB 시간 매핑 | `preimu/clock.py` | ESP32→호스트 근사 매핑과 상태 기록 |
| 편향·거리 게이트 | `preimu/ranges.py` | 편향 차감·보류·3회 재획득·이력 유지 |
| ToF·자세 입력 | `preimu/sensors.py` | 출처와 측정 시각을 포함해 보관 |
| 단계 연결 | `preimu/pipeline.py` | 결과 취합·게이트 상태·보류 사유 기록 |

파일 입력의 부팅 상태는 세션 동안 유지한다.
새 boot·재시작·통신 복구 실패 때 초기화한다.
RAW 펌웨어는 주기적 상태 송신을 보장하지 않는다.
입력 단절은 cycle과 tick 사이 경과시간으로 기록한다.

## 계산 함수 경계

수식 함수는 존재하지만 실행 경로에서 호출하지 않는다.
이유: Z 자료와 기하 조건을 아직 검증하지 않았다.

| 계산 | 함수·파일 | 현재 범위 |
|---|---|---|
| ToF→FC 높이 | `height.tof_to_fc_height` | 자세·광축·거리 편향·레버암 수식 |
| Z 시간 필터 | `height.alpha_beta_step`, `height.median3` | 한 단계 계산 함수 |
| 안테나→FC 위치 | `height.antenna_to_fc_position` | 장착 오프셋 변환 수식 |
| raw XY | `rawxy.solve_raw_xy` | 기존 함수 보관 |
| H80 | `h80.fit_h80` | 기존 함수 보관 |
| Q_S10 | `qs10.solve_q_s10` | 기존 함수 보관 |
| 창고→PX4 좌표 | `transform.warehouse_to_px4` | 기존 함수 보관 |

기존 H80·Q는 ZIP과 완전히 같다고 판정하지 않았다.
앵커 수·반복·잔차·Q 규제식 등의 대조가 남아 있다.
Z pending·정지/이동 전환도 연결하지 않았다.
자세 SLERP와 표본별 Z의 풀이 연결은 후속 작업이다.
현재 버퍼는 측정시각 이전 표본을 선택한다.
이 선택은 자세 보간이나 높이 계산을 대신하지 않는다.

`calculation_enabled`는 false만 허용한다.
`external_output_enabled`도 false만 허용한다.
설정만 바꿔 게이트를 여는 기능은 제공하지 않는다.

## 입력 형식

시뮬레이터와 후속 실측 자료는 같은 봉투 형식을 쓴다.
봉투 안의 `message`가 센서 원본이다.

| 필드 | 의미 |
|---|---|
| `source` | `simulation` 또는 `measured` |
| `host_received_monotonic_ns` | 호스트가 받은 단조 시각(ns) |
| `message` | UWB 상태·거리, ToF, 자세, tick 중 하나 |
| `simulation_truth` | 합성 기준값. 입력 계산에는 사용하지 않음 |

ToF·자세는 호스트 시간축의 측정 시각을 요구한다.
`clock_domain=host_monotonic_us`로 표시한다.
FC/ToF 장치 시각의 실제 매핑 어댑터는 아직 없다.
미매핑 시각을 호스트 시각으로 간주하지 않는다.
이유: 다른 순간의 거리와 자세가 섞일 수 있다.

이번 합성 입력은 Gazebo 물리 시험이 아니다.
기준 XY는 `(0.70, 1.80)`m다.
Z는 `1.13 + 0.12 sin(2πt/4)`m다.
거리·자세·기준값에 simulation 출처를 기록한다.
ToF 잡음 표준편차는 0.002m다.
UWB 잡음 표준편차는 0.005m다.
두 값은 합성 설정이며 센서 실측값이 아니다.

## 출력 계약: 기록 양식과 읽는 규칙

**값과 사용 가능 여부를 함께 전달한다.**
좌표 숫자만 보내면 받는 쪽이 시험값을 구분하기 어렵다.

| 현재 필드 | 쉬운 의미 | 현재 값 |
|---|---|---|
| `source`, `z_source` | 실제 센서인가, 시뮬레이션인가 | 입력 출처 |
| `raw_slant_m` | 처음 받은 거리 | 원본 그대로 |
| `cal_slant_m` | 편향을 뺀 거리 | `RAW - 편향` |
| `range_accepted` | 거리 게이트가 이번 값을 받았는가 | 앵커별 true/false |
| `stages` | 어디까지 처리했는가 | 단계별 상태 |
| `measurement_time_us` | 진단이 참조한 UWB 시각 | 매핑 전에는 null |
| `source_fresh` | UWB 입력이 시간 기준 안인가 | 좌표 사용 허가와 별개 |
| `x_m/y_m/z_m` | 계산한 위치 | 모두 null |
| `valid` | 이 위치를 외부 관측으로 써도 되는가 | false |
| `fresh` | 신선한 최종 위치가 있는가 | false |
| `reason` | 사용 불가 또는 처리 상태의 이유 | 예: `calculation_gate_closed` |

`null`은 0m가 아니라 계산값 없음이다.
`valid=false`는 시험 파이프라인의 실패를 뜻하지 않는다.
현재는 사용 게이트가 닫혀 있다는 뜻이다.

기록 type은 `uwb_pipeline_diagnostic`이다.
PDF의 최종 `jetson_uwb_preimu` 계약은 후속 단계다.
500ms tick 검사는 입력 단절 진단이다.
비행용 failed·복귀 hold 정책의 구현 완료를 뜻하지 않는다.

## 적용 설정

시뮬레이션에는 참고 편향을 명시적으로 적용한다.

| 항목 | 현재 값 |
|---|---|
| 편향(m) | `[-0.08733, +0.41107, -0.11148, +0.15125]` |
| 편향 출처 | 2026-09-20 ESP32 시험값 |
| 현재 태그 교정 완료 | false |
| 거리 게이트 | `0.20m + 1.20m/s × Δt` |
| 거리 재획득 | 0.15m 이내 3회 |
| 거리 이력 | 0.8초, 최대 192개 |
| ToF·자세 버퍼 | 종류별 최대 512개 |
| 버퍼 표본 age | 0.10초 후보값. 높이 신뢰 판정 아님 |
| 합성 앵커 배치 | 기존 `anchors_20260906.json` |

`PreimuSettings.fixed_z_m`는 기존 설정 항목이다.
새 파이프라인에서는 읽거나 대체 높이로 쓰지 않는다.
