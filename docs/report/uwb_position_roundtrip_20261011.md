사용자 비행 보고와 확인 자료를 보존한 기록이다.
이번 왕복 시험과 다음 분석을 이어갈 때 읽는다.

## 판정

점프 보호 발동과 UWB 전송 중단을 확인했다.
차단의 적절성은 아직 미판정이다.

## 사용자 보고한 비행 순서

두 축 이동 뒤 각각 시작 지점으로 돌아왔다.
처음의 편도 이동·도착점 정지 해석을 정정한다.
2026-10-11 17:33 KST 무렵 보고받았다.
이 시각은 보고 인접 시각이며 이륙 시각이 아니다.
사용자는 착륙·DISARM 완료도 확인했다.

```text
시작 지점 정지
    |
    v
+Y 방향 1m 이동 -> 시작 지점 복귀 -> 20초 정지
    |
    v
+X 방향 1m 이동 -> 시작 지점 복귀
    |
    v
착륙 -> DISARM
```

| 항목 | 근거와 남은 확인 |
|---|---|
| 실내 축 | +X=A1→A2, +Y=A1→A3 |
| 이륙 전 기수 | 사용자 확인 −Y=A3→A1 |
| +Y 왕복 | +1m 뒤 시작 지점 복귀·20초 정지 보고 |
| +X 왕복 | +1m 뒤 시작 지점 복귀 보고 |
| 마지막 정지 | 최초 보고는20초; 복귀 추가 설명 뒤 재확인하지 않음 |
| 이동 소요 시간 | 미확인. 20초를 이동 시간으로 쓰지 않음 |
| 이륙·이동·착륙의 정확한 시각 | 미확인 |
| 시험 고도·독립 거리 기준 | 미확인 |
| 비행 중 모드·정밀 경로 | 사용자 시험 문맥과 사후 POSCTL 확인. 전 구간 대응 미실시 |

## 점프 보호의 의미

잘못 튄 위치가 비행 제어에 들어가지 않게 한다.
UWB 좌표는 거리 오류·가림의 영향을 받는다.
PX4가 잘못된 위치를 실제 이동으로 해석할 수 있다.
그 위치에 반응하는 보정 명령을 예방하는 목적이다.
전송 중단이 드론의 정지 명령을 뜻하지는 않는다.
다른 센서 융합과 실패 대응은 PX4가 맡는다.

의심 관측으로 기준을 바꾸지 않는 의도된 보호다.
시간이 지났다고 새 좌표를 자동 승인하지 않는다.
착륙·DISARM만으로 기준을 초기화하지 않는다.
전달기에는 시험용 좌표 점프 생성이 없다.

| 상황 | 판정 |
|---|---|
| 실제로 잘못된 좌표를 차단 | 의도한 보호 동작 |
| 정상1m 이동을 점프로 오인해 차단 | 오거절 조사 대상 |
| 이번 자료 | 보호 발동만 확인. 차단 적절성 미판정 |

검증 근거는 `test_observation_guard.py`에 있다.
큰 변화가 계속 들어와도 이전 기준점을 유지한다.
현재 기본 제한은1m/s·여유0.10m다.
공백에 따른 추가 허용은 최대0.25초까지만 늘린다.

```text
기본 허용 거리 = 0.10m + 1m/s × min(기준점 이후 시간, 0.25s)
25ms 간격: 0.125m / 기본 검사 상한: 0.35m

연속 정상 이동 -> 승인 -> 기준점도 이동 -> 다음 관측 검사
큰 의심 변화 -> 거절 -> 이전 기준점 유지 -> 다음 관측 검사
```

35cm는 비행 반경이나 총 이동 거리 제한이 아니다.
승인한 기준점은 정상 이동을 따라 계속 바뀐다.
따라서 연속된1m 이동도 통과할 수 있다.
거절된 좌표는 기준점을 바꾸지 않는다.
반복되는 같은 오류를 정상값으로 만들지 않기 위해서다.
시간 경과만으로 허용 거리를 무한히 늘리지 않는다.
착륙·DISARM도 좌표 정확도를 증명하지 않는다.
그래서 자동 초기화의 근거로 사용하지 않는다.

17:34 표본의 이전 전송점과 차이는 약0.74m다.
이 값은 같은 NED 안테나 XY끼리 비교한 값이다.
기본0.35m 상한을 넘는다는 점은 설명할 수 있다.
실물 이동인지 측정 오류인지는 이 비교로 알 수 없다.
기본 수치의 현장 적합성도 아직 검증하지 못했다.
이 값의 존재로 이번 관측이 잘못됐다고 판단하지 않는다.
승인 속도에 의한 이동 재획득도 별도 조건을 요구한다.
같은 시각의 실제 이동과 입력 좌표를 대조해야 한다.
