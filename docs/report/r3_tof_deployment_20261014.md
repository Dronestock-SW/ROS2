# R3·ToF 결합 펌웨어 적용 기록
2026-10-14 실제 FC 업로드와 설정 확인 기록이다.
노트북에서 현재 실행 펌웨어를 확인할 때 읽는다.

## 작업 범위

LiDAR 독립 수평속도 융합 R3와 ToF 전용 모드를 결합한다.
CRSF와 현재 기체 보정값을 보존한다.
사용자는 모터 전원 분리 또는 프로펠러 제거를 확인했다.
FC·Jetson 전원을 유지할 수 있다고 확인했다.
하향 표적 거리를 지금 바꾸는 것은 어렵다고 했다.
따라서 유효 거리 50Hz 검증은 현장 후속 조건이다.

## 변경 전

17:10 조회 FC는 13일19:30 빌드·R2였다.
EKF2_LID2_VER=1, EN=1, AGE=180ms였다.
ToF 연속 5표본의 4간격은101.500~101.601ms였다.
거리0.021~0.023m는 TFmini Plus 최소0.1m보다 작았다.
현재 숫자 파라미터1,098개를 새로 보존했다.
MAVROS pull1,099개에는 해시 항목이 포함된다.
어제 대비 가속도계 offset6개가 바뀌었다.
어제 값을 복원하지 않고 현재 값을 기준으로 유지한다.

## 결합 방법

bluewak의 ToF 기준본을 별도 작업 경로에 복사했다.
기존 bluewak 소스·산출물은 수정하지 않았다.
복사본에서 R2 패치를 역적용한 뒤 R3를 적용한다.
ToF 패치와 R3 패치의 역적용 검사를 모두 요구한다.
CRSF·TF02PRO·EKF2_AUXVEL 보드 구성을 유지한다.

초기 복사와 패치 단계가 겹쳐 R2가 남은 것을 검출했다.
해당 빌드를 중단하고 복사 완료 뒤 R3를 재적용했다.
그 중간 결과는 업로드하지 않았다.
최종 빌드는 별도 build-r3.log에 기록한다.
결합본의 ToF 소스4개는 기존 ToF 기준본과 해시가 같다.
생성 boardconfig에서 CRSF·TF02PRO·EKF2_AUXVEL을 확인했다.

재현 도구 prepare_lidar_independent.py에 --with-tof를 추가했다.
이 옵션은 소스만 구성한다. 기체·센서를 설정하지 않는다.
파라미터 검증 도구는 R2·R3 버전 판독을 지원한다.
불완전·모호한 응답은 계속 거부한다.
관련 로컬 시험15개를 통과했다.

## 최종 결과

결합 빌드와 FC 업로드·검증을 완료했다.
이미지는1,939,132바이트다. 플래시 여유는26,948바이트다.
SHA256은0176a4365b0a55d905f37898577de17ff7b633a3ed28ac1aed2d12d0d09825c5다.
FC는14일17:29:23 빌드와 VER=2를 응답했다.
초기 업로더는 부트로더의 ttyACM1 재열거를 따라가지 못했다.
삭제 전 대기 중인 업로더를 종료했다.
by-id 경로로 재실행한 업로드·검증은27.736초에 끝났다.

TFmini Plus -T -C 일회성 설정 ACK를 확인했다.
config state6·설정 오류0·통신/체크섬 오류0이다.
설정 대기 뒤 첫 상태 요청은 작업 도구의 신선도 검사로 중단됐다.
새 조회 연결로 ACK·현재 읽기 상태를 확인했다.
센서 설정 명령을 중복 실행하지 않았다.
거리 범위 거부가 누적되고 유효 발행은0이다.
현재2cm 배치에서 정상 거리 검사를 유지한 결과다.

SD extras.txt는 이전 파일을 보존한 뒤 -T 시작으로 변경했다.
매 부팅 SAVE를 하지 않도록 -C는 넣지 않았다.
일반 TF02PRO가 먼저 시작될 수 있어 stop 후 전용 모드를 시작한다.
재부팅 뒤 VER=2·-T 모드 자동 시작을 확인했다.
76.100025초 동안 범위 판정 수가3,805회 증가했다.
같은 구간 읽기 시각 기준 처리율은49.999984Hz다.
이는 평균 약20ms의 읽기 결과 처리율이다.
개별 유효 거리 발행 간격이나 물리 측정 지연 통계는 아니다.
통신·요청·읽기·헤더·체크섬 오류와 skipped slots는0이다.
센서 전체 전원 차단·재인가 시험은 하지 않았다.
-T 일반 시작은 내부100Hz readback을 제공하지 않는다.
앞선 일회성 설정·저장 ACK와 구분해 기록했다.

재부팅 후 숫자 파라미터1,098개를 다시 대조했다.
변경은 EKF2_LID2_VER 1→2뿐이다.

가속도계·자력계·RC·고도·제어 설정을 보존했다.
EKF2_EV_DELAY=0ms, LID2_EN=1, LID2_AGE=180ms다.
EKF2_AVEL_DELAY=5ms도 유지했다.
운영 관측 서비스는 active 상태다. 디스크 여유는 약12GiB다.
