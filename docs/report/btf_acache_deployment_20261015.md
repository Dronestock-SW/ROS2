## 설정 변경과 복귀

**앵커 설정 변경 후에는 해당 노드를 재시작한다.**
물리 배치와 수신기 앵커 파일·B_TF config를 함께 맞춘다.
현재 실행 중인 프로세스는 파일 변경을 자동 적용하지 않는다.
새 프로세스에서 기하 해시와 `builds=1`을 확인한다.
ClockMap·모델 reset은 같은 기하의 캐시를 유지한다.

운영 전환은 아래 drop-in을 추가했다.
`/home/arialhanho/.config/systemd/user/dronestock-manual-observe.service.d/zzzz-acache-20261015.conf`
이전 drop-in과 슬롯은 보존했다.
복귀할 때는 새 DISARM·지상 확인 뒤 이 drop-in만 다른 이름으로 보관한다.
그 뒤 daemon-reload와 센서 서비스 restart를 수행한다.
기존 슬롯 경로·센서·backend를 다시 확인한다.
배포 실패 시에는 activate.sh가 이 복귀 절차를 수행한다.
복귀 실패는 별도 주의 파일로 남긴다.
이번 적용에서는 복귀가 발생하지 않았다.

센서 서비스 restart는 MAVROS·UWB 수신·B_TF·스트림 요청 노드를 재시작한다.
따라서 FC 텔레메트리 연결이 잠시 다시 맺어진다.
이전 슬롯의 native 라이브러리를 계속 사용한다.
새 슬롯 운용 중에는 이전 슬롯을 삭제하거나 변경하지 않는다.
